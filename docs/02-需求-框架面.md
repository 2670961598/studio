# 02 · 需求 — 框架面（F1 执行调度 / F2 数据状态 / F3 自进化监控）

> 来源：3 路框架面需求 agent（2026-10-15），主 PM 整理。

## F1 · 执行调度与适配器

**设计判断**：core 只做确定性决策（同状态同配置必同决策），一切 executor 差异收敛到适配器能力声明，调度器里不留 `if executor`；成功语义必须契约化（dsh 被 kill 退出码=0 且 final 空是实测坑）；预算预留-结算做成事后扣减等于没做。

| # | 需求 | 验收口径 |
|---|---|---|
| F1-01 | 主循环单 tick 幂等相位机：采集→state-diff→派发→收割→合并→回收→落账/心跳；daemon 唯一写入者 | 5 个 kill 点崩溃注入后重放同拍零重复动作 |
| F1-02 | 采集改 YouTrack 活动流增量（categories+epoch-ms 游标持久化），全量 list 降为对账 | 滞后 P95≤2 拍；游标丢失自动全量重建零重复 |
| F1-03 | 派单决策纯状态驱动，由(状态,等级,Type,泳道租约)唯一决定；派发参数=adapter×model×plugins×唤起源单据级可配 | golden trace 回放决策一致 |
| F1-04 | 装配=分层提示词拼接（见 C2），每次出工记分层指纹+哈希 | 任一派发可复现完整拼装 |
| F1-05 | 并发三闸：泳道租约（跨项目同名泳道同一物理仓互斥，锁名不含 pid）+每拍派发上限+全局在途上限；TTL+心跳续租+死主回收 | kill -9 后租约到期可回收；触顶顺延不丢 |
| F1-06 | 收割成功判定契约化：成功=终态事件(completed)＋输出非空＋REPORT 落盘＋闸门 exit=0；usage 按 executor 分派解析 | 四家各一例"kill 后退出码 0"判红 |
| F1-07 | 证据与闸门：冻结命令禁改（哈希留痕）；派发闸⊆消毒器；加测 exit=2 判"不可判定"跳过；复验/合并持租约切本单分支，忙则顺延不烧 attempt | 含 `~`、`cd && for` 形态的冻结命令不误杀 |
| F1-08 | 看门狗三道：wrap 内 wall-clock kill（进程组 SIGTERM→宽限→SIGKILL）/daemon 侧兜底/心跳超时；kill 后等死再重派 | 僵死进程被 SIGKILL 且卡道≤宽限 |
| F1-09 | 预算预留-结算：launch 前原子预留→完工 settle 释放→超额调用前拒绝落 refusal；归因键适配器层注入 | 扇出不超父单预留；refusal 可查 |
| F1-10 | 断路器：同(单号,错误签名)连击 N=3 断路——停重派+回首批位+自动开 bug 单+面板标记；异常同样计 attempt | 人为卡单自动开 bug 单；断路后零新 DISPATCH |
| F1-11 | 唤起六源统一：六源只产"意图"交主循环按状态决策，任何源不得直接驱动 worker；接力=幂等提示（本机+wkey+防抖） | 六源各一端到端；接力重投零重复派发 |
| F1-12 | 适配器协议：四原语+能力声明（上下文/工具集/成本模型/权限模式/副作用等级/插件清单/预算帽支持/单轮 cancel 支持）；未登记 executor 启动即错；副作用 prepare→execute→receipt | 四家过同一探针集；receipt 重放不重复执行 |
| F1-13 | 四家接入：claude=参考实现（含预算帽）；kimi-code（usage 读 wire.jsonl；`-p` 与 yolo/auto/plan 互斥）；dsh（锁版本+价目表折算+看门狗兜底）；codex（exec --json） | 同单可换 adapter 证据格式一致 |
| F1-14 | dsh 治理边界：生产泳道禁运行时自装插件（默认禁+patch 双保险）；自修改仅 explore/沙箱；自进化输出只作提案；并发不共用 sdk runtime；禁转包 | 生产泳道装插件被拒留证；转包检测拦截 |
| F1-15 | **续跑协议（resume）**：`studio resume <单号>`（或 `--session <id>` / `--worker <工号>` 定位）→ 从 work_records 取最近一次工时单（executor+session_id+泳道+分支）→ 用该 executor 的原生续跑（claude `--resume`、dsh `--session-id`、kimi/codex 各自机制，适配器声明是否支持）→ 注入**前情摘要**（上次 REPORT 结论+diff 名单+打回理由，≤300 字，P3）→ 新工时单挂 `causation_id` 链到上次 | 任一已交付单可续跑且上下文含前情；续跑不重置 attempt 计数（防断路器被绕过）；不支持续跑的 executor 明报并降级为新派 |

## F2 · 数据与状态

**设计判断**：SQLite 只是**可重建投影**不是第二事实源（每行能答"权威源是谁"）；ULID 的顺序保证来自 daemon 单写入者；token bucket 互斥先定计费口径再落列；**回填前先对账——done.json 实测 194 份**（蓝图 1167 系口径混淆）。

| # | 需求 | 验收口径 |
|---|---|---|
| F2-01 | 三事实源边界+版本纪律：流程=YouTrack／组织=config.yaml／产物=文件，SQLite=可重建投影；daemon 唯一写入；migration 脚本化；schema_version 不符拒启动 | 任一表答得出权威源 |
| F2-02 | events 账本 append-only：ULID/ts/pid/issue/event/actor(工号+账号)/attempt/level/dept/correlation_id/causation_id/tokens/cost/duration/size/payload_hash/note；25 类事件枚举+zod | 无 UPDATE/DELETE 路径；未知类型拒收 |
| F2-03 | 结果体分离：库内只存 status/hash/size/path_ref；大 payload 留文件，prompt 短保留期 | 行可反解路径且哈希校验通过；库内无 >8KB 文本列 |
| F2-04 | 互斥 token bucket：input/output/cache_read/cache_creation 四列+计费口径标志 | 成本对账 drift<5%；"有 usage 零成本"体检为空 |
| F2-05 | work_records+sessions：工时单（工号/实例/单号/泳道/branch/起止/attempt/adapter/model/cost/tokens/session_id/refs/status）；会话索引 | 194 份 done.json 逐字段回填一致；单号 1s 定位会话 |
| F2-06 | people+personnel_events：people（工号 stable PK/名称/login/等级/部门/岗位/技能+side_effects/能力档/汇报线/状态）；台账 append-only 必挂单 | 抽查变动答出谁批的、依据哪单 |
| F2-07 | departments+ticket_mirror：部门只读镜像 config；单据镜像（created/updated/state/type/dept/level/dispatcher/parent/lane） | 抽样 100% 一致；config 变更后可重建投影 |
| F2-08 | ledgers+reports：task_ledger（事实/假设/计划）+progress_ledger（进度/卡点/重规划）；reports 快照（口径版本+数据窗口） | 任一报表可回溯台账快照复算一致 |
| F2-09 | candidates+budgets：候选制品（类型/版本/diff/blast_radius/验证结果/谱系父 id/状态）；预算 reserve/settle/refusal 三节点 | 多级扇出超支为 0；制品答得出来自哪代哪单 |
| F2-10 | YouTrack 镜像：启动全量+运行期活动流增量（1 分钟级）。**实测口径（2026-10-16 对拍）**：`start`（epoch-ms）参数有效、`after`/`startAfter` 被静默忽略；游标=start 持久化 + 最后活动 id 去重双保险，水位以 issue.updated 复核 | 断网 1h 恢复后无缺口无重复 |
| F2-11 | JSONL 双写灰度：库为权威写、JSONL 单向派生；每日比对行数+哈希，零分歧 30 天降级为导出格式 | 灰度期分歧=0；CLI 可从库再生 events.jsonl |
| F2-12 | 恢复重建+演习：rebuild --from jsonl,yt,org 全量再生；季度删库演习；每日快照不入 git；删库与删备份不同钥匙 | 再生后行数/哈希全对，演习留盘证据 |
| F2-13 | 存量回填：先对账（2026-10-14 实测：done.json 194/REPORT 286/stream 315/events 11807/LLM 1167，**数字以回填日实测为准**）再走幂等脚本+逐条校验+差异清单；旁路关单（有 CLOSE 无 DISPATCH）标注处理规则 | 抽检一致率 100%；差异入清单不静默丢弃 |
| F2-14 | contract 契约包：cases.json（稳定 id+恰一 in/out/err+`__NULL__` 哨兵）+JSON Schema 描述三格式；vitest 侧 30 行 runner 为主 | 纯函数部分全绿；外部依赖转 golden trace |

## F3 · 自进化、监控与健壮性

**设计判断**：护栏与进化目标同处一个可编辑面是头号死法——物理隔离（独立进程/权限/仓）而非注释约定；探针集泄漏比闸门不足更致命（验收=扫描零命中）；零分歧必须定义到决策字段；最差分位与证据可追溯率必须与均值同屏；刹车必须在运行时可执行可演练。

| # | 需求 | 验收口径 |
|---|---|---|
| F3-01 | 进化管线统一入口：全部可进化资产走同一 promote 状态机（观测→提案→沙箱→闸门→灰度→切权→复盘），禁旁路 | 无 candidate id 的生产改动即判负 |
| F3-02 | 候选制品四元组+谱系：{版本/diff 哈希/blast_radius 分级/验证结果}+谱系父 id 缺一不进闸门 | 任一上线资产反追 ≥3 跳谱系 |
| F3-03 | 三态闸门+fail-closed：accept/reject/escalate 按 blast_radius×风险档定档，仅 escalate 惊动制作人；无审批人默认拒绝 | 初期建议全 escalate 再放开 |
| F3-04 | 灰度切权+回滚：shadow 并行记账，决策字段级 diff（派谁/目标状态/预算动作），零分歧期满+回滚演练后才切权 | 分歧判据冻结后禁改 |
| F3-05 | 探针两层：能力（定级/可接单域）+回归（历史已通过子集）；确定性 oracle > rubric+judge；judge 禁同族模型 | 升级前回归全绿才放行；同族 judge 告警 |
| F3-06 | 探针集私有+物理隔离：题目不进产品仓/不进 worker 上下文/不进进化观测输入；独立进程独立权限 | 全量扫描探针原文零命中；越权读取攻击用例失败 |
| F3-07 | 监控两面分册+防通胀：框架面/公司面口径分离共用台账不共用报表；看板必含证据可追溯率+最差分位；禁提交数当绩效；审批界面展示原始证据 | 单维均值报表判负 |
| F3-08 | 异源监控：验证岗不得与生成者同 CLI 同模型，固定用"另一家"适配器 | 同源比对自动开 bug 单 |
| F3-09 | 心跳+报错升级电路：daemon 心跳区分零活动/采集故障；同单同错误 N 连击自动开 bug 单 | 制造卡单→自动开单演练 |
| F3-10 | 配置漂移看门狗：config.yaml 与代码能力/未提交改动/注释与值矛盾三类漂移，只读确定性零 LLM | 三类各造一例全部检出 |
| F3-11 | 崩溃注入+幂等恢复：五点各 kill 一次；prepare→execute→receipt，恢复先查 receipt | 五点全绿方可切权 |
| F3-12 | 短时令牌+不可逆阻断：凭证按单签发任务结束即吊销；删数据/改权限/对外发信/动钱独立进程同步拦截；删数据与删备份不同钥匙 | 四类不可逆操作无人工确认被阻断 |
| F3-13 | 审计：台账 append-only+rolling hash 链；月度外审保留兜底；每月自检管线盲区 | 篡改一条历史事件校验失败且定位到行 |
| F3-14 | 全部设计过审后在 YouTrack 开新项目实施、拆单开工；F3-01/03/06 为 P0 前置 | Epic 拆单完成，每需求一单一冻结验收命令 |

**开放问题**：分歧判据须先冻结；探针集 CI 怎么跑；组织配置的权威边界（`org-config.yaml` 单源，→ 总览 D1）；daemon 自我进化的 blast_radius 定档；全局在途上限默认值；游标存储位置。
