## 一、决策一：公司规范 v1 终审（docs/43 定稿 + §七增补 + docs/44 验证报告）

**⑤验证已过**：良性最小包真闭环全链绿（真 dsh spawn+真闸门+台账四要件）；五恶意样本
（.git 钩子包/路径逃逸/env 探测/指纹漂移/harmless 自述）全部被**机制**挡下；零削弱零放宽。

**拍板项**（可整体批准、可逐条改）：
- **a. 方向 C 分层规范**（核心层十条每条点名执行点+可选层 fail-closed）——A 最小规范已被
  红队+前沿双路独立否决（纯声明无执行点=制造已防护错觉）；B 全量方向对顺序错。
- **b. 信任立场=Compose 口径**：「公司包是你要跑的代码，不是你要看的数据」。
- **c. 边界 A**：v1 不承诺「下载即跑安全」（confinement 执行点不存在，降级为目标面）。
- **d. 边界 B**：v1 公司包不含平台绑定与 IM 绑定（业界空白，先 spike 后入 v1.x）。
- **e. 八条「不做什么」**（docs/43-§三：不做签名 PKI/不做 registry 运营/不做多 executor
  协商降级等）。
- **f. §七增补采纳**：manifest 更名 `package.yaml`、`extendEnv:false` 前提、信任锚双向
  排除等六条。

**拍板后动作**：v1 冻结 → 条款 1-10 各落实现单（含 M2.2-⑤/M4-⑧ 挂账收口）→ 模板对齐
→ 契约测试收口。

## 二、决策二：协作栈路线（docs/46，四条候选可组合）

| 路线 | 一句话 | 许可证 | 即期工程量 | 关键风险 |
|---|---|---|---|---|
| **A 零接触** | 编排引用+API 消费（现状） | 三形态近零义务 | ~0（产品级向导 5-10 人日） | 上游转向（Taiga 主力已移 Tenzu） |
| **B IM 换引擎** | 家服务器迁 Tuwunel（Apache-2.0） | IM 侧 AGPL 雷提前拆除 | 试点 ~5 人日 | bus factor+数据不可回迁 |
| **C taiga 二开** | 插件优先（MPL 文件级）、前端永不碰 | 插件零义务 | 15-25 人日/插件 | rebase 债+二开冲动蔓延 |
| **D LocalFile 优先** | 内置最小平台升默认 | 全零（自有代码） | 25-40 起步/对外 60-100 人日 | 范围蔓延=重造 PM 平台 |

- **组合性**：A 是所有路线的公共底座（无理由不保持）；B/C/D 是介入深度阶梯、可叠加。
- **宰相参考序**（非决定）：A 恒保 + B 设触发条件（Q2=是 或 Synapse 运维痛感）+ C 维持
  「功能必须住平台侧」门槛 + D 待规范冻结与面板收口后按「最小够用」宪法评估。
- 完整六面评估/对比矩阵/八条决策点见 docs/46-§三/§四/§五。

## 四、决策四：桌面平台（docs/48，四形态候选）

| 形态 | 一句话 | 体积/门槛 | 桌面独有能力 |
|---|---|---|---|
| **A 纯 Web** | 浏览器访问 :8787/:8789（docs/37 已选型底座） | 零 | 无（管家职能缺失） |
| **B PWA** | A+manifest+Dock 图标+Web Push | 极低 | 告警触达可补，无进程管理 |
| **C Tauri 壳** | Rust 壳包裹面板（2.12 稳定线） | ~3-10MB，Rust 门槛 | 全管家职能 |
| **D Electron 壳** | 与 Codex/Claude Desktop 同路（44.9.0） | ~120-200MB | 全管家职能+TS 同构复用最高 |

- **关键洞见**：六项桌面能力中 2/3/5（编辑中心/向导/token 控制台）本质是 HTTP 面（Web
  即可承载）；**真正只有壳能做好的是 daemon 生命周期管理与漂移告警触达**——「壳的价值
  在管家职能，不在视图职能」；A 是公共底座、无后悔路径。
- **宰相参考序**（非决定）：A 先行（随面板收口 v0.8）→ 壳形态（C/D）待管家职能成为真实
  痛点再启动。
