## 2. daemon 内部设计

> 目录结构（DEV-45b 结构刀按域分层）：`src/engine/`（领域机制，含 `tools/`）｜`src/control/`（进程控制——热重载/停机通道）｜`src/evolve/`（进化链）｜`src/cli/`（命令面 22 文件 = 20 命令模块 + taiga-cure + help 小件——分面求助/错误面发射器；jobs 组=list/catchup 两子命令，studio-dev-127 §4.3；gen-templates 分级模板生成器，DEV-14；**增删/改名命令必回写本行**——studio-dev-103 S6/S1b）｜`src/assembly/`（组合根 serve）｜`index.ts`（纯出口）。
> 分层与依赖边界：依赖方向冻结/尺寸阈值/域平面纪律=分层宪法（20-§十五），由 `bun run guard:boundaries` 机械门禁强制。
> CLI 人机面约定（studio-dev-103 S1/S5，studio-dev-125 实施）：错误行→stderr、帮助面→stdout；显式求助（-h/--help/help）exit 0，用法错（含裸命令/typo）exit 1，命令自身错误 exit 2（仅 company validate 判定器自身错误与 serve tick 异常）；`--flag=value` ≡ `--flag value`；`--version`/`-V` 读 apps/daemon/package.json。声明正文单一源=`src/cli/usage.ts` 尾部（语法位/旗标同义/退出码/版本四表），对账闸=`apps/daemon/test/cli/`；改约定=改 usage.ts，不另立双源。

**主循环（相位机，每拍幂等）**：`采集 → state-diff → 派发 → 收割 → 合并 → 回收 → 落账/心跳`
- 采集：YouTrack 活动流增量（`start` epoch-ms 游标 + 最后活动 id 去重双保险）；启动全量对账
- state-diff：纯函数 `decide(state, level, type, lane_lease) → action`，golden trace 可回放
- 并发四闸（129-§6.2-R3，studio-dev-167 单B）：断路 > 泳道租约（锁名不含 pid，TTL+续租+死主回收）> **人闸**（缺省 1/人，`HOLD_PERSON_BUSY` 顺延不丢——批量执行岗可配并发覆盖）> 每拍上限 > 全局在途上限；派发定序=排序键规则缺省档（score=意图优先级+ageBoost 两档封顶、置顶恒首、并列 FIFO，129-§6.2-R1/R4；小模型精序档已接线=160-B·studio-dev-182 两址 `mj-129-pick`/`mj-129-interrupt`——daemon.yaml `judgeSites:` 逗号清单缺省空=规则缺省档；**不越权双轴**：置顶单永不入两址候选集、重排只在非置顶区头部纯置换不增不删，降级=规则档原序；体=`engine/judge/sites129.ts`）
- 收割相位尾·落位对账步（P3，studio-dev-100 提案 §4.3，2026-10-21 全批；相位内步骤**不增删相位**）：`jobs[].output` 声明落点 × 公司目录实际文件——缺归档=`REPORT_MISSING` 事件+内容哈希幂等补收（先事件后搬运；哈希异转人工绝不覆盖）；有产物无 REPORT=`HARVEST_INCOMPLETE`（不补收不代写）；收账面不可读=`HARVEST_DENIED`（不静默）。节流拍跑（`harvestReconEveryTicks`，缺省 30）
- P3 读回门扩展（R4，studio-dev-127 §4.5 批示⑤，2026-10-22 全批）：只对**已归档且可读**的目标件生效（冲突/转人工既有支配序不动）。④ 内容门——归档 REPORT 有效字符（Unicode 字母/数字）<16=`HARVEST_INVALID`（骨架/占位空壳不充数；recon-key 含目标件内容哈希，修复=换哈希=换键可再报）；⑤ 哨兵门——工单型岗单归档 sidecar `<归档名>.summary.json` 三元组（company/job/nonce）非期望=`SENTINEL_MISSING`（**欠账不重派**，处置=`studio-next jobs catchup` 手动补跑；nonce=sha256(`company:job:run_at`)，抄旧槽必 mismatch）。patrol 巡查物化单只计观测数不事件化（无收割语义——结构性零产出不进对账流）
- 定时岗新鲜度窗（R2，studio-dev-127 §4.3 批示④）：计时器族第三源 `freshness`（tick 驱动零内存态，serve 旗标 `freshness` 缺省关）——越窗 `next_run_at+grace` 落 `JOB_STALE`（停跑）/`LATE_FIRST_RUN`（从未跑：配置坏≠跑了没产出）；只落事件不派工，处置=CLI 手动补跑。grace 解析序：`jobs[].grace`（org-config，如 `2h`）> cadence 档缺省（hourly 10m/daily 2h/weekly+monthly+quarterly 12h）> cron 周期桶（≤90min→10m/≤36h→2h/else 12h；坏 cron 从宽 12h）；DST 豁免=槽/现时 offset 差。逃逸档（paused/manual/offline/下线）白名单不扫
- 同一 tick 内单只一单至多一动作；tick 返回结构化 actions 落账
- 合并相位（202-P2 双轨注记，studio-dev-232，202-§5.2）：待验收位（post-verified 批准槽）+standing 批准在场+触发全齐（未标 merge=manual/合并租约空闲/断点可解析——末位工时单 executor_session_id+summary 可读+session_resume executor+repo HEAD 可解析）=**真单刀**：相位 5 内 resume 唤起**原工位原会话**（resumeWithSession，dsh 侧会话 id）自合并——最小合并任务书（续跑版+合并指令块）→收割链同构四要件→全绿 daemon 代推 dev【R2】→MERGE 真事件（提交 sha/门禁摘要/续跑证据）→迁已交付；触发不齐=降级宰相手工链（ESCALATE `chain=manual` 锚每单一次；每拍重查，宰相修复阻断件即自恢复；merge=manual 锚=终局让位）；**收割四要件不齐=冲突兜底**（202-P3，studio-dev-233，§5.5）：GATE_FAIL 追 `category=MERGE_CONFLICT` 锚（错误类词表既有——台账事件名冻结零新增，分类随 note 走锚）+清批准站立+merge=manual 终局让位+ESCALATE 通知宰相（低噪不广播）+**不自动重试**（同会话重试=同结果空转——合并跑面位别覆写 worker 循环面的 retry 行，一次自合并失败即手工链）；手工链完成后批示:批准（R6：宰相∪制作人∪派单策划——P1 验收位白名单四源覆盖）重建站立→decide 再出 mergeTo→**v0 模拟迁移转正为手工链收口路径**（simulatedMergeTransition 共体：迁移语义不删不改，note 如实=宰相手工链收口、无真 git 合并不冒认真单刀）；lease 忙/批示不在场=顺延不弃单——顺延单重进决策候选经新活动或镜像 rescan 兜底（DEV-42① 既有机制，缺省 30 拍）。面关（serve 无 acceptance 配置）或非验收位=v0 模拟合并零变更（原「v0 模拟合并」注记由本轨取代）。体=`engine/merge/`（merge-run.ts 头注=语义总纲；位别接线：断路器不计连击、平台迁移面在途禁用、wkey 不签发、attempt 续号）
- micro-judge 判断调用（studio-dev-160，2026-10-22 全批）：框架内微调用，**零生命周期**——不进七相位/收割/work_records，主循环相位只可作其唤起点；判定结果进状态组装已接（C7 口径，160-B·studio-dev-182：judge 结论作为候选定序输入进 state-diff——`decide` 纯函数签名不动，golden trace 面=`TickReport.phases.stateDiff.judge` 段+JUDGE_* 事件族 append-only 可回放）；可观测面=JUDGE_* 事件族+预算行（apps/daemon/src/engine/judge/）

**调度表（jobs 表，SQLite 持久化）**：
`{job_id, company, dept, cron, role, level, model_tier, budget_cap, payload, next_run_at, last_run_at, status}`
- 定时岗全部来自公司目录配置（D9）；启动时扫 `next_run_at <= now` 的槽位补跑（coalesce 成一次）
- 表达式解析用 croner；补跑/错过语义自己实现（APScheduler 语义无现成库）

**生命周期**：supervisor（launchd/看护脚本）拉 daemon；`/api/health` 心跳；
升级=进化管线候选制品，切权后 supervisor 重启加载。

## 6. 执行与收割（adapters 包）

四原语实现差异全在适配器内：
| executor | launch | stream | result_stats | kill |
|---|---|---|---|---|
| dsh | `dsh --profile headless --json`（锁版本） | NDJSON（step_end 带 usage） | tokens 有，**成本无价目表折算** | SIGTERM 可杀；成功判定=turn_end.completed+输出非空（非退出码） |
| claude | `claude -p --output-format stream-json --max-budget-usd` | stream-json result 事件 | 原生 cost/tokens/duration | killpg TERM→KILL |
| codex | `codex exec --json` | turn.completed.usage | tokens 有，成本折算 | 同上 |
| kimi | `kimi -p --output-format stream-json` | stdout JSONL；**usage 读 session wire.jsonl** | tokens 有，成本折算 | 同上（`-p` 与 yolo/auto/plan 互斥） |

收割成功契约（四要件）：终态事件 completed + 输出非空 + REPORT 落盘 + 闸门 exit=0。
（202-P2 合并跑位别注记，studio-dev-232：四要件同构复用于合并跑——要件 4=引擎亲跑冻结
验收命令【R1】∧合并提交存在性核验（目标分支 tip 为 merge 提交且含 review tip 祖先），不加
要件不改判据；回执=`merge-REPORT.md`；断路器不计连击/平台迁移面在途禁用/wkey 恒不签发
——位别接线全表见 `engine/merge/merge-run.ts` 头注）
REPORT 旁落 `summary.json` sidecar（结论/改动文件/打回理由）供续跑前情摘要；工单型定时岗单
sidecar 另携**产出哨兵**三元组 `{job, run_at, nonce}`（R1，studio-dev-127 §4.2 批示③：
nonce=sha256(`company:job:run_at`)——同司同岗同槽确定、异槽必异；任务书 L4 注入期望三元组，
worker 原样并入 summary.json 顶层 `sentinel` 字段=「这一槽真产出」的机械回执；抄旧槽
（旧 run_at）必 mismatch。哨兵**不证产出质量**（三元组一致≠内容合格——质量归四要件+读回门
内容判据），数据源断链须 REPORT 如实上报不归咎模型）。patrol 巡查岗单不携哨兵（结构性
不进——零产出是契约本性而非欠账）。
**micro-judge 判断调用（studio-dev-160 §6，2026-10-22 全批；实现 apps/daemon/src/engine/judge/）**：
低档小模型微调用——框架组装结构化上下文 → 模型只回 `JSON{操作,参数}`（词表冻结）→ 三道闸
