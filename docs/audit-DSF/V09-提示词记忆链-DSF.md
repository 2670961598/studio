## 1. 结论

1. **P0 = 1，P1 = 4，P2 = 3。** 本条链的断点不在细节错漏，而在**中层缺失**：提示词/上下文这个对象在 L2（69–72）与 L3（76/77/82）**没有对象、没有记录类型、没有追溯行**，其唯一"规范源"是一份逐文件附录（81-files/05），而该附录自己写着这是"已存在的归属缺口"。
2. 最严重三条：
   - **V09-01**：C2-06/07/08/09/11 五条承诺在 69–82 无对象、无记录、无责任人落点。机械核对：76 全文 `L0/L1-company/L3-person` **0 命中**；77 全文 `任务书/TaskBrief` **0 命中**；82 全文 `提示词/prompt/C2-` **0 命中**；64 全文 `提示词/上下文/知识` **0 命中**。C2-07 的六类责任人里，四类（L0 主 PM、L2 人事台账、L3 整理岗、L5 适配器维护者）在 63–82 **零命中**，第五类"派单人"在 L2/L3 已改名为"派工位置"，只剩"制作人"一名能对上——责任人表用的是一套 L2 从未采用的词汇。

3. 值得记录的**通过项**（不构成本报告发现）：①"persona/AGENTS.md 不得当权限"处理正确——78-§2.4 三类（硬/软/不可表达）、§3.2.2 `persona.weight` 钉死 `soft`、§3.2.3 硬规则 4 禁止其承载允许/禁止语句；②四层记忆从 63-§1.5 → 65-§七 → 72-§三 → 76-§7.2（`GOV-POS-10/11`）→ 77-§八 → 82:535-536（`TR-G-10/11`）承接**完整**，且"删除不消灭历史""管理员权限不是处置授权"逐层都在，是本链条最结实的一段；③72-§5.1 明确"只是提示词"不自动降低变更分类，L2 对提示词变更治理没有放水。

### 2.1 关键断点（6 条，各说明会让什么失效）

1. **提示词六层在 L2/L3 没有对象，责任人与记账面整层落空** → 使 C2-07 的验收（"任一层变更答得出谁改/依据哪单/影响哪些在途单"）在记录面**不可答**。今天能答的只有两处非记录载体：公司目录的 git commit（覆盖 L1–L3 内容，不覆盖 L0/L5）与 `DISPATCH` 事件 `note` 里的 `fp=…` 自由文本（81f05:58）。两者都不是 76/77 意义上的记录字段。
2. **指纹用 sha8 与 `TS-SCALAR-08` 正面冲突** → 使 C2-08 从"版本可追"退化为"字符串可看"：短哈希被判不得作比对依据，而它唯一用途就是比对；L0/L4/L5 内容变化完全不动指纹，"按层出报表"与"跨实例同一内容可比"两条同时失效。
3. **L0 红线没有内容载体，"永不裁"与"抗压缩"同时落空** → 使 08-D8 的"五条不变律+四条红线"在提示词通道上**不存在**（它只存在于代码/闸门里）。这不是"未实现"，而是 L1 的两条验收口径（C2-06 的 L0 定义、C2-09 的永不裁清单）在描述一个不存在的对象。
4. **记忆/上下文注入侧三条通道全在四层记忆治理之外** → 使 65/72 的"不全量倾倒、每次访问留审计、清除边界"对**真正进模型的文本**不适用：`summary.json` 前情摘要（worker 自写、受信插入、300 字上限未实现，81f05:246/248）、`--session-id` 续跑（31:226 实测前缀缓存命中、模型复述上轮、会话存档在 `$DSH_HOME/sessions/<cwd>/<id>/`）、L4 `lessons`（来源与信任级未定、恒空，81f05:567）。结清清单（67:951-961）八项无"会话/上下文归档"，所以 transcript 永久驻留（31:199、25:271 记"员工家永不删=结构性满足的机器依据"）仍可宣称结清。
5. **C2-10 不可信隔离在生产链未启用，而三处外部可写文本按受信插入** → 使 C2-10 的验收（"被中和且落检测事件"）**既无正例也无负例**，无法证伪；`objective: input.issue.title`（`prompt-assembly.ts:157`）与单据正文/评论（`read-tiers.ts:49-51` 自注"v0 原样入任务书读面节…待批示"）都在一等指令位。
6. **责任人词汇断裂** → C2-07 的六类责任人里，"主 PM、人事台账、整理岗、适配器维护者"在 63–82 零命中；66-§5.2.1 十类治理位置与 76-§7.2 十一类都没有"上下文内容/提示词注入/知识沉淀"位。于是"谁改了提示词内容"在 L2/L3 无位置可指，只能落到"框架/daemon"——而 77:70-72 明令禁止把"框架/daemon"写成动作主语。
