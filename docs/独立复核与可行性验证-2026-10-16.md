## 二、逻辑闭环判定

### 2.1 闭环成立的五条链（简证）

1. **执行主环**：六源唤起只产"意图"→ 状态机唯一决策（纯状态驱动，golden trace 可回放）→
   派发装配（L0-L5→AGENTS.md，分层指纹记账）→ 四原语（能力声明收敛差异，调度器零 `if executor`）→
   收割成功契约（终态事件+非空输出+REPORT+闸门 exit=0）→ append-only 台账 → 报表逐级聚合 →
   老板收件箱/惊动预算 → 变动回流。环上没有一步靠自觉。
2. **数据环**：三事实源（YouTrack 流程/公司目录组织/文件产物）+ SQLite 只作可重建投影 +
   events 只增、索引全派生——可重建与不可篡改同真；F2-12 季度删库演习兜底。
3. **治理环**：网页编辑→草稿→三档批示→personnel_events 必挂单→daemon 代写 git commit
   （公司目录历史=组织变迁史）→三表 join 时间线回放。任一变动答得出谁/何时/依据哪单。
4. **进化环**：观测→提案→候选制品（谱系）→沙箱→三态闸门（fail-closed）→灰度→切权→复盘；
   判据类 L4 锁死、护栏物理外置、探针集与进化目标隔离、异源监控。
5. **对外环**：外部只落单不派工→派单人锚+等级封顶→幂等键→wkey→审计回放→A2A 只做 exporter。
   外部能量进不了控制面。
