## 二、开发流程自身（框架怎么被开发）

- **分支模型（2026-10-16 制作人定调：正式三级晋升）**：
  - 现 studio 仓 `master`：**冻结为 V3 维护线——只修 P0 bug，不发新功能**
  - Studio Next 新仓：`dev`（开发主线，feature/* 合入，CI 必绿）→ `gray`（预发布灰度：
    对生产 YouTrack 只读/限定泳道灰跑）→ `release`（正式发布，tag 版本）
- **晋升闸**：feature→dev=CI 全绿（tsc+vitest+contract+密钥扫描）；dev→gray=契约包+崩溃注入全绿；
  gray→release=灰度期零事故+**制作人过目**（东西我得过）→ tag（对应 16 的里程碑版本）
- **回退**：release 出问题，gray 顶回去修；V3 master 始终是最后兜底
- **代码评审**：worker 产出 → 异源验证岗（不同 CLI/模型）评审 diff → 主 PM 过（重装制作人）
- **CI**：push 触发 `tsc --noEmit` + vitest + contract runner + 密钥扫描；面板/概览加截图基线
- **测试金字塔**：contract cases（规格）> 单测（core 纯函数）> 集成（fake YT+fake CLI）> E2E（真单）> 崩溃注入
- **发版**：里程碑 tag 在 release 分支；CHANGELOG 从 git 历史生成；SemVer

## 三、日志与排障

- daemon 日志：结构化 JSONL（ts/level/job|issue/actor/msg/attrs），按日轮转，保留 30 天，>100MB 压缩归档
- 排障 runbook 入库：每类报警给"先看哪、怎么判、怎么处置"三句（STUDIO-30 类循环报警的处置范例当模板）
- worker 日志=stream 归档已有；新增"最近异常索引"页（:8787 报警面板直链单日志）

## 四、数据保留与归档

- events：热表全量；>90 天行按月导出 Parquet 到公司目录 `archive/`，库里留索引（报表读历史走归档）
- stream/REPORT 归档：按公司分区 `archive/<company>/<year>/<month>/`；总量超阈值告警
- done.json 类产物入库后可删文件（库里有全字段+哈希）
- 预算口径：全周期成本=热表+归档合并

## 五、多公司关系

- 资源仲裁：全局在途上限 + 每公司配额（并发/日预算/日开单数），高等级公司优先可配；超限排队不拒绝
- 跨公司单：一张单可挂多个公司（YouTrack 链接），派单人=主责公司；成本按工时分摊
- 公司间接口=对外 API（同一套，无特权内部通道）

## 六、通知与告警通道

- 通道优先级：面板置顶（默认）→ 群聊 bot（可配）→ 邮件（默认关）
- 告警分级：info（入日报）/ warn（面板置顶）/ critical（即时通知制作人，计入惊动预算）
- 同一报警去重（同单同错误只报一次，NC1 教训）

## 七、备份与灾难恢复全图

| 资产 | 备份 | RPO | RTO |
|---|---|---|---|
| SQLite 台账 | 每日快照 kernel/backups/ | 24h | 分钟级（恢复或全量重建） |
| 公司 git 目录 | 私有远端或纯本地+每日快照 | 24h | 分钟级（git clone/restore） |
| YouTrack | 容器卷每日快照（docker volume tar） | 24h | 小时级 |
| 框架 config home | 每日快照 | 24h | 分钟级 |
| 宪法内核 | 随框架仓 git | 全量 | 重装即有 |
- 每季度恢复演习一次（删了再生，留证据）；删数据与删备份不同钥匙

## 八、安装/升级/卸载

- 安装：`bun install -g studio-next`（或单文件）→ `studio-next init`（检查依赖/建 config home/注册公司目录）
- 升级：进化管线候选制品 → 灰度 → 切权；`migrate` 子命令处理 SQLite 与公司目录 schema 版本
- 卸载：`--purge` 保留公司目录与台账导出，删程序与 config home（双确认）

## 九、性能预算

- 主循环一拍 ≤5s（三公司级）；面板首屏 ≤1s；概览页 ≤2s；活动流增量滞后 P95 ≤2 拍
- 成本预算：定时岗日成本上限默认 $50（公司可配）；单工单预算帽默认 $15
- 9 级规模：SQLite 百万行内无压力；超出再议分区

## 十、密钥管理细节

- 凭证只存 config home（0600 权限）+ macOS Keychain 可选；台账/日志/报表永不写明文密钥
- wkey 按单签发、关单吊销、库存哈希；面板 token 与对外凭证完全隔离
- 密钥扫描在：push 前 + 对外 API 出站 + 报表生成后，三处

## 十一、时间与时区

- 一律本地时区（制作者机器），ISO 8601 落盘带 offset；cron 按本地时区（现有约定延续）
- 报表"日/周/月"边界=本地 00:00 / 周一 / 每月一日

## 十二、框架自身 DX（给开发它的 AI 用）

- `npm run dev`（tsx watch）/ `npm test` / `npm run contract` / `npm run doctor`（环境自检：Node 版本/dsh/YouTrack 连通/端口占用/凭证在位）
- 新 worker 上手框架开发：读仓内 AGENTS.md（写给 agent 的开发指南）——吃自己的狗粮
