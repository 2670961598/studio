## 〇、根命题

> **本纲所称的公司，其存在与运行的正当性在于：在有正当来源、可被相关方检验的使命与
> 边界内，组织权责、能力、资源与信息，持续把意图转化为可验收的结果，并对过程、代价
> 与后果负责。**

这是一句**规范定义**，不是对所有现实公司为何能够存活的经验解释。一个组织可以在事实上
自动运行、取得收益甚至长期存续，同时因自证、越权或逃避责任而不符合本纲。违反本纲
不否认其经验存在，只表示它失去本纲所要求的自治正当性。

根命题包含八个不可拆去的部分：

1. **使命与边界有正当来源**：来源可以是设立公设、合法委托、共同契约或公共规则；来源
   必须公开、可说明、可质询，不能因内容看似合理就免除来源检验。
2. **使命与边界可被相关方检验**：内部声明不等于正当性已经成立；委托方、受益者、
   受影响者与监督者按各自关系拥有相应的知情、异议、验收或救济位置。
3. **公司组织的是完整履职条件**：权、义务、能力、资源与信息缺一不可；任何一项缺失
   都必须显式处置，不能被其他项冒充。
4. **公司由责任关系而非执行工具维系**：执行主体可以更换，责任关系、历史与承诺不能
   因此消失。
5. **意图可以被发现和修正**：探索、学习与新事实可以反过来修正意图，但修正必须回到
   使命、既有承诺与边界接受检验。
6. **结果必须可验收**：交付不能仅以动作发生或自我宣称完成；验收不等于价值，指标
   达标不等于使命达成。
7. **过程、代价与后果同责**：好结果不能洗掉违规过程、隐性成本、未兑现承诺和对外损害。
8. **持续包含维持、退出与清算**：持续不是永不终止，而是在合法存续及其后的责任期间，
   不让工作、承诺与责任无声消失。

本纲不把公司理解为单纯的「意图 → 产物」生产函数。公司还要选择意图、协调多主冲突、
维持自身能力、保存事实、修复错误、证明正当性，并在必要时终止与结清。

### 0.1 本纲所称「闭环」

闭环不是自我证明，也不是封闭系统。一个闭环必须同时具有：

- **合法入口**：输入从何而来，谁有权提交，谁必须受理，何时接受、拒绝或暂缓；
- **有序转化**：每一步的输出能够成为下一步的合法输入；
- **具名责任**：每一步由哪类责任位置负责，实例化时又如何落到具体主体；
- **事实反馈**：实际结果能够反向修正判断，而非只在体系内部互相引用；
- **终态与出口**：成功、失败、撤销、终止均有定义，超时、冲突与无能也有去向；
- **后验校正**：结果不仅被记录，还能改变后续决策、能力、组织或规则。

暂缓、附条件接受与叫停必须附期限或复审条件，否则不是闭环中的合法状态。新事实、
新证据可以依法重开已经闭合的事项，但重开与原样重复申请不是一回事。

**闭环的完备，是每种已识别情形都有合法处置路径；未知情形一旦被发现，也有进入剩余
裁量或元治理的入口。它不表示预先知道世界上所有答案。**

### 0.2 本纲的四类命题

| 类型 | 含义 | 如何审查 |
|---|---|---|
| **规范公设** | 我们选择何种正当性：边界先于效率、不可自证、责任不可匿名等 | 由设立者及合法治理程序确认，不冒充经验定律 |
| **逻辑结论** | 在接受定义与公设后，为避免矛盾而必须成立的规则 | 用反例检查自洽性、覆盖性与未定义情形 |
| **设计选择** | 岗位范式、部门数量、职级名称、权责目录、控制参数 | 比较替代方案与场景后果，不冒充逻辑必然 |
| **经验假设** | 自治在某任务分布内有效、独立验证值得成本、学习能改善表现等 | 预先声明任务范围、时间窗、基线与失败条件，接受现实反驳 |

技术可行性属于经验问题。外部条件可以限制理论何时可用，不能替理论修补逻辑矛盾。
本纲中的全局不变量除明确标为事实与概念区分者外，均是规范承诺；其具体参数属于设计
选择，不得借「不变量」之名免除验证。权能分离、禁配累计、授权不放大、空编不能解释
实际履职等属于由核心定义与规范公设共同推出的逻辑结论；岗位与部门的具体形态不是。

## 一、核心概念

### 1.1 公司、目的与关系

**公司（Company）**：由持续使命、权责关系、历史与承诺联结的责任共同体。公司的同一性
不取决于某个任职者、执行能力、部门或工具；合并、分立、迁移与终止时，以历史、承诺和
责任的合法承接关系判断连续性。本定义不自动授予法律人格。

**使命（Mission）**：公司持续存在的方向与价值承诺。使命不是某一任执行者的临时目标，
也不是任何指标的最大化。使命可以依法变更，但变更属于元治理，不属于普通工作优化。

**意图（Intent）**：希望形成、维持、避免或停止某种状态的具体要求。意图可以来自委托、
章程义务、外部事件、内部发现或既有承诺；来源经检验不等于内容必然可执行，仍须受理。

**委托主体（Principal）**：给予公司使命或特定合法意图、并有权接受相应交代的主体。
委托主体可以是单方、共同决策体或成员关系；制作人是本项目当前形态之一，不是唯一命名。

**受益者（Beneficiary）**：意图使其结果为自己或他人带来价值的主体。受益者接受、使用
与长期效果，是价值判断的重要依据，但不因此取得修改公司边界的当然权力。

**受影响者（Affected Party）**：承受公司行动风险、成本或损害的主体，包括未直接委托
或受益的第三方。其发言权与保护需求随暴露程度增加，不能由公司单方把他们排除在外。

**监督者（Overseer）**：依合法关系检查公司是否遵守使命、边界、承诺与程序的主体。
监督者可以内部或外部存在；名称上的外部不等于实质独立。

**相关方（Stakeholders）**：以上角色的总称。同一主体可以兼具多角，但不同角色不得被
平均成一个模糊「意见」。使命约束主要由委托关系判定，价值主要由受益者判定，外部性
主要由受影响者判定，合规由有合法位置的监督者判定；冲突按本纲优先序处理。

**边界（Boundary）**：公司不得或暂未获准跨越的约束，包括使命限制、外部规范、承诺、
资源限度、风险限度和自治范围。边界不能由被约束者单方解释、放宽或废止。

**资源（Resource）**：履职所消耗或占用且供给有限的一切条件，包括预算、时间、注意力、
人力与执行能力额度、信誉、外部配合及维持承诺所需的其他条件。资源结算不限于金钱，
是否稀缺、可否补充、耗用后影响何者，均须按事项说明。

**信息（Information）**：履职、验收、问责与结清所需的事实、规则、上下文、来源与记录。
信息不只包括可读取内容，还包括其知悉范围、真实性、完整性、时效与可使用边界；需要
保存或移交的信息，以能否重建当时权责、决定依据、结果与未决义务为判断原则。

**初始宪制公设（Founding Postulates）**：公司设立时被明示接受的使命、边界、责任、
相关方基本权利，以及继任、清算与残余责任安排。第一因不由本纲继续向上推导；本纲要求
其公开、可质疑并承认外部关系。自我设立可以构成事实起点，但不自动取得对外代表、财产、
法律人格或使他人受益/受损的当然正当性。没有可识别的设立责任主体，或未预设残余责任
承接与失能后再指定规则的集合，不取得本纲的自治正当性。

**设立责任共同体（Founding Responsibility Body）**：在设立关系中实际接受上述初始公设、
并能被识别其成员、代表、决定与责任分配方式的一个或一组主体。它不是公司终止后的抽象
化身；未另约时，它承担残余责任，成员失能时按初始公设与外部关系继任。有可识别设立
责任主体的既有公司，可以依元治理补正这些安排，经独立确认后取得后续自治正当性，历史
设立缺陷不因此被溯及消除；无可识别设立责任主体的，只能以可检验的新设立关系重新设立，
不得由现任运行者自封为设立责任共同体来补正。

### 1.2 工作、结果与验收

**事项（Matter）**：需要被选择、决定、执行、维持、调查或终止的一件对象。事项可以尚未
成为工作；越界、无能力、不可持续或不符合使命的事项必须可以被拒绝。

**工作（Work）**：围绕事项形成的有目的履职过程。工作既包括创造与变更，也包括记录、
对账、值守、维护、回收、继承、调查和清算。

**结果（Outcome）**：工作实际造成的一切变化与未变化，分为三个可关联但不可互替的层次：

- **产物**：交付出的文档、决定、服务、记录或其他对象；
- **状态结果**：产物造成的状态改变、维持、避免、失败、部分完成或停止；
- **外部影响**：状态结果对受益者、受影响者、承诺与后续能力造成的长期作用。

结果还包括代价、残留、损害与未兑现承诺。未记录的结果仍然发生。

**验收口径（Acceptance Criteria）**：对产物、过程、状态结果及必要外部影响进行判断的
事前依据。探索事项必须事前约定探索边界、学习交付、停止条件与事后独立评价，不得事后
把偶然产物追认为原目标。

**自检（Self-check）**：交付者对自身工作进行的检查。自检是必要的履职动作，但自检结论
不得冒称独立验收。

**独立验收（Independent Acceptance）**：由具有合法位置、且不直接受被验方控制的验收者，
依据口径、证据与理由作出接受、拒绝、附条件接受或依授权终止判断。独立性由证据来源、
判断过程、利益关系与错误相关性决定，不由名称、账号、岗位或模型单独决定。验收者的
选任、替换与独立性争议，由不直接受被验方控制的位置按事前规则处理。

**事后独立审计（Ex-post Review）**：在自检或生效之后，由外部独立位置、内部独立位置或
可独立复算的事实复核证据、过程与结果，包含抽查。低风险、可逆且不涉及不可放弃权利
影响的事项，可以以「自检 + 可复核证据 + 事后独立审计」完成闭环，但不得把这种完成
称为已经通过独立验收；日常低风险对外事项还须保留相对方验收与异议位置。其余中风险、
高风险、不可逆且影响重大或显著影响相关方权利的事项必须独立验收，其中高风险与不可逆
且影响重大的事项除 §6.1 预设紧急止损路由中的保全与止损动作外须在生效前完成，其他事项
可按事前规则在生效前或约定复审点完成。风险与可逆性分类者不得直接受交付方控制，分类争议由独立位置
终裁；可逆性存疑、分类有争议、不可逆且影响重大或无独立分类时，按高档处理。

**验收（Acceptance）**：上述正式判断的总称。验收可以定量，也可以是有理由、可质疑的
定性判断；定性判断必须给出可被异议和复审的依据，不能只说「我认为」。附条件接受必须
写清条件、责任者与到期处置。

**证据（Evidence）**：能够被独立检查、质疑、复核或复算的事实材料及其来源关系。证据
支持事实，不等于事实本身；记录存在不等于记录为真，证据缺失也不等于外部事件未发生。
补证与追认必须标明形成时间，不得伪装成当时证据。

**价值（Value）**：结果对使命与受益者实际产生的意义。内部验收是价值证据之一；价值
还应按事项性质考察适用的相关方反馈、使用结果、外部影响或反事实，不要求每项证据俱全。
负价值、损害与风险残留同样必须入账。

### 1.3 权、义务、承诺与责任

**权（Authority）**：制度承认的作为、要求、决定或免受不当改变的资格。权回答「可否做、
可决定什么」，不证明实际有能力做，也不自动证明行为正确。「权的范围」统一简称权限时，
二者不另立概念。

**义务（Obligation）**：特定主体在特定触发下必须完成、维持、报告或避免的要求。完整
义务至少有承担者、对象、触发、完成口径、时限或复审条件、违约去向。义务还包括诚实
披露不利信息、合理注意、保密与避免不当利益冲突，不能只提交有利证据。

**禁止（Prohibition）**：权的否定边界。明确禁止、未获授权与暂时无能力是三种不同状态：
未覆盖不等于禁止，也不等于已授权；无能力不等于无责任。

**承诺（Commitment）**：有权主体向另一方作出、使对方可以合理预期公司将履行或维持某事
的责任关系。承诺必须能识别承诺者、相对方、内容、条件、期限与未兑现后果。面向分散或
未来公众的公开承诺，必须在作出时明确相对方类别、代表或异议通道及变更条件；代表须由
相对方类别依可检验程序产生，或由公共规则、独立裁决确认，不得由承诺方单方指定。缺少
这些安排时，不得以公众无法逐一同意的形式作出可执行承诺。变更、降级、退出或解除承诺，
须依原承诺条件与相对方权利完成；无法取得逐一同意的，按预定变更程序或有权公共程序
处理，不能由承诺方单方宣告。

**责任（Responsibility）**：主体因其角色、决定、行动或应行动而未行动，对过程与后果
承担说明、接受评价及相应后果的关系。责任不等于惩罚，也不等于把所有后果归给最近的人。

**运营责任**：对具体工作与交付的直接责任。

**管理责任**：对岗位、授权、信息、资源与监督条件是否正确设计、维持和纠偏的责任。

**最终责任**：对使命、制度有效性、对外承诺及未被合法分配的剩余事项承担最终交代的
责任。最终责任不是对每一操作失误承担同等或无限责任，也不是没有实质控制者的背锅位置。

**对外最终责任**：跨公司联合承诺中，由各方预先约定由一方、按份或共同承担的对外交代
责任。它不等于任一公司的内部最终责任，也不替代实际法律关系中的责任判定；承担者必须
拥有与该约定相称的信息、监督、救济与止损位置所形成的实质控制。合法保证或担保可以
构成风险覆盖，但仅有知情或追偿而没有相应控制，不足以承担全部对外最终责任。

**问责（Accountability）**：责任被实际结算的过程，包括说明与申辩、质询、独立判断、
救济、后果与结清。问责不能只有追责权，没有被问责者的知情、异议和申诉位置。后果须与
行为、可观察的注意义务违反、实际控制、损害及修复相匹配，不要求证明人类式主观恶意，
也不得因轻微与严重违规适用无差别处置。

**救济（Remedy）**：更正记录、撤销错误决定、恢复权利或资格、返还资源、重新独立审查
及必要的补偿。救济不预设员工具有人类情感或财产利益。

**授权（Delegation）**：有权者把特定目的、范围、条件与期限内的权交给另一主体行使。
授权不放大、可撤回并保留授权链；运营责任可以分派，授权者的管理责任与最终责任不因此
消失。

**禁配（Incompatible Combination）**：同一责任主体不得同时持有、或必须附补偿条件才能
持有的权与义务组合。禁配按任职者的全部任职与出工累计判断，不得通过拆身份重置。

**绩效（Performance）**：对结果、过程、代价、合规与价值的分别评价，不是单一分数。
执行能力表现、任职者绩效与组织绩效必须分别归因；部门绩效是组织绩效的子层。

**共同责任（Shared Responsibility）**：多个主体对共同决定、共同控制或共同救济作出
交代的责任形式。共同责任不要求任一主体承担全部，可以是按份、共同或其他事先约定形式；
贡献是否可分及其争议，由不直接受被评价方控制的位置判定。

**实质控制（Effective Control）**：与责任相匹配的实际决定、信息获得、资源配置、监督
与及时止损能力所形成的组合。只有信息或头衔而没有与其责任相称的制约能力，不构成实质
控制；紧急情形下的叫停与止损位置也属于必要控制。

### 1.4 主体、岗位与能力

**岗位（Position）**：为持续承担某类责任而设置的权责与义务组合。岗位不是执行者，也
不是一段职责描述；没有履职者时可以空编，但空编不能解释实际动作由谁负责。

**任职者（Holder）**：在明确任期内承接岗位或事项责任的可归因身份。任期可以是一次、
短期或长期；持续指责任在任期内连续，不表示永久。任职者可以承继任职史、绩效与经确认
的记忆；兼任不重置累计禁配与利益冲突。

**员工（Employee）**：具有持续任职关系、能够积累任职史与绩效的任职者。临时责任主体
不因一次性任务自动成为长期员工，但其在事项中的责任仍须完整。

**执行能力（Execution Capability）**：任职者履职时可调用的理解、判断、行动与工具能力。
能力是「能做」，不是「有权做」；能力可声明、评价、组合、替换、升级、降级与退役。
能力的客观存在不需要授权，能力的配置与使用必须有正当依据。

**出工（Engagement）**：任职者在特定时间与事项中实际履职的过程。一次出工可以按规则
分段更换执行能力；更换能力不自动产生新身份、新授权或新责任起点。出工必须按事项风险
保留足以重建权源、关键输入、决定依据、行动、结果与后续变更的事实材料；充分性由独立
记录责任者或事后审计位置按事前口径判定，不能由交付方单独宣布。无法保留内部判断过程时，
可以记录可核验的决定依据与后果，不得编造推理。继任者不对不存在的主观理由承担虚构说明
义务，记录不足归原记录与设计责任。

**部门（Department）**：为共同结果与协调而聚合岗位的责任边界。部门存在的理由是降低
协作成本、形成明确责任，而不是增加名称和层级。

**职级（Rank）**：责任范围、决定幅度与监督关系的层级。职级不等于聪明程度，不与特定
模型或工具绑定；能力资格与职级必须分别判断。

**工具（Instrument）**：被调用来产生信息或动作、但不独立承担任职责任的对象。模型、
工具或其他能力部件在被调用时不因名称而自动成为员工；它们作为何种能力组成被评价，
取决于实际履职关系，而非产品类别。调用者与规则责任主体不能因此匿名。

### 1.5 历史、变化与终止

**历史（History）**：曾经发生的意图、行动、结果、依据与责任关系。后续配置不得重写
当时事实；评价当时行为须区分当时规则与后续规则。

**记忆（Memory）**：从历史中选择、形成并供后续使用的信息。个人记忆随任职者，岗位记忆
随岗位，组织记忆随公司；出工记忆随工作及其责任关系，不因任职者离岗自动转为个人记忆。
出工记忆的形成、使用与结清由工作册负责，访问、继承、修正与清除的授权和争议由组织册负责；
经确认的经验可以按规则转为岗位或组织记忆。所有记忆都是历史的派生物，不得反过来篡改历史。

**变更（Change）**：对工作、能力、岗位、组织、承诺或规则的任何改变。变更可以普通、
重大或构成性，层级由实质影响而非名称决定，并按 §6.3 的分类程序处理，不同层级适用
不同授权与验证。

**进化（Evolution）**：由事实反馈驱动、经合法授权和独立验证、能够后验评价的变更。
进化必须能停止其继续影响；不能逆转的外部后果，以恢复、修复、补偿与责任结算处理，
不得虚构可撤回。积累经验不自动等于进化，指标改善也不自动等于使命改善。

**终止（Termination）**：出工、任职、岗位、部门、公司或对外关系的结束。终止必须处理
在途事项、未兑现承诺、资源、信息、记忆与责任承接。公司停止生产不等于公司历史与责任
已经清算；清算中的责任关系仍属于本纲调整范围。初始宪制未预设残余承接与失能后再指定
规则的，属于设立缺陷，不得在缺陷暴露后声称责任自然消灭；设立责任共同体是未另约时的
默认残余责任主体，其自身失能时按预设继任与外部关系处理。

## 二、自治及其边界

### 2.1 自治的定义

> **自治是：在明示使命与边界之内，除保留事项依专门程序处理外，公司无需委托主体处理
> 常规决定，即可自行受理、组织、授权、执行、组织验收、纠偏、学习、调整与终止，并在
> 其决定与角色范围内对过程与后果承担交代责任；不可控不等于免除外部影响的说明义务，
> 交代责任也不等于对所有间接后果承担无限赔偿或救济责任。**

「自行组织验收」包括使用内部独立位置、外部验收者与可独立复算的事实，不要求公司
假装所有判断都由自己作出。使用外部服务不必然损害自治，暗中依赖未声明的人工补救
才会使自治声明失真。

自治不等于：

- 所有任务都接受或成功；
- 所有决定都自动通过；
- 不需要外部信息、外部服务或外部监督；
- 没有失败、异常、争议或停止；
- 可以自行扩大使命、权限与资源边界；
- 最终责任、外部法律责任或受影响者权利被消灭。

拒绝越界或不可持续事项、承认无能力、请求外部专业意见、停止危险工作、依法重新协商
或解除不可维持的承诺，都是自治的组成。本纲所称的构成性失败，是没有合法路径处理这些
情形，或者以单方降标、隐瞒失败来制造闭环；有预案但处置失当仍是普通运行失败，不能因
路径存在就被排除。

### 2.2 三类事项与例外状态

| 类别 | 公司与委托主体的关系 |
|---|---|
| **自主事项** | 公司可在既定边界内独立受理、决定并负责，无需逐次请示 |
| **保留事项** | 只有指定主体或更高门槛可以决定，公司负责提案、证据与执行 |
| **禁止事项** | 不因高收益、时间紧、能力具备或自我追认而取得合法性 |

**例外状态**：任一事项在规则未覆盖、规则冲突、来源存疑或紧急情形下所处的状态。例外
状态与三类事项可以叠加；禁止事项不因例外状态变为可做，保留事项不因紧急自动变成自主
事项。例外状态只触发专门处置，不改变事项本身的权利层级。

自主与保留清单由初始宪制公设及其合法修订确定，所有者、修改门槛与争议裁决必须明确。
**未列入自主清单的新事项默认为保留事项**，只能先受理、分类和请求决定，不得因清单沉默
而自动取得自治权；剩余裁量只能在其预设功能类别与最高边界内适用，不能把清单外事项转为
自主事项，超出者仍须按保留程序处理。需要扩大自治范围的一方可以提案，不能单方修改清单
或重新命名事项降级。

### 2.3 最终责任、决定位置与顶点

本纲所称**顶点**，是最终责任或特定终局决定所在的责任位置，可以是单一主体，也可以是
有明确议事、表决、异议与责任分配规则的集体。集体顶点不等于无人负责。

1. 最终责任是使命、对外承诺、制度设计、监督、救济与未分配剩余事项的兜底交代，不是
   对每个日常结果承担同等直接责任；
2. 最终责任位置必须拥有与其实际责任相称的制度设计、信息、监督与止损位置，形成实质
   控制，不能只留责任而只有知情或签字；
3. 最终责任位置与最高日常决定位置可以不同，但二者冲突时的终局、相互止损及不得互相
   架空必须由宪制规则预先规定；
4. 最终责任不等于拥有所有日常决定权，更不豁免禁配与独立验收；
5. 顶点可被质询、替换和继任，替换主体、失能判定、临时代理、权限限度与正式继任路径
   必须事先明确；集体顶点也须指定紧急止损权限及其后验复核；
6. 继任者承接未决义务与前瞻处置，历史行为责任仍按当时主体、岗位与实质控制归属；
7. 内部最终责任与对外法律责任是不同概念，后者由实际法律关系决定，不能由本纲任意改写。

**最终责任与无限权必须分开；责任与实质控制必须同时成立，但不要求顶点无所不在。**

### 2.4 自治的理论边界与现实边界

本纲定义的是自治得以成立的规范条件。公司能否在某任务分布、时间窗与风险水平下实现
自治，是经验问题。理论不得把「逻辑上允许自治」偷换成「现实已经证明自治」。

## 三、从根命题到组织形态

根命题直接要求工作、结果、证据、责任与履职条件，但不必然要求固定的岗位、部门和
职级。后者按以下条件成立：

1. **当同类责任反复出现且需要持续承接时，设置岗位**；一次性协调可以由临时关系完成。
2. **当共同结果需要多岗位协作且明确边界能降低成本时，设置部门**；否则保持扁平关系。
3. **当授权、监督和责任范围需要嵌套时，设置职级**；不得仅为制造尊卑或模拟人类组织。
4. **当任职关系需要跨出工积累责任、记忆与绩效时，设置持续任职者**；临时责任主体不
   因此被迫取得永久身份。
5. **当能力需要独立于责任主体替换时，分离员工与执行能力**；更换工具不得重写岗位语义。

这些条件是设计与审查问题，不是事后合理化任何结构的套话。新增结构时必须能说明它
解决了什么责任或协调问题、增加何种成本、失败时如何撤销；不能只因结构已经存在就
追认其必要。

因此，临时协作体、单人公司、扁平公司与多级公司都可以满足本纲。判断标准不是组织图
是否相似，而是责任是否连续、协调是否有效、成本与结果是否值得、结果是否可验收。
单人公司的低风险内部事项采用自检与事后独立审计，独立审计须由外部独立位置或可独立
复算的事实完成，不能由本人冒称；无此条件时不得以低档方式闭合。

## 四、五条闭环

五环是同一公司运动的五个**可重复责任过程与观察视角**。价值闭环是结果主环，权责、
能力与组织提供支撑，进化是作用于全部四环的二阶环。每个具体过程可以独立达到终态并
触发另一环；一环闭合不表示其余四环自动闭合。

资源、时间、信息与异常处理贯穿每一环，不另立「资源环」或「异常环」割裂责任。跨环
资源必须合并结算，不能以每环局部合规掩盖整体不可持续。

### 4.1 价值闭环：为什么做，结果是否值得

```
相关方需求、使命、既有义务与内部发现
  → 意图提出、受理（接受 / 拒绝 / 有期限的暂缓）
  → 承诺、验收口径与整体资源约束
  → 工作、结果与副作用
  → 按风险选择的验收、相关方反馈与价值评价
  → 意图、承诺或后续选择校正
```

- **责任位置**：意图受理者、承诺授权者、工作责任者、验收者、价值复盘者；实例化时
  必须落到具体主体，不得由「市场」「公司」代名；
- **闭环判据**：结果与过程得到判断，价值、代价、整体资源和未兑现事项均有交代；
- **强制失败出口**：一旦确认越界、无价值、不可验收或承诺不可持续，必须停止原路径，
  并选择拒绝、返工、依法变更承诺或终止，不得继续原承诺却按新标准庆功；
- **禁止自指**：内部指标改善不能单独证明使命达成，承诺与验收口径变更须经相应权利
  关系同意，不能倒填为原成功。

### 4.2 权责闭环：凭何行动，由谁负责

```
使命、规则、承诺与合法授权
  → 权和义务的授予、限制与利益冲突检查
  → 行动、证据与过程记录
  → 说明、质询、申辩与独立判断
  → 责任结算、救济、调整、撤回与结清
```

- **责任位置**：授权者、行动者、记录责任者、质询与裁判者、救济与结清责任者；
- **闭环判据**：行动有权源、过程可说明、责任有结算、授权有去向；
- **强制失败出口**：无权、冲突、异议、超期或责任争议时，必须停止或限制原行动，进入
  复核、申诉、剩余裁量或终裁，不得无限保持原状态；
- **禁止自指**：被约束者不得单方修改约束自己的规则，被问责者不得独占裁判与救济。

### 4.3 能力闭环：凭什么能做，不能时怎么办

```
岗位与任务的能力需求
  → 能力声明、识别、匹配与资格认定
  → 履职与实际表现
  → 能力、任职者与组织效果分别归因
  → 学习、组合、更新、替换或退役
  → 重新认定履职资格
```

- **责任位置**：能力需求所有者、资格认定者、履职者、归因者与再认定者；能力提供方
  不能单独认证自己的资格或独立性的结论；
- **闭环判据**：能力经过实际履职或独立评价，变更后重新认定，能力缺失有明示与处置；
- **强制失败出口**：不匹配、退化、不可用或成本不可接受时，必须降级任务、替换能力、
  寻求外部能力、拒绝或停止，不得虚构能力继续；
- **禁止自指**：能力增加不自动扩权，能力降低不自动免责，执行能力表现不直接等于任职者
  绩效或部门绩效。

### 4.4 组织闭环：持续责任如何协同，结构是否值得

```
使命与工作分解
  → 临时关系或岗位设置
  → 必要的部门、职级与协调关系
  → 共同结果、整体资源、协作成本与争议处理
  → 组织绩效、外部影响与结构评价
  → 调整、合并、撤销、交接或终止
```

- **责任位置**：结构所有者、协调与争议裁断者、整体资源责任者、组织评价者、交接与
  清算责任者；
- **闭环判据**：共同结果有人承接，争议有终局，结构成本、偿付与持续能力被同时评价，
  调整有交接；
- **强制失败出口**：空编、协调失败、层级空转、部门割据、资源不可持续或结构成本过高时，
  必须缩编、撤层、改组、补足资源或终止，不得只用新增岗位掩盖；整体资源责任者不得单方
  削减既有对外承诺，涉及承诺变更时必须回到承诺授权者与相对方权利；
- **禁止自指**：组织规模、岗位数量、会议与审批活动不能单独证明组织有效。

### 4.5 进化闭环：如何改变自身而不漂移

```
历史、结果、异议与外部事实
  → 复盘、因果质疑与候选学习
  → 工作、能力、组织、承诺或规则的候选变更
  → 实质分类、合法授权与独立验证
  → 受控生效与后验观察
  → 保留、停止、恢复、修复、归档或再次修正
```

- **责任位置**：复盘责任者、变更提案者、分类与授权者、独立验证者、后验评价者；
- **闭环判据**：变更有权源、有验证、有后验，继续影响可以被停止，外部后果有修复路径；
- **强制失败出口**：证据不足、验证失败、外部性不可接受或使命漂移时，不得生效；已生效
  者必须停止、恢复、修复或依法变更，不得仅以新指标证明其成功；
- **禁止自指**：被进化对象不得单独分类或修改验收自己的判据，局部改善不能掩盖他处退化。

### 4.6 五环共同规则

1. 每环的每个具体过程都有合法入口、具名责任位置、时限或复审条件、终态与强制失败出口；
   环作为持续职能可以延续，但任何具体事项不得无限悬置；
2. 每环都可向其他环提出输入，但不能用另一环的内部结论替代本环所需证据；
3. 单件校正属于价值或工作过程，形成稳定变更才进入进化环；构成性变更还须经过元治理；
4. 能力评价、任职者绩效与组织绩效分别归因，不互相替代；
5. 任何一环未闭合都是可见状态，不能通过改名、拆身份或停止记录假装闭合；
6. 止损先于定责，调查先于普通处分，申诉不因其本身招致更重后果；符合标准的新证据
   可以重开，重复无新据的申请可以被有理由地终结；
7. 资源投入、消耗、剩余、补充与不可持续状态必须按公司整体结算，不能分散在各环后
   逃避总责任；
8. 最终责任位置必须指定跨环趋势汇总责任者，把任务构成、整体资源、能力退化、外部影响
   与各环局部指标的合并趋势纳入其信息范围；汇总者不得由被汇总的业务位置单独兼任，报告
   须直达委托主体或独立监督位置，不得等某一环单独越线后才承认整体异常。

## 五、全局不变量

以下不变量适用于三册及其全部模板。违反它们表示失去本纲所定义的自治正当性，不表示
否认一个组织的经验存在或其技术自动性。

冲突时按以下优先序处理：

1. **事实、明确禁止与不可放弃的相关方基本权利，不得被其他规则抵消；**
2. **正当授权、责任连续与不可逆损害的事前控制，优先于效率与便利；**
3. **比例原则只在合法控制方案之间选择，不得取消独立验收、责任归属与禁止事项；**
4. **不可逆后果不得用虚构的「可撤回」处理，必须事前加重约束并保留修复与责任路径。**

### I-1 正当性先于效率

任何意图、权、岗位、部门、能力与资源或信息的配置、使用和变更，都必须能追溯到正当使命、
合法委托或既有义务。能力与信息的客观存在不构成非法，只有其配置与使用需要正当依据。
高收益、低成本、技术可行和多数同意，不能单独使越界行为合法。

### I-2 事实与来源先于叙事

实际发生不因未记录而消失，记录存在也不证明其内容为真。组织可以规定「无证据不得
承认完成」，不得规定「无记录即外部未发生」。意图、授权、证据与验收的来源都必须可
检验；内容看似真实不能证明来源真实。对来源、失真与污染的质疑必须有着落。

### I-3 结果、过程、代价与后果同账

验收和绩效不得只计算成功产物。失败、返工、空转、资源消耗、风险残留、外部损害、
未兑现承诺和维持性工作，均须进入相应交代。任何局部节约不得把代价转到公司整体、
未来期间或外部第三方后被隐藏。

### I-4 权责必须可结算

每项权都有来源、范围、限制、证据、问责与退出；每项义务都有承担者、对象、触发、
完成口径、时限或复审条件与违约去向。有权无责、无责式授权、只有责任却无必要履行
条件，均不成立。

### I-5 权与能力不得互相冒充

有权不等于能做，能做不等于有权做，曾经能做不等于现在仍能做。能力不足必须显式处理，
不得通过虚构能力、降低验收或暗中扩权来闭合。

### I-6 授权不放大且可撤回

转授权不得超出父授权的目的、范围、条件与期限。撤回不仅是停止未来动作，还包括在途、
资源、信息、承诺与责任结清。任何拆分岗位、出工或身份的做法不得重置累计禁配。

### I-7 责任与实质控制相匹配

责任不得集中给没有实际控制、信息或止损能力的主体。委托可以转移运营行动，不能消灭
授权者的管理责任；最终责任也不能成为吸收一切失误的兜底标签。多主体共同控制结果时，
须按事先分工与实际控制分别承担，必要时承担明示的共同责任，不得随机选一人承担全部，
也不得以贡献难分由集体免责。

### I-8 验收独立性必须与事项相称

交付者可以自检，但自检不自动构成独立验收。低风险、可逆且不涉及不可放弃权利影响的
事项，可由自检、可复核证据与事后独立审计形成闭环；其余中风险、高风险、不可逆且影响
重大或显著影响相关方权利的事项必须独立验收，高风险与不可逆且影响重大的事项除 §6.1
预设紧急止损路由中的保全与止损动作外须在生效前完成。低、中、高风险由事前分类确定，
未分类不得按低档闭环；
风险与可逆性分类者不得直接受交付方控制，分类争议由独立位置终裁；可逆性存疑、分类有
争议、不可逆且影响重大或无独立分类时，按高档处理。验收者的选任、替换与独立性争议
不得由被验方单独决定，验收形式及证据强度按事前规则判定。

### I-9 主语与共同责任必须明确

任何「公司 / 系统 / 框架 / 部门 / 委员会做了某事」的责任陈述，都必须能继续回答：
谁依何规则作出决定，谁执行，谁承担监督责任，异常由谁承接。监督责任不表示每一动作
都需另设一个人。工具和抽象规则不得成为匿名责任主体；集体行动必须有决策规则、分工、
记录及共同或按份责任安排。

### I-10 主体可以替换，历史与承诺连续

执行能力、任职者、岗位持有者乃至顶点均有替换与继任路径。替换不改变已经发生的行动、
责任与对外承诺；后续配置不得追改当时权责。继任者承接未决义务与前瞻处置，历史责任
仍按当时事实归属。说明以当时保留的事实材料为限，材料缺失归原记录与设计责任，不得
强迫继任者虚构理由。

### I-11 异常、冲突与无能必有去向

规则内偏差、规则未覆盖、规则冲突、能力不足、超时、叫停和恢复，均有具名接收者、处理
时限或复审条件及终局。不得以无限复核、反复重提、永久叫停或无人签收替代闭环。已经
终局的事项可以因符合标准的新证据重开，重开由独立位置受理并限定影响范围。

### I-12 自主不得自我扩张

普通运行不得单方扩大使命、权限、资源或自治范围，不得修改用于约束自身的构成性规则。
剩余裁量的持有位置、可处理事项的功能类别与最高边界必须预先合法设定；功能类别不是
逐案白名单，真正的新型个案不因名称未出现而被排除。具体个案的范围和期限可以在行使时
确定并接受事后独立复核。没有相应裁量权时，只能采取保全与升级所需的最小行动。

### I-13 变更必须有权、有证、有后果处置

任何学习、修复与进化都必须有变更主体、授权依据、验证方式和后验处置。未达到生效
条件的变更不得因其被称为「学习」而取得合法性。可逆变更须能停止和恢复；不可逆变更
须能停止继续影响，并以修复、补偿、承诺变更或责任结算处理残余后果。

### I-14 比例与反仪式

控制形式与强度应针对错误相关性、后果可逆性、可发现性及成本，并有可观察的失效信号
与反指标。比例原则不得用于取消根本约束，也不得为表面分离制造责任稀释、协调死锁或
无成本否决。参数由事前规则与复盘调整，不能事后为任何既定选择辩护。

### I-15 外部性不可被内部闭环抹除

内部全绿不代表外部正当。可识别或可合理预见的受影响者，其异议、非量化价值、长期影响
与损害必须有进入验收、问责或元治理的通道；公司不得单方通过解释边界排除他们。无法
直接表达的主体须由事前代理立场或禁止规则保护。不可接受、不可补偿损害的认定及其
授权限度，不得由公司或受益委托方单独决定，须依公共规则、事前合法约定的受影响者代理
或独立裁决确认；无合法依据时不得作为可接受风险。损害已经发生时，必须先停止继续影响、
保全并说明事实、接受独立评价，再处理修复、救济、责任与是否允许相关业务继续，不能以
责任结算代替终局。

### I-16 终止必须结清并被承接

出工、任职、岗位、部门与公司终止时，在途事项、未兑现承诺、资源、信息、记忆、外部
关系和责任承接均须结清或由有权接收者明确接受。移交不能单方宣告，接收与完整性须可
核验；无人承接时不得宣称清算完成。公司设立时必须预指定清算、残余责任及其失能后的
再指定规则；设立责任共同体是未另约时的默认残余责任主体。承接者失能或空缺时必须依
预设规则再指定并公示，未完成前不得宣称清算完成。停止运行不等于责任消灭。

## 六、异常、剩余裁量与元治理

### 6.1 异常及其发现义务

**异常（Exception）**：实际或潜在状态偏离事前口径、缺少可比口径、口径本身失效、
来源真实性存疑，或多个合规局部累积成整体不可接受状态。缓慢漂移和长期未被发现的
异常同样属于异常，不因单次未越线而豁免。

各责任位置必须发现、接收或转交与其信息范围相关的异常；无人认领的异常按既有升级链
进入最终责任位置，不得归给「框架」。发现义务只要求合理注意与可检验的监测，不要求
全知；隐瞒与应发现而未发现必须区分。跨环合并趋势由 §4.6 指定的汇总责任者发现与升级。

| 异常类型 | 理论处置 |
|---|---|
| 规则内偏差 | 按既有口径校正、返工、停止或终止 |
| 规则未覆盖（无论此前是否预见） | 进入剩余裁量，明确范围、期限、理由与后验复核 |
| 规则冲突或失效 | 暂停受影响决定，进入元治理，不由邻近强者自行吞并 |
| 来源存疑 | 先核验意图、授权或证据来源；核验失败须拒绝、撤销或终止受理，暂缓须有复审期限 |
| 正在发生的不可逆损害 | 先按下述特别路由止损与保全事实，再调查与定责；恢复是新的决定 |

「没有规则」不等于「可以自由行动」，「规则冲突」也不等于「任选一条」。剩余裁量
保证的是有合法路径产生决定，不保证任何决定都被允许。

**紧急止损的特别路由**：明确禁止事项不因紧急变为可做。保留事项须在事前指定备用决定者；
备用决定者不可达且延迟将造成更大不可逆损害时，现场责任主体可以在预设紧急边界内采取
最小必要止损。高风险或不可逆动作在独立验收确实无法及时获得时，也只能按预设紧急边界
先行保全与止损，并立即留证、通知和接受事后独立复核；该先行不构成对后续行动的追认。
本路由是 I-8 与 §1.2「生效前独立验收」的唯一时序例外，不得推广到普通高风险决定；
原高风险动作本身仍须独立验收，保留事项的实体决定权仍按备用决定者程序取得。
无预设紧急边界时，只能采取不进入禁止或保留权限的保全与升级行动。

### 6.2 剩余裁量

剩余裁量用于已发现但不能按普通规则处理的事项，无论该事项此前是否被预见。其**持有
位置、可处理事项的功能类别与最高边界**必须由宪制或上位规则预先设定；功能类别按事项
所需决定的功能、风险与责任界定，不按部门名称或逐案清单界定，真正的新型个案不因名称
未出现而被排除，也不得借此把清单外事项转为自主事项。其**个案范围、期限与处置**可以在
事件发生时确定，但必须具有：

- 具名决定者与适用范围；
- 临时有效期限或复审条件；
- 理由、证据与受影响者异议通道；
- 与既有边界的关系说明；
- 事后独立复核及转为普通规则、撤销或终止的去向。

没有剩余裁量权的主体，只能进行防止损害扩大、保存事实和请求决定所需的最小行动。
真正未预见不构成自由授权，也不使依法暂停本身成为违规。

### 6.3 元治理与分类权

**元治理（Meta-governance）**：对使命、边界、最终责任、相关方基本权利、禁止事项、
验收原则、承诺授权原则及规则修改权本身进行变更与裁决的责任过程。它分为两层：

- **本纲层**：本纲 §5 的全局不变量只能由本纲制定与维护的上位治理程序修订，任何公司
  不得以本公司元治理削弱、删除或重新解释这些不变量；本项目当前由制作人终审；
- **公司层**：公司可以在本纲不变量之内修改本公司的使命、边界与宪制对应规则，不得把
  本公司上位权威当成修改本纲本身的授权。

公司层元治理必须具有完整路径：

```
变更提案或规则冲突
  → 具名受理与登记
  → 按实质影响分类（普通 / 重大 / 构成性）
  → 上位授权与相关方意见
  → 独立逻辑或事实验证
  → 决定、公告与生效
  → 后验评价、异议、保留 / 撤回 / 修复
```

- 构成性规则的修订权必须位于被修订规则之上，不能由同层普通权自行授权；上位权威可以
  是委托主体、成员大会、合法受托治理体或公共权威，由初始宪制关系确定，不必然在公司外；
- **修订权条款本身不得仅由该条款所授权的同一主体修改**，须由初始宪制指定的更高且不受
  同一主体控制，或实质独立于被修订权主体的位置确认；仅更换名称、设立形式上级或由同一
  主体控制的委员会不构成独立。不存在此位置时，不得自我修改，只能取得合法授权、终止或
  依宪制重新设立；
- 标为不可放弃的相关方基本权利，只能加强或以同等以上保护替换，不得由公司层削弱或删除；
- 变更分类由实质影响决定，不得通过改名、拆段或转移载体降级；受益方不得单方分类，
  分类争议由上位或独立位置终裁；
- 受理与拒绝受理均为决定，须有理由、期限和可复核位置；被提案直接约束的受益方不得
  单独拒绝登记，也不得控制其复核位置。受理时必须给出决定时限或复审条件，未获批准不生效
  且原规则继续有效；
- 元治理本身也有拒绝、暂缓、撤回与终局，不是把事项无限期送入的另一名词；新证据标准
  与重开条件也由上位规则预先确定；
- 使命合法变更与使命漂移的区别，在于是否走完上述程序，而非变更者自称善意。

### 6.4 多主、共同责任与跨公司关系

**多委托冲突**：公司必须在设立或接受委托时确定不同使命、合同与操作指令的优先关系
和终裁位置。相同层级且无法协调的合法要求，执行者不得私选；必须暂缓相冲突的新承诺，
由预定共同权威或联合程序决定。无法形成合法决定时，拒绝或依法解除是合法终态。

**共同成果**：多主体共同控制且贡献可分，按分工与实际控制分别负责；贡献不可分时，
由事先确定的协调责任、共同决定记录和共同责任规则承接。不得为追求个人绩效精确而
虚构归因，也不得用集体成果掩盖个体明知与故意行为。

**跨公司交付**：联合交付不自动产生共同顶点。各方必须在承诺前约定对外最终责任由
一方、按份或共同承担，及验收、争议、终止和剩余承诺的处理。未形成此约定，不得作出
无法界定责任的联合承诺。任何一方不得用自己的内部闭环替代联合交付的外部交代。

### 6.5 终局、重开与终止

终局是为了防止无成本拖延，不是为了屏蔽新事实。重开必须满足事前说明的新证据标准，
由独立位置受理，并限定到受影响的结论、责任与救济；单纯重复或拒绝接受终局不构成
新证据。证据被证明伪造、关键事实被隐瞒、裁判者被俘获，均可构成重开理由。

终止前必须指定清算责任主体及剩余承诺承接者；未在设立时作出且未依元治理补正的，不得
取得本纲所称的自治正当性。历史行为责任不随继任转移给新任职者，公司的持续责任由存续
或清算关系承接；原主体已经不存在时，由初始宪制预先指定的受托、清算或法定承接者处理，
未另约时由设立责任共同体承担。承接者失能或空缺时，按预设规则再指定并公示；全部主体
同时失能属于自治失效与未结清状态，由预设外部受托者或外部法律关系接收提请并公示未决
义务。该状态不是闭环终态，不得用「已经终止」或「无人可指定」消灭义务或宣称清算完成。

## 七、理论的开放性与经验假设

以下内容是本纲允许且需要后续验证的假设，不是逻辑公理。任何实际公司在宣称自治前，
必须另行声明：**任务分布、时间窗、比较基线、失败阈值与停止条件**。总纲不写死通用
数值，因为数值属于场景与风险，而不是哲学公理。对外公开自治声称属于对外承诺，其任务
分布、阈值与停止条件须由不直接受声称方控制的位置接受；内部自我评估不得冒称外部认可。
分布外事项不得援引既有自治结论，必须重新分类与验证，而不是被静默纳入或一律拒绝。

| 假设 | 最低验证要求 | 若被证伪，说明什么 |
|---|---|---|
| 在明示任务分布与风险水平内，自治能够达到可接受质量 | 与声明的人类、人机混合或历史基线比较质量与尾部失败 | 缩小自治范围或提高保留事项，不得宣称普遍自治 |
| 执行能力可以替换而不改变岗位与责任语义 | 更换后权责、历史、承诺与资格仍可核对 | 修正可替换性边界，不得暗中重置身份 |
| 独立验证的收益能够覆盖其协调与延迟成本 | 同时记录避免损害、控制成本与漏检 | 调整合法控制形式，不得取消不可自证原则 |
| 学习、记忆与能力更新能长期改善而非累积漂移 | 比较多轮后验结果、退化与撤回情况 | 限制或停止相关进化机制 |
| 内部证据与外部反馈足以纠正重大错误 | 检查伪造、同源盲点、外部异议与未发现问题 | 增强外部检验，不能隐瞒反例 |
| 自治的总成本与尾部风险可接受 | 将监督、纠错、资源与不可补偿损害一并结算 | 自治在该场景不具现实可行性或可持续性 |

外部条件不改变权、义务、责任、验收与禁止的概念含义，但可以改变证据强度、取得成本
和可行控制参数。多agent审查也只能提供反例与不同推理路径，不能仅凭数量证明独立验收；
最终逻辑必须可被他人重复质询，并仍须本项目当前治理程序的终审位置（制作人为当前实例）
确认。多agent讨论是发现问题的手段，不是理论正确性的充分证据。

## 八、共同反例集

以下反例是三册共同的上位测试，不依赖任何技术实现。表中给出的是总纲的原则答案；三册
必须展开各自责任位置与完整路径，不得重新给出相反判据。每个反例及五环责任位置由哪一册
展开，必须在第二步的统一目录与边界矩阵中唯一指定；该矩阵是三册扩写的前置条件，不是
三册可以各自重新选择的自由项。

| # | 反例 | 总纲的原则答案 |
|---|---|---|
| R1 | 两个合法委托方提出互斥要求 | 按预定优先关系与共同终裁处理；同级未决不得私选或新增承诺，可拒绝或依法解除 |
| R2 | 探索任务事前不知道正确产物 | 事前约定探索边界、学习交付与停止条件，事后独立评价，禁止追认偶然产物为原目标 |
| R3 | 内部验收全过，外部无用或受损 | 内部验收不等于价值；外部影响与受益者反馈必须按事项性质进入价值闭环 |
| R4 | 临时协作体无岗位、部门、职级也完成任务 | 组织形态是条件性选择；临时责任主体同样承担完整事项责任 |
| R5 | 同一任职者兼多岗并多次出工 | 按任职者全部关系累计禁配，拆身份不重置 |
| R6 | 出工中途更换执行能力 | 身份、历史与承诺连续，重新认定资格；说明依赖事实材料而非虚构记忆 |
| R7 | 执行能力退化、不可用或成本失控 | 明示不能，降级、替换、拒绝或停止；不得降标冒充完成 |
| R8 | 自学习把验收标准改成更容易通过 | 判据变更按实质分类并进入上位授权，普通进化不得自行通过 |
| R9 | 顶点失能、退出或被替换 | 按预定失能判定、临时代理与继任处理；历史责任不随继任改写 |
| R10 | 反复返工、永久否决、长期叫停 | 暂缓与叫停须有时限或复审，达到条件必须进入强制失败出口 |
| R11 | 任职或公司终止但仍有在途承诺 | 由接收者明确承接并核验；无人承接则由预定清算或残余责任主体处理 |
| R12 | 外部伪造意图、证据或验收 | 来源存疑即暂停使用并核验，内容逼真不构成有效来源 |
| R13 | 信任、尊严、长期期权等难以量化的价值 | 使用有理由、可异议、可复审的定性判断，不以不可量化抹除价值 |
| R14 | 无新产物但成功维持、拒绝或避免风险 | 维持、避免与停止均是结果，可按状态与过程验收 |
| R15 | 多主体共同造成结果且贡献难以分离 | 按实际控制分别负责或按预定规则共同负责，不随机归全部，也不集体免责 |
| R16 | 与其他自治公司联合交付 | 承诺前约定单方、按份或共同最终责任及争议终止；未约定不得联合承诺 |
| R17 | 外部验收者被俘获或与交付者同源 | 外部名称不等于独立；独立性须可质疑，并有更换、重审或上诉位置 |
| R18 | 无单一委托主体、由集体最终负责 | 允许集体顶点，但须有议事、表决、异议、替换与责任分配规则 |
| R19 | 受益者收益与第三方不可逆损害冲突 | 不得以内部总收益抵销不可接受、不可补偿损害；事前边界优先 |
| R20 | 真正未预见的危机没有个案授权 | 预授权剩余裁量的功能类别与上限；无裁量者只保全与升级，个案范围事后复核 |
| R21 | 合法使命在事实上不可行或不可持续 | 明示不能，重新协商、依法变更或终止，不得持续消耗并伪造进展 |
| R22 | 各环各自合规但整体资源持续透支 | 按公司整体资源结算，触发缩编、补足、变更承诺或终止 |
| R23 | 单次均合规的缓慢漂移年末形成事故 | 累积趋势属于异常，跨环汇总责任者不得只按单拍越线触发 |
| R24 | 把构成性变更改名降级为普通优化 | 按实质影响分类，受益方不得单方分类，争议由上位或独立位置终裁 |
| R25 | 终局后发现原证据伪造或裁判被俘获 | 符合新证据标准即可重开并限定影响范围，终局不得屏蔽事实 |
| R26 | 保留事项同时发生不可逆紧急损害 | 禁止事项仍不可做；按预设备用决定者与紧急边界最小止损，事后独立复核 |
| R27 | 新事项不在自主或保留清单 | 默认保留，只先受理、分类和请求决定，不得因清单沉默自动扩权 |
| R28 | 被授权修宪者修改修宪权以自我锁定 | 修订权条款不得由同一主体单独修改；无更高或实质独立确认位置时不得自我修改 |
| R29 | 公司层成员大会修改本纲不变量 | 公司层只能改本公司宪制，本纲不变量只能由本纲上位治理程序修订 |
| R30 | 公开承诺的相对方分散且无法逐一同意变更 | 作出时即须明确相对方类别、独立代表或异议通道与变更条件，否则不得作出可执行承诺或单方降级 |
| R31 | 交付方把不可逆高风险事项自评为低风险 | 分类者不得直接受交付方控制；可逆性存疑、分类有争议、不可逆且影响重大或无独立分类时按高档处理 |

反例通过的标准不是每份文档都给一句原则，而是能在三册合读后形成完整、互不矛盾的
处置路径；仍无法回答的反例必须回退总纲或相应分册，不得标为「以后再说」。

## 九、本纲不做什么

1. 不规定具体模型、执行宿主、CLI、插件、接口、存储或运行时；
2. 不把任何特定产品的能力当作自治的逻辑前提；
3. 不列具体岗位名称、部门数量、职级名称、权责原子编号或禁配清单；
4. 不把公司等同于法律人格，不用内部责任分配替代外部法律判断；
5. 不假定 AI 有意识、忠诚、恶意或天然合作，只讨论可观察行为、制度位置与证据；
6. 不承诺所有任务都能自治，不承诺所有能力都能获得，不承诺学习必然带来改善；
7. 不用概念数量、文档长度或矩阵覆盖率证明理论正确；
8. 不用「不符合本纲就不是公司」排除经验反例，只判断其是否符合本纲的自治正当性；
9. 不在本纲阶段展开员工、组织与工作三册的详细规则。

## 十、总纲完成判据

总纲只有同时满足以下条件，才允许进入三册目录与边界阶段：

- 根命题能规范地覆盖生产、选择、协调、维持、学习、退出与外部关系；
- 自治与主权、全能、自我授权、自我验收有明确区别；
- 核心概念无同名异义，权、能力、责任、证据、价值不互相替代；
- 五环的每个具体过程均有入口、反馈、责任位置、终态与强制失败出口，资源与异常贯穿其中；
- 不变量可以被单个反例质询，冲突有优先序，不是无法执行的修辞；
- 规范公设、逻辑结论、设计选择与经验假设被明确区分；
- 共同反例集能够覆盖自证、兼岗、无能、进化、顶点、终止、多主、集体和跨公司关系；
- 多路审查发现的硬冲突与重大缺陷已修复，或经明确论证形成不采纳结论；审查数量本身
  不作为独立验收证明；
- 没有需要依靠特定模型、CLI、插件或运行时才能成立的概念定义。

达到上述条件，只表示**可以开始三册目录与边界设计**，不表示整套理论已经通过终审。
