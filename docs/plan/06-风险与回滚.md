## 二、每波停止条件与回滚路径（引 v2/16 §五＋03，补齐 commit/表/配置口径）

### 2.0 回退点纪律（本节为 03 未细化处的统一补齐）

1. **Tag 即基线锚**：每波开工打 `mig-NN-entry`、波门全绿打 `mig-NN-exit`；MIG-06 收尾步（删旧面）前加打 `mig-06-cutover-pre`（03 §七回滚扩展的机械落位）。tag 由宰相在波入口/出口打，注释带波门证据摘要。
2. **回滚动作白名单**（白名单外一律禁止）：git revert（正向提交）｜检出 tag 重做｜DB 快照恢复（sha256 校验后）｜绑定档案 `supersedes`＋新版本。**禁**：reset --hard 共享分支、force push、回拨 LATEST_VERSION（H-01）、跳断言式「软回滚」。
3. **波入口回滚物料**（回滚可执行的前置）：MIG-04 起＝库快照（SQL/JSONL＋sha256）＋`daemon.yaml`/根 `package.json` 配置快照；MIG-06 停机窗另含在途单清点表。物料缺失＝该波不得开工（入口条件追加项）。
4. **回滚后重开**：同波重开须**重过入口条件**（含 DEC-OPEN 状态与 DSF 随访节），不许「回滚即免门」；重开事件记施工日志。
