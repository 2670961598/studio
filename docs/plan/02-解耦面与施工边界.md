## 三、泳道依赖 DAG 与关键路径

```
LANE-T(MIG-01 冻结 → MIG-02 V2 套件基础设施＋旧测试台账)
   │
LANE-C(MIG-03 形状与冻结工件) ──────────────┐
   ├──→ LANE-K(子域/纯函数) ──────────────┐              │(能力包产物,
   ├──→ LANE-S(MIG-04 v14+/限域) ─────────┼→ LANE-E(MIG-06 拆分与装配) ─→ LANE-M(MIG-06 后段:api 装配)
   └──→ LANE-O(MIG-05 资产部) ────────────┘    │              │
                            │(MIG-05+06 产物)  │              ↓(external 迁出验证)
                            ├──→ LANE-X(MIG-07 DSH 绑定) ──┐  LANE-V(MIG-08 stale 出口)
                            ├──→ LANE-B(MIG-07 三件套) ────┤      │
                            └──→ LANE-G(MIG-07 fail-closed)┴→ LANE-T(MIG-08 自检收口)
```

边表（依赖→理由）：T→C（MIG-02 出口是 MIG-03 前置）；C→{K,S,O,X,B,G,M,V,E}（端口/记录形状唯一源）；K→E（判定纯函数被编排消费）；S→E（MIG-06 前置＝MIG-04 只读打开）；O→X（MIG-07 前置含 MIG-05 能力包）；E→{X,B,G}（MIG-07 前置含 MIG-06 运行时装配）；E→M（assembly/api 注入点与 serve 拆分序）；M→V（external 迁出并验证后方可清理对账）；S→V、O→V（投影数据面）；全部→T 的波末自检。O→E 为**弱边**：E 消费 company 现状只读兼容面即可开工（org-config 兼容至 MIG-08），不硬等 MIG-05。

**关键路径**（波）：MIG-01 → 02 → 03 → 04 → 06 → 07 → 08 ＝ **7 波**；关键泳道链 T→C→S→E→{X｜B｜G}→T。MIG-05（O）在旁路（前置仅 MIG-03，与 MIG-04/06 同窗并行；但它是 MIG-07 前置——若 MIG-05 拖期即并入关键路径）。注：MIG-08 前置只点名 MIG-04/06 产物，波序仍按「波次不可跳」串在 MIG-07 后（v2/16 §五全局规则）。

## 七、分层宪法在施工期的守则（引 v2/13 §三、docs/20-§十五）

4. **基线棘轮只降不升**：22 条 lineBaseline 每里程碑对账点只许净减（清偿义务；连续两个里程碑零清偿＝开改进单）；MIG-06 的 engine.ts/serve.ts 拆分验收项含基线下降幅度登记；**600 行阈拆件先行**——预计超限的新件先拆设计再立单，不得「先超限再入基线」（新超限＝提案流，原则上按 DISP-02 拆件不批豁免）。
