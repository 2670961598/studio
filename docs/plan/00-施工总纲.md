# PLAN·00 · 施工总纲（施工方案目录与原则）

> 版本：v1.0-draft｜2026-10-28｜编写：宰相（GLM-5.3）｜性质：**V2 规范的施工方案总纲**——定目录、原则、依据与门禁；各分卷由子代理按本卷职责撰写。

## 一、施工目标与唯一依据

目标：把现有 StudioNext 代码（dev HEAD，v0.5 真单刀已合入，store LATEST=13，209 测试文件）按 **docs/v2/01-17** 规范重装为 V2 实现。唯一依据=V2（过 F8 后为定稿）；现状事实依据=v2/16 处置总表 + GLM C4a/C4b/H2c 已核实的代码事实；宪法依据=AGENTS.md（顺序铁律/提案流/契约测试唯一标尺/分层宪法/唯一写入者/密钥不入库）。

## 二、施工原则（从 V2 与两族审计直接导出）

1. **先冻结后施工**：MIG-01 基线冻结、MIG-03 contract/schema 冻结（v2/16 唯一主表；MIG-02 为 test 门禁修红）是一切实现单的前置——冻结物以 v2/09 主表与 v2/11 记录族为字面。
2. **契约先行**：每波先落契约 case（packages/contract cases.json）与 NEG- 负向用例（v2/17），再写实现——契约测试是唯一验收标尺（AGENTS §五.2）。
3. **按分层宪法分泳道**：cli→assembly→engine→packages 单向；一单一领土（文件级），领土互斥的单可并行（docs/24 并行轨道先例）。
4. **fail-closed 优先级**：v2/15 SEC-FC-01..07 的七项在触及对应面时同波修复，不留 fail-open 过渡态。
5. **钱账限域**：cost_daily 备份不重放（v2/16 §cost_daily），rebuild 排除域先立再动 store。
6. **DSH 主绑定不动摇**：执行器面只做 v2/07/12 的 DSH 具体化与专属/通用二分，不做备选 CLI 的实机适配（终裁簿 kimi/codex 缓）。
7. **不杀活 worker、不动在途、不重写历史、不 force push**（红线照旧）。
8. **证据断言**：每单完成=终态事件+非空输出+REPORT+闸门 exit=0（AGENTS §五.3）；每波出口=该波验收命令全绿+DSF 再审对应节通过。

## 四、门禁

- **方案门**：01-07 成稿 → 宰相审读一致性（01 差距项 100% 映射到 03 波次与 05 实现单；05 每单验收命令可执行）→ DSF 再审 → 通过方可开工。
