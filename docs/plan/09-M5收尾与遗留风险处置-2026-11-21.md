## 四、notify 面实现记录（2026-11-21，§二#3 小刀）

  daemon 侧零 matrix import 不变（docs/25-§一.2）；relay 调用面零改动（`face.send(notification,
  {alert/overview/dept/room})` 同一端口）。判例=chatd-mention-source.ts（transport/config 收口

- **投递语义**：alert/overview/dept 三逻辑角色**折叠投配置房恰一条纯文本**（chatd 无部门频道

## 五、id-floor 面实现记录（2026-11-21，§二#5 小刀）

- **形态**：`<platformRoot>/id-floor.json`，形如 `{"min": 99}`。可选——不存在=无下限
  （发号退回 M2 口径：全树 LOCAL-N max+1，行为逐位不变）。**不走 provision 面**（对
  本文件 §二.5 原 sketch "`--id-floor`/provision floor" 的落地修正）：发号是平台内部
  关注点、不是公司字段/状态语义；provision 走公司代码路径，而 floor 是 ops 决策——
  落独立文件才能保「daemon 只读、人工只能由 ops/迁移脚本写」的单一写入面。
- **语义**：`createIssue` 自增号 = `max(树内 LOCAL-N 最大号, floor) + 1`——floor 只抬
  下限不压上界（floor 低于树内 max 时仍取 max+1），只影响新发号；既有单号与
  list/get/activity 语义零改动。实现：`packages/localplatform/src/issues.ts`
  `readIdFloor`（fsutil/layout 同款零依赖；路径 `layout.ts idFloorPath`，平台根级、
  不进 meta/）。迁移重叠期安全：LOCAL-99 占位单未删时 `max(99,99)+1=100`，不双抬。
- **非法明报（不静默）**：文件在场即严检——非合法 JSON / 顶层非对象 / 缺 `min` / 非数字 /
  非整数 / 非安全整数 / 负值 ⇒ `LocalPlatformError(CONFIG_INVALID, 'bad-id-floor')`
  拒建单（撞号是事故，宁可明报）；缺文件=无下限、不报。重复读幂等：每次建单直读盘、
  无缓存，同内容必同值；daemon 永不写该文件。
- **测试**：`packages/localplatform/test/id-floor.test.ts`（14 例：无 floor 行为不变/
  min=0 等效无下限/floor=99+树内 max=28→LOCAL-100/占位单在场不双抬/floor 低于 max 取
  max+1/7 类非法内容明报＋零落盘/只读幂等/同根两实例交错号不重不漏）；全包 71 例绿
  （`mise x -- bunx vitest run packages/localplatform`）、typecheck/typecheck:v2/
  guard:boundaries 绿。注：新测试落 `test/`（非 `test/v2/`）——属包级单测面，不进 V2 门。
- **ops runbook**（生产平台树落盘；本刀只交代码＋文档，平台树写入归 ops——「人工只能
  由 ops/迁移脚本写」）：
  1. 各公司平台根写 `id-floor.json`（内容 `{"min": 99}`）：pilot-internet/studio-profit/
     workbench-dev=`<公司目录>/var/platform/`，studio-dev=`<公司目录>/platform/`。现状
     四树 max（2026-11-21 读）=1136/444/155/187，均>99——min:99 只作下限护栏（历史
     demo 单裁撤/恢复场景防再撞 LOCAL-1..28），当前号段连续性仍由树内 max 承担；
  2. 同目录留 `id-floor.ops.md`（内容：本文件是 localplatform 发号下限，形如
     `{"min": N}`、可选、daemon 只读；人工只能由 ops/迁移脚本修改，禁随手编辑；
     依据 docs/plan/09 §五）；
  3. 验证：建一张试单应为「树内 max+1」（如 pilot-internet=LOCAL-1137）→ 归档该试单；
  4. 删 `issues/LOCAL-99.jsonl` 占位单（防撞号职责已由 floor 承担；删除后下一单仍
     由树内 max 决定，语义不变）。
- **回滚**：删 `id-floor.json` 即回 M2 口径（无下限）；占位单删与否不影响 floor 语义。
