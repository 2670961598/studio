### 7.2 status（探测口径）

- daemon：GET `/healthz`，**200 ∧ body.ok=true** 才算 up（503/坏 body/连接错=down）。
- chatd：unix socket NDJSON 两步（`health`＋`rooms.list`，`workbench-transport/v1`），
  token 从 token 文件读、**永不回显**；缺 `--company-dir` → 行标 `skip`（不算失败）。
- panel：GET `/` 任一 2xx 即 up。结论行 `failed` 只数 down；exit 0 ⟺ failed=0，否则 1。
- 本机冒烟实录（daemon pid 真在跑）：daemon ● up（ok=true tick 计数在涨）、panel ● up
  （http 200）、chatd 随目录状态如实标 down——**探测只读兑现**。

### 7.3 doctor（六项＝§三 5-1 判据）

1. node ≥24（`process.version` 可注入）；2. companyDir 存在；3. daemon.yaml
   `platform=localfile`；4. chatd 三件权限 **socket 0700／db 0600／token 0600**（§四 #2
   口径——socket 0700 为目录可达性留门，非 0600）；5. 备份目录存在→可写，不存在→最近
   存在祖先可写即绿（将建）；6. 磁盘余量 ≥2GiB（statfs 可注入，null=红）。
   任一红 → exit 2 逐项明报（表/`--json` 双面）；全绿 exit 0。

### 7.4 up/down（macOS launchd 首版——§六「首验 macOS」口径）

- label 三件：`io.studionext.daemon`（guardian）｜`<prefix>.chatd.<slug>`｜`<prefix>.panel.<slug>`；
  plist 落 `--launch-agents`（缺省 `$HOME/Library/LaunchAgents`）0600 原子写（tmp+rename）；
  日志落 `--log-dir`（缺省 `$HOME/Library/Logs/studio-next/<slug>`）。
- daemon plist=guardian 模型（§2.2 双 plist）：`node scripts/guardian.mjs --config <guardian.json>`；
  chatd plist 与 scripts/ops/chatd-setup.mjs PLIST_TEMPLATE 同构（env 四键
  WORKBENCH_CHATD_SOCKET/DB/TOKEN_FILE/LOG＋`--experimental-strip-types`）——**重复面
  记账**：M5-2 打包刀收拢单源，不在本刀扩面。token 只经 env 传**文件路径**，值永不入 plist。
