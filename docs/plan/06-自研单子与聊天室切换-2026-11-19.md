> 制作人 2026-11-19 03:2x 指令：**单子和聊天室必须自研，不再使用外部（Taiga/Matrix），方便以后打包分发；尽快接入并切换到正式使用。**
> 本文为执行方案；与既有 A 路线（插件/接口冻结）不冲突：外部产品不再是我方生产依赖，插件只作为观察/对标对象。

## 〇、目标与原则

1. **生产事实源切换**：单子 Taiga→`@studio-next/localplatform`（localfile，文件驱动、零外部依赖）；聊天室 Matrix→`workbench-chatd`（自研 sidecar，Unix socket+SQLite）。
2. **自研不引外部运行时**：打包分发只需 Node + 公司目录 + 两个自研服务（daemon + chatd），不再依赖 Docker/Taiga/Matrix。
3. **可回滚**：切换前保留 Taiga/Matrix 只读快照与增量回同步路径；任何一步失败可按 runbook 回退，回退窗口 ≤10 分钟（聊天）/≤30 分钟（单子）。
4. **不混事实源**：切换后 Taiga/Matrix 只作历史归档，不允许双写；localplatform/chatd 为唯一写入者。
5. **流程不降级**：验收四要件、enforce 闸、台账、成本、面板、提醒/唤起链全部保留；切换不是"降级到玩具"。

## 三、单子切换细则

1. **目标**：`platform: localfile`，根=`<companyDir>/platform/`；单据=jsonl 事件流、状态=末次 transition、评论=md、知识=md 树、活动=activity.jsonl。
2. **迁移映射**：Taiga project/单 ID→`studio-dev-N` 保留；状态 1..8→localplatform 状态映射表（`binding.ts`）；评论/活动/父子/自定义字段→fields/provision/links；附件=显式 UNSUPPORTED（v1）。
3. **写入者**：daemon 经 gateway 唯一写；迁移只允许离线工具一次写入空树（迁移窗口）。
4. **对账**：计数/ID/状态/评论数/父子/活动游标；0 差异才允许切；差异=gap 清单 exit1。
5. **回滚**：保留 Taiga 只读快照（04:30 备份）+迁移工具回导 Taiga 的"最后窗口增量"（只在新系统运行期间产生的单回写），回滚 ≤30 分钟。
6. **不可迁项**：Taiga 内部 ID 引用、附件、历史版本 diff、自定义报表——显式登记"不迁"，不伪装。

## 四、聊天室切换细则

1. **目标**：daemon 的 MentionSource/Notifier 从 Matrix 切到 chatd（Transport v1）；聊天室 UI 用 panel 新页（自研），复用 chatd rooms/messages/inbox/wake。
2. **数据迁移**：Matrix rooms/messages→chatd（rooms/messages/wake），actor=MXID→工号映射；只迁语义不迁拓扑；附件/加密不做（显式 UNSUPPORTED）。
3. **切换**：daemon 配置 `mentionSource: chatd`、`notifier: chatd`；Matrix 只读保留 N 天；停 Matrix 前完成双跑（wake 恰一次、0 漏/0 重复）。
4. **回滚**：双跑期 Matrix 仍可写？——**不允许双写**；回滚=停 chatd 写、恢复 Matrix 写、把窗口内 chatd 消息回导 Matrix（工具化）。
5. **打包**：chatd 随 daemon 同生命周期（launchd/systemd 双进程），socket 0700/token 0600；无外部端口。
