## 〇、读法与口径

1. **单号**：`IMPL-<波两位>-<序两位>`（如 IMPL-04-02），即 Taiga 标题前缀；单名 ≤40 字。
2. **领土**：文件/目录级，含 test/ 镜像（plan/02 §〇-5 原则①）；两单零重叠（plan/02 §八）；共享文件对只能出现在 §五裁决过的串行单对里（表内「依赖」列显式）。
3. **规模**：S（单文件机械/夹具）、M（2-4 文件常规）、L（≥5 文件或契约/架构件）。**并行**：∥＝可与同波单同时开（领土互斥且依赖满足）；「串行 X」＝必须待 X 合并。
4. **验收口径**：命令全部 `mise exec --` 证据口径（v2/13 §0.2）；**V2 门**＝`mise exec -- bun run guard:boundaries && mise exec -- bun run typecheck && mise exec -- bun run typecheck:v2 && mise exec -- bun run test:v2`（`verify:v2` 含台账校验，MIG-02 后统一用 `verify:v2`）；**旧测试不作门**，触及面用 `mise exec -- node_modules/.bin/vitest run <path>` 跑并登记（红也登记、不阻塞）；NEG-/case 编号引 plan/04 §三（分配表冻结）。**命令与 NEG 路径随 03/04 卷过审即冻结，单内禁改。**
5. **波门**：每波单全合＋波验收命令（plan/03 §二..九，V2 新套件）全绿＋**触及面旧测试登记**＋该波 NEG 全过＋guard 绿＋无 fail-open 残留，方可开下波（plan/00 §四）。
