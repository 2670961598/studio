## 二、§12 组织架构总纲（新增条款正文）

### 12.1 纵向：等级与分权
- 单据等级 1-9；**等级 N 团队 → 单据区间 1~N**（越团队等级即越级）
- **批/干/派错位一格**：每层领导 干[N-1,N] / 批[N-2,N-1] / 派[N-2]；
  下层干的上限=上层批的下限（咬合）
- 制作人：批 9（必亲批）、看 8（评论=高权重指令）、只发 9 级探索单
- 等级渐进启用（org.yaml `渐进启用` 段），存量 L/G 轨道双轨兼容

### 12.2 横向：部门与交叉
- 部门=主管+成员+职能+泳道资源；每部至少一个上级（可交叉多处）
- **跨部门单联签**：涉及部门主管全部签字方放行
- **全流程逐环确认**：理解→拆分→方案→执行→测试→回归→merge，逐环签字

### 12.3 铁律（不可变更级）
- **派出人是起点和终点**：单据带派单人字段，中间环节按等级分权流转，
  **终验收=派单人本人**（制作人原话定死）
- 派生上限=派单人批上限（子单等级<父单，天然防越级）

### 12.4 账号与网关
- **账号=等级锚点**（agent-1~9，纯等级无职能定位；职能归 org.yaml 人事档案维度）
- **agent 用 YouTrack 必经框架网关**（wkey 白名单：comment/heartbeat/article；
  状态推进无网关端点——平台层不可越级）；评论署名协议 [项目·个体名·部门]
- YouTrack 平台级状态 guard 与框架 statemachine 双保险

### 12.5 分工定则
- **框架（studio-daemon+kernel）= agent 人事与干活**（编制/档案/定时/worker/沙箱/记账）
- **YouTrack = 流程流转**（状态机/等级/批示/联签/知识库）
- 唯一事实源：kernel/org.yaml（组织）+ YouTrack 字段（单据）

### 12.6 团队等级与升级
- 九级分形（1级=1人→9级=3000-10000）；主力 2-4 级；标准参考表见 ORG-DESIGN 五点十
- **升级流程**：项目最高负责人提议 → 最高领导层会签（≥3级团队三人签）→ 制作人终验收 → 升级
- 4 级起推荐设人事部（管控编制与成本）

### 12.7 分布式路线（远期预留）
- 状态外置=天然分布式亲和；多 NUC 分区（STUDIO_PROJECTS）；网关地址 STUDIO_WEB_HOST 参数化；
  YouTrack 联网安全（TLS+九账号按等级收权限）
