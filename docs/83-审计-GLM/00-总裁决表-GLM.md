## 四、A/B/C 分档（可实施性）

- **A 档（阻断第一张实现单）——6 项**：A1 规范自反矛盾三处（K8）；A2 共用枚举双字面量（K9）；A3 82 卷自检脱节包（K10：§12.7 悬空+P-82-01 无体+V0 漏六族+GAP 统计）；A4 MIG-01 冻结基线数字不可复算（38 条边=实测 76、210 文件=实测 209）；A5 端口类型文件路径双事实源（K5 核心）；A6 裸字母 ID 重号三组（K11）。
  理由统一：MIG-02 要冻结 schema/50 类 payload，以上任何一项未清，冻结物自带非法字面量或无法落笔——按 82 自订停止条件字面触发。
- **B 档（阻断过审，可与 A 并行修）——10 项**：B1-B4（K1-K4 四个「载体决定」，全部须在 MIG-02 冻结前一次性收口，避免冻结后二次 schema 迁移）；B5 元治理独立性纪律（K6）；B6 迟到副作用观察义务（K7）；B7 TR-W-06 锚错（K5 外周）；**B8 D1 终裁簿裁决（呈您）**；B9 MCP 缓办划界+D3 补 MIT（呈您一句话划界）；B10 记录型定稿大清单（B1-B4 载体+能力回执/交接包/在途变更申请/激活批准）。
- **C 档（实施中补）**：其余 ~115 条 P1 + ~96 条 P2——三册衔接缝、组织册具名化、附录漂移、版本口径、表述级问题，均不触碰 MIG 前置与 payload 冻结。
