# 前沿侦察 2026-11-23（只读；近一周 GitHub/arXiv/厂商）

## 结论（TL;DR）
本周主线是**"企业级 Agent OS"商业化加速**：Cognitum One 发布 ruOS（面向 AI agents 的企业计算机平台）、Redule AI 发布面向咨询/经纪客服运营的 Agentic OS，加上此前的 Kortix CompanyOS（开源）——赛道从"框架"卷到"OS/平台套餐"。研究侧两个高价值延续：**AZOWL AgentOps**（任务域治理：稳定 work ID 绑定权限/执行/审批/证据）与 **Error-Memory Institution**（53 天生产审计：写前闸门+错误记忆机构，维护成本仅 ~1.8% 写流量）。另 DGF-Bench 用基准测"治理委员会被 agent 欺骗"，对我们红队验收有直接借鉴。

## 3-5 个最相关对比

### 1) 企业 Agent OS 商业化三连（Cognitum ruOS / Redule / Kortix CompanyOS）
- 证据：https://www.businesswirenews.com/news/home/20261006476353/en/Cognitum-One-Announces-ruOS-the-Enterprise-Computer-Platform-for-AI-Agents ；https://markets.businessinsider.com/news/stocks/redule-ai-launches-agentic-ai-operating-system-for-customer-operations-in-consultancies-and-brokerages-1036595598 ；https://github.com/kortix-ai/CompanyOS
- 要点：Cognitum=面向企业的"AI agents 计算机平台"；Redule=垂直行业（咨询/经纪）客服运营 Agentic OS；Kortix=开源 company OS。共同点：都往"平台/OS + 场景套餐"卖。
- 可借鉴：①**垂直行业套餐化**（把公司能力按场景打包：客服运营/研发交付/内容生产），我们 M5 已有公司模板（game/internet 等），可扩"场景套餐"叙事；②**企业级卖点=治理/审计/可控**，这正是我们强项（三事实源+闸门+审计链），文案应主打"可审计的 AI 公司"而非"更多 agent"。
- 已覆盖：可分发运行时（tarball/stack）、真实单据闭环、审计链；不该学：为追概念堆无治理的"平台"壳。
- 判断：产品竞争加剧，但**我们差异化明确**；建议把"治理/审计/可回放"写进对外一页介绍。

### 2) AZOWL AgentOps（arXiv 2611.25562；任务域治理）
- 证据：https://arxiv.org/abs/2611.25562
- 要点：稳定 work ID 绑定 **发送者权限 / 执行 runner / 必要审批 / 结果证据**；默认 enrolled PC 只读；scope gate 在范围变化时**重新请求审批**；28 组合成 run 验证零越权写。
- 可借鉴：我们已有 ticket+ledger+验收，但缺"审批/证据绑定视图"与"范围变更重新审批"检查。→ 建议给验收/派发面加这两个检查点（小刀）。

### 3) Error-Memory Institution（Zenodo 53 天审计；延续最重要）
- 证据：https://zenodo.org/records/23597096
- 要点：合规尝试不下降，但把错误类收敛成"一次性事件"后固化；写前闸门+错误档案两制度；规则 1 天成文、维护成本 ~1.8% 写流量；5 条行为规律（激励近视/收口节奏/外包收敛/脚本-模型分工/谄媚放大）。
- 建议：把"错误类一次性规则+复发计数+维护成本口径"落进进化链/哨班（P1，昨已建议，仍未排单）。

### 4) DGF-Bench（治理委员会 deception 审计基准）
- 证据：https://aisecurity-portal.org/en/literature-database/dgf-bench-a-benchmark-for-simulating-and-auditing-deception-against-multi-agent-governance-boards/
- 要点：模拟并审计"agent 欺骗治理委员会"；对验收红队/伪证检测有直接参考。
- 可借鉴：把现有验收红队样本扩成"欺骗场景"（伪证、虚构 REPORT、规避闸门），定期注入验收审计；不引依赖。

### 5) 开发工具链（观察）
- colink-harness（PyPI）、geenii（PyPI 预发布）、pnnl/adept-agentic（DOE 代码库）：agent harness/编排工具链继续碎片化。我们已有执行器适配器（dsh/claude/codex/kimi），维持观察不引依赖。
