## 一、切换前置（Export Freeze）

1. **冻结源**：Taiga 项目（PH0=studio-dev）停止一切人工/自动流转与评论——冻结时刻记 `frozenAt`。
2. **导出**：按 Phase0 同构格式导出全量单据（rows：issue/state/subject/description/assignee/
   parent/comments/created/updated…）；导出件落 `docs/quality/phase0/ticket-export.json` 同构路径。
3. **导出指纹**：`planHash=sha256(canonicalJson(planBody))`——同源数据必得同哈希（测试已断言）。
   冻结后任何人重导出，planHash 不变即证明源无漂移。
4. **期望表**：以冻结快照生成 `ticket-diff.json` 同构期望表（每单 desiredStateCode/评论数）。

## 二、迁移窗口（Migration Window）

前置全部绿灯后才开窗；窗口内 Taiga 保持只读（§五回滚依赖）。

```bash
# 1) 演练（零写入）：只打印计划与哈希
node scripts/taiga-localplatform-migrate.ts --dry-run --root <平台根>
# 期望：exit 0；dryRun:true；planHash 稳定；根目录不创建（测试已断言零落盘）

# 2) 实迁（先备份目标根，若非空）
node scripts/taiga-localplatform-migrate.ts --root <平台根> --out <计划件.json>
# 期望：exit 0；written=N skipped=0 blocking=false；gapCount 只含 3 条全局显式不迁
#（attachments-not-migrated / dispatcher-description-only / stateflow-edges-not-declared）

# 3) 幂等复跑（不动树，只证明收敛）
node scripts/taiga-localplatform-migrate.ts --root <平台根>
# 期望：written=0 skipped=N；平台树字节不变；planHash 与首跑一致（测试已断言）

# 4) 逐单对账
node scripts/taiga-localplatform-diff.ts --root <平台根>
# 期望：exit 0；源 N / 平台 N / 逐单全对 N / gap 0
```

## 三、双跑门槛（Dual-Run Gates）

迁移完成后、切流前，双跑期至少满足：

| 门槛 | 判据 |
|---|---|
| G1 逐单 0-gap | diff exit 0 且 `gaps.length===0`（漂移披露不计） |
| G2 幂等收敛 | 重跑 migrate `written=0`，树哈希不变 |
| G3 daemon 可起 | 沙箱同款 `daemon.yaml`（platform: localfile + platformDir=迁移根）boot 通过 healthz 自探活（§六已验证） |
| G4 daemon 只读兼容 | daemon 短跑前后迁移树**字节不变**（沙箱已验证：`746e8479…` 前后一致；activity 游标能消费到迁移活动流末条 `a-000010`） |
| G5 状态口径 | 平台态逐字保留；`binding.ts` 判决 Ok/unverified/workStates=[]（STATE_MAPPINGS 空为部署工件，迁移不伪造映射行）；对账码按 `STATE_MAP` 冻结表（新单1/待批2/已派发3/证据就绪4/复验中5/已交付6/打回7/收口族8） |

## 四、0-Diff 判据（切流标准）

- `scripts/taiga-localplatform-diff.ts` **exit 0** 且报告 `ok:true`：
  - counts：source=platform=matched=N（评论/父子计数同源同标）
  - `gaps:[]`；`drift` 每条都有人工裁决记录（预演数据 1 条：studio-dev-1495 源已派发(3) vs 快照已交付(6)，裁决=以源为准迁移、快照口径披露）
- 任一 `extra-ticket / missing-ticket / state-mismatch / comments-* / link-missing / parent-mismatch`
  = 硬 gap，**禁止切流**，回 §二修数据后重走全链。

## 五、回滚（Rollback：回 Taiga 只读）

回滚=停写自研、写面回指 Taiga；**不需要**从 LocalFile 反迁（窗口期 Taiga 一直只读=事实源未动）。

1. `daemon.yaml` `platform:` 改回 `taiga`（SEC-WD-02：org-config `company.platform` 同步改回，二者不一致=拒启）。
2. 重启 daemon；Taiga 启动探针（fields.schema 四层连通）通过即回滚完成。
3. LocalFile 迁移根整体归档（只增不改的 jsonl 树可直接 `tar` 留证；回滚不删除）。
4. 回滚演练口径：迁移侧 fail-closed 已验证——树内计划外单（extra-ticket）时 migrate **拒绝全部写入**
   （written=0、树不变），不会产生半迁移状态；对账侧 exit 1 显式列出 gap。

### 踩坑实录（复现必读）

| 现象 | 根因 | 处置 |
|---|---|---|
| 无 companyDir 的 demo 装配 + localfile → `/v1/company` 503 → 拒启 | API 启动自探活要求公司维 200；读源未提供投影 | 给最小 companyDir（模板）|
| 同上 503（给了 companyDir 仍拒） | `daemon.yaml company:` 标签 ≠ org-config `company.slug`（companyId 对不上）| 标签对齐 slug（example-corp）|
| `platform-binding-mismatch` 拒启 | org-config 未声明 platform 时装载缺省 youtrack，与 localfile 不一致（SEC-WD-02）| org-config 显式 `platform: localfile` |
| `gw-secret-too-short`（23B）拒启 | 签根门限 32 字节（HMAC-SHA256）| 换 48B 沙箱哑密 |
| 每拍刷「公司目录不是 git 工作树」 | 报表挂单 commit 需 git worktree（非致命，不挡 tick/healthz）| `git init` 即消 |
| 硬杀后重启 `STALL/writer-lease-held` | SIGTERM/SIGKILL 不走优雅停 → `ledger.sqlite.writer.lock` 残留；pid 复用令「死锁清理」误判持锁者存活 | 优先优雅停（SIGINT/控制面停机）；已污染则人工核 pid 后删锁文件 |

## 七、已知缺口（M2 阻断项，切换前必须收口）

1. **`issues.ts` ID 前缀硬编码**：`create()` 只发号 `LOCAL-N`，`scanIssueIds()/list()` 只认 `LOCAL-` 前缀。
   迁移侧以「直写 created 事件行 + activity 条目」保 ID（`studio-dev-N` 逐字），`get/transition/
   setField/comments/links` 全兼容——但引擎 `list()` 看不见迁移单。**daemon 真正消费迁移树前必须
   改前缀策略（可配置或全量扫描）**，否则派发/收割面等于失明。
2. `stateFlow` 边集未声明（导出无流边数据，不伪造）——guard 接线日按部署工件补。
3. 附件/历史版本 diff/自定义报表显式不迁（v1 口径）；dispatcher 仅存 description 溯源 JSON。
4. binding `STATE_MAPPINGS` 空=部署工件：切流前须由部署面产出映射行并通过契约验收。
