## 二、为何备份写内部盘（TCC 限制，重要）

- 首次安装指向外部盘 `<volume>` 时 launchd 退出 **78 EX_CONFIG/126 Operation not permitted**；
- 复现：launchd 用户 agent 对 `<volume>`（外置卷）**TCC 拒绝**（getcwd/exec/写入均 Operation not permitted；最小 launchd job 写 /tmp 正常，写外置卷被拒）；
- 因此：**脚本与备份目录都放内部盘**（`~/Library/Application Support/StudioNext/`），launchd 才能稳定运行。

## 三、外部盘同步（两层方案，待制作人选择）

1. **推荐（无需交互）**：保留内部盘每日备份为基线；把"到外部盘 ``<volume>/backups`` 的复制"作为**人工/哨班动作**（会话有权限）——每次哨班或每周把最近备份 rsync 一份到外部盘，并记录；
2. **全自动**：给 `/bin/bash`（或包装脚本）授予 **Full Disk Access / 可移除卷** 权限（系统设置手动一步），之后可让 LaunchAgent 直接写外置卷；
3. 或用 root LaunchDaemon（需 sudo，权限面更大，不推荐）。
