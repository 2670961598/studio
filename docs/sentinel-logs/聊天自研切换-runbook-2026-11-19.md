# 聊天自研切换 Runbook（task-137 · M4 矩阵迁移版）

依据：docs/plan/06-自研单子与聊天室切换-2026-11-19.md §二 M4、§四.2/§四.3/§四.4。
工具链（全部仓内、只读 Matrix、零生产写入；快照与工作目录只落 /tmp）：

| 角色 | 文件 | 说明 |
|---|---|---|
| 导出器 | `scripts/matrix-export.ts` | 密码登录→joined_rooms→逐房 /messages 翻页；产出 `matrix-export/v1` + manifest（房数/消息数/sha256/时间范围） |
| 迁移器 | `scripts/matrix-to-chatd-migrate.ts` | 导出→临时 chatd（临时 socket/token/SQLite）→ Transport v1 `rooms.create`/`messages.send` |
| 对账器 | `scripts/matrix-to-chatd-diff.ts` | 导出 vs 迁移报告 vs chatd（`--db` 全量 / `--socket` 在线两口径） |

## 一、切换前置（Export Freeze）

1. Matrix 侧冻结公告：迁移窗口内 Matrix 只读（不新增消息/不改房）；无法硬冻结时按 §三 双跑口径处理增量。
2. 快照（示例路径；凭据只经 env，不入命令行历史）：

```bash
set -a; source <(凭据文件); set +a   # MATRIX_HOMESERVER / MATRIX_BOT_USER / MATRIX_BOT_PASSWORD
node --experimental-strip-types scripts/matrix-export.ts \
  --homeserver "$MATRIX_HOMESERVER" --user "$MATRIX_BOT_USER" \
  --out /tmp/matrix-export-<date>.json --manifest /tmp/matrix-export-<date>.manifest.json
# 期望：exit 0；单行 JSON（rooms/messageEvents/nonMessageEvents/timeRange/exportSha256）
# manifest.exportSha256 可独立重算自证（sha256: 前缀 + 64 hex）
```

3. 冻结判据：manifest 时间范围上限距今 ≥ 冻结时长；导出器内置分页去重（eventId 唯一性由对账器复核）。

## 二、迁移窗口（Migration Window）

```bash
# 1) 迁移（临时 chatd：mkdtemp 工作目录，随机 token 落 chatd.token 0600）
node --experimental-strip-types scripts/matrix-to-chatd-migrate.ts \
  --export /tmp/matrix-export-<date>.json --actors <mxid→工号映射.json> --workdir /tmp/mx-migrate-w1
# 期望：exit 0；单行 JSON ok:true gaps:0；报告落 <workdir>/migrate-report.json

# 2) 幂等复跑（chatd 同一 SQLite 重启 hydrate；证明收敛、不重发）
#    同命令重跑：期望 messages.sent=0（余为 preexisting/L3 标签预检 + replayed/L2 idempotencyKey）

# 3) 对账（两口径都过）
node --experimental-strip-types scripts/matrix-to-chatd-diff.ts \
  --export /tmp/matrix-export-<date>.json --report /tmp/mx-migrate-w1/migrate-report.json \
  --db /tmp/mx-migrate-w1/chatd.sqlite --quiet
node --experimental-strip-types scripts/matrix-to-chatd-diff.ts \
  --export /tmp/matrix-export-<date>.json --report /tmp/mx-migrate-w1/migrate-report.json \
  --socket /tmp/mx-migrate-w1/chat.sock --token "$(cat /tmp/mx-migrate-w1/chatd.token)" --quiet
# 期望：均 exit 0；gaps:0 gapKinds:[]
```

actor 映射冻结铁律：`--actors` 文件一旦定稿，迁移窗口内不得改（chatd idempotencyKey 作用域含
sender——换映射=换 sender=重放去重失效）。映射三规则：显式文件 > localpart 启发式（合法字符集）
> MXID 逐字兜底注册（脏 localpart 不猜）。

## 三、双跑门槛（Dual-Run Gates）

| 门槛 | 判据 |
|---|---|
| G1 完整 | 导出 manifest 消息数 = 迁移报告 planned+skipped；对账器记账层 0 `export-unaccounted` |
| G2 无漏 | 对账器事件层每房 `missed=0`；`--db` 口径 headRoomSeq=标签+迁移外 |
| G3 无重复 | 复跑 sent=0；对账器 `duplicate=0`（append-only 一旦重复=回滚重迁，不可原位修） |
| G4 语义 | 发送者集合/首末时间逐房一致（时间唯一载体=标签 ts，见 §八） |
| G5 稳定 | 复跑后 `--db` 对账仍 exit 0；SQLite 行数不变（房=导出房数、消息=可迁消息数） |

## 四、0-Diff 判据（切流标准）

对账器 exit 0 = 上述 G1–G5 全过。gap 分类（`--quiet` 摘要里的 gapKinds）：
`export-unaccounted`（漏）/ `missed`（漏）/ `duplicate`（重复）/ `unexpected`（漂移）/
`sender-mismatch` / `time-range-mismatch` / `count-mismatch` / `room-missing` / `room-count` /
`plan-foreign`。无标签消息与计划外房只记 note 不判 gap（双跑窗口正常流量）。

## 五、回滚（Rollback：回 Matrix）

聊天 append-only，回滚=切回 Matrix 客户端使用（数据仍在，迁移只读源）：
1. 停双跑判定，公告回 Matrix；
2. chatd 侧迁移库只作审计留存（不删——回滚不销毁证据）；
3. 若已产生 chatd 独有消息（无标签迁移外消息），回滚决定前先跑对账器看
   `foreignMessages` 计数——非零即有双跑期新消息需人工决断去向；
4. 二次切流=同快照复跑迁移器（幂等收敛）+ 对账 exit 0，再放行。

## 七、不可迁项（UNSUPPORTED，对齐设计文档 §四.2「只迁语义不迁拓扑」）

| 项 | 处置 | 证据 |
|---|---|---|
| E2EE（m.room.encrypted） | 导出器保留事件（body=null），迁移器登记 skip `encrypted`，绝不猜密文 | 迁移报告 skips 明细 |
| 附件（m.file/image/audio/video） | 导出保留元数据；迁移器 skip `attachment`——chatd v1 无 mxc/二进制位 | 同上 |
| 编辑（m.replace） | 只迁首版语义；编辑史 skip `edit`（chatd append-only 无编辑原语） | 同上 |
| 消息原始 createdAt | chatd v1 createdAt=服务端落地时刻，协议无回填位——原始 ts 进标签 `[mx:<eventId>@<ts>]`，首末时间对账以标签为准 | §八缺口登记 |
| 房 topic / canonical alias | chatd Room DTO 无字段——落迁移报告作审计，不进 chatd | 报告 rooms[].topic |

## 八、已知缺口（协议侧登记，M3/M5 议题）

1. `messages.list` 每房只暴露最旧 200 条（hasMore 截断）：L3 标签预检视野有限，窗口外靠
   L2 idempotencyKey（SQLite 持久、跨重启）兜底——全量对账用 `--db` 口径。
2. WorkbenchTransport v1 客户端未建模 token（服务端契约收 `params.token`）：迁移器/对账器内置
   鉴权适配注入；daemon 接线（M3 模块 D）应把 token 收进客户端构造。
3. chatd 服务端 idempotency 表落键在消息事务之后（两事务毫秒级窗口）：崩溃于窗口内会重发一条
   ——对账器 `duplicate` 检出后按 §五 回滚重迁。
4. createdAt 无回填位、Room 无 topic：见 §七。
