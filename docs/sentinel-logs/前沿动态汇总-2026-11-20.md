# 前沿侦察 2026-11-20（只读；近一周 GitHub/arXiv/厂商页）

## 结论（TL;DR）
"一人公司 OS"赛道明显升温：**OneManCompany**（Apache-2.0，2026）把"AI 公司"做成产品级 OS（org chart/招聘/绩效/会议室/成本/像素办公室），是当前最直接的产品级对标。学术侧 **GAMPO/"When Agent Governance Helps"** 给出可运行治理规格，并给出一个对我们验收闸很有用的实证结论：**answer-blind 的逐任务完成定义（DoD）显著优于统一流程**。协议侧 **AG-UI** 正在成为 agent↔UI 交互标准，值得作为面板/聊天交互的观察项。

## 3-5 个最相关对比

### 1) OneManCompany（最相关产品级对标）
- 证据：https://1mancompany.github.io/OneManCompany/ ；https://github.com/1mancompany/OneManCompany （Apache-2.0）
- 定位：面向"一人公司"的 **Agent OS**：`npx @1mancompany/onemancompany` 一键起，浏览器内 CEO+EA+HR+COO+CSO+员工；层级 org chart、招聘/解雇（Talent Market）、季度绩效/试用期/PIP/晋升、任务委派+逐层质量门、会议室多 agent 同步讨论+自动纪要、按项目 token/USD 成本；**Vessel（执行容器：重试/超时/工具/通信协议）+ Talent（技能/知识/人格/工具的能力包）** 架构；像素办公室 UI。
- 可借鉴：① **Vessel+Talent 分离** 与我们"executor 适配器 + 岗位/技能 prompt"同构，但他们的"能力包"可安装/可交易——值得作为我们岗位模板/技能包的产品化参考；② **会议室（多人同步讨论+纪要）** 是我们没有的协作面（我们只有对话投影/群聊）；③ 绩效/试用/PIP 与我们的进化链/HR 同步可对照；④ 一键安装的开发者体验。
- 已覆盖/更强：我们有三事实源/证据链/验收 enforce/多公司隔离/执行器中立/真实单据闭环；他们更偏"演示级自主公司"。
- 不该学：外部 Talent Market 供应链模式（治理/责任边界不可控）；像素仿真当产品；不做我们核心事实源替换。

### 2) When Agent Governance Helps（GAMPO，arXiv 2609.05531）
- 证据：https://arxiv.org/abs/2609.05531
- 内容：从 321 篇文献综合出"受治理的自目标多 agent 产品组织"（GAMPO）可运行规格；在 CHI-Bench 上验证：治理收益受**模型剩余能力**门控（弱模型上完整流程无可靠收益，"verify your writes"一句反而翻倍成功率）；**用 answer-blind、逐任务的 definition-of-done（只依据案例自身政策/公开标准，绝不看隐藏答案）替代统一流程**，前置授权 24%→84%（best-of-five）。
- 可借鉴：**answer-blind 逐任务 DoD** 正是我们 `acceptance_criteria` + 独立 verifier 的方向——建议把"验收标准不得含隐藏答案/结果，只能含可测判据"写成验收审计硬检查（红队样本）；治理强度按执行体能力分层（我们 high/mid/low 档位已有基础）。
- 已覆盖：四要件、enforce、独立 verifier、按单验收口径。
- 不该学：把 prompt 层脚手架当产品治理；小样本结论直接照搬。

### 3) AG-UI（Agent User Interaction Protocol，spec 1.0）
- 证据：https://docs.ag-ui.com/introduction （2026 生态扩张：.NET SDK 等）
- 定位：agent↔前端的事件/状态同步协议标准。
- 判断：与我们自研 `workbench-transport`（daemon↔chatd）不同层；对**面板/聊天 UI 与 agent 流式交互**有参考价值；列入观察，不替换现有 Transport v1（协议已冻结、切换在即）。

### 4) 延续：RelLedger / DGF-Bench（前周）
- 结论不变：归因账本+下游回放（RelLedger）、权威记录 vs 叙事分离+对抗验收语料（DGF-Bench）——继续作为研究 spike/QA backlog，不引入依赖。

### 5) 趋势观察：一人公司 OS 竞争加剧
- 信号：Paperclip（控制面）、OneManCompany（产品级 OS）、MiniCorp（模拟+反事实）、Company Brain（Zenodo 公司知识层）同月出现 → 我们"自研 + 去外部依赖 + 打包分发"的方向正确，但**产品化/可安装性**是明显差距，M5 打包优先级应提升。
