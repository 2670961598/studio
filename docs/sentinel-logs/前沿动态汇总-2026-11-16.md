## A. 多 agent 编排 / 公司式组织 / 治理（论文）

1. **RelLedger: Relational Information Governance for LLM Agent Organizations**（arXiv 2610.16281，2026-10）— 面向「LLM agent 组织」的关系型信息治理：信息流、权限、账本关系。与 StudioNext 三事实源/唯一写入者/台账投影/授权链最同题。→ 参考池 #1。
   https://arxiv.org/html/2610.16281v1
2. **When Agent Governance Helps**（arXiv 2609.05531）— 治理机制何时带来正收益（成本/延迟 vs 合规）；可对照我们 shadow/enforce 授权链与 gate 的成本权衡。→ 参考池 #3。
   https://browse-export.arxiv.org/pdf/2609.05531
3. **The Governance Tuple: An Atomic Record for Auditable Agentic AI Decision-Making**（Zenodo v3.0，2026-10-31）— agent 决策的原子治理记录字段集；可与 events 口径逐字段核对。→ 参考池 #1。
   https://zenodo.org/records/23837027
4. **AMEA（Autonomous Micro-Enterprise Architectures）**（Zenodo，多版本）— 微型企业=高并发多 agent 编排+零边际劳动；架构对照参考（并发/预算/审计面）。
   https://www.zenodo.org/records/22129869
5. **From Process Models to Composable Agentic Workflows**（arXiv 2611.13196）— BPMN 流程模型 + agents + 企业知识组合；与我们「提案→文档→过审→代码」流程化组织同构。
   https://arxiv.org/abs/2611.13196v1

## B. 可审计 / 溯源 / 人机协作（论文）

6. **Auditable Human-Agent Teams for Autonomous X-ray Experimentation**（arXiv 2611.12933）— 人机团队可审计协作协议+实验闭环；「证据包+人审介入点」可借鉴到收割验收文档链。
   https://arxiv.org/abs/2611.12933v1
7. **Audit Trails（delegated authority in an agentic payment workflow）**（arXiv 2608.21942）— 授权委托轨迹+审计轨迹案例；对照我们 wkey 六动词授权链与 GW_AUTHORITY_DECISION 证据面。→ 参考池 #2。
   https://export.arxiv.org/pdf/2608.21942

   https://export.arxiv.org/abs/2611.15843
