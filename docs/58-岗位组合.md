## 〇、结论先行

1. **岗位 = 权责原子的合法组合 + 参数。** 合法性判据=docs/57-§三九条；参数={职级、
   预算、幅度、节奏}。组合不合法=这个岗位不存在。
2. **类型=主族标签，不是职能标签（v1.1 修正）。** 一个岗位的类型=它持有的**主原子族**
   （决策/资源/执行/验证/人事/信息/风险/元规则/协作），允许「主类型+副类型」。
   类型回答「这个岗位主要在哪一族行使权力」，范式回答「具体怎么拼」。
3. **规模不增减原则，只增减持有者。** 最小组织不可省的只有两条：**具名责任人** +
   **执行与验收不同源**；其余制衡可合法取消，但取消要用东西换（事后举证/外部锚/
   阈值双签；外部锚的定义见 §四.3，不再是个名词）。

## 一、组合模型

```
岗位（Position） = {
  atoms:      权责原子集合（57-§二），满足 57-§三 组合规则,
  params:     { level（成熟度锚）, budget（帽）, span（幅度）, cadence（节奏窗） },
  interfaces: reports_to / supervises / co_sign / veto —— **派生面**（见下）,
  holder:     任职者（工号）或 空编
}
```

四条组合定律：

1. **权责一体**：每个原子连权带责整取，不得劈开。
2. **空编可见**：岗位无任职者=合法但告警。
3. **模板与实例二分**：岗位配置变更不得改写历史任职者的当时快照。
4. **参数不下沉**：职级/预算/幅度是参数不是原子；同构不同档=同族不同参数。

**派生面规则（v1.1 新增，I14）**：
- `mandate`（职责文本）= **原子组合的人读摘要**，派生，不独立授权；额外职责必须
  映射到原子，否则视为「未授权职责」（写了也不算）。
- `interfaces`（汇报/联签/否决关系）= **原子关系的投影**，派生；若独立配置，
  必须与原子组合一致——判定器做一致性校验，冲突即不合法。
- 这样「岗位=权责组合」才是真的组合，不是「组合 + 一段自由文本」。

## 二、岗位类型（主族制）

类型=主原子族标签。六主型（沿用 55 的六类，但坐标改为族）+ 副型：

| 主类型 | 主原子族 | 典型副型 |
|---|---|---|
| `execute` 执行岗 | C 执行族 | +协作（I2 配合） |
| `coordinate` 协调岗 | C2 派工 + A5/A6 + D7 | +信息（F2） |
| `govern` 治理岗 | D 验证族 + A4 + G | +元规则（H1 标准） |
| `platform` 平台岗 | H1 技术标准 + D10 + C5 | +协作（I1） |
| `intel` 情报岗 | A1 + I1 + F1 | —（不持执行/批准） |
| `watch` 巡检岗 | D5 + D8 + I2 | —（禁业务写动作族；**治理动作——告警/叫停/关卡主持——允许**，与 55-P-8 v1.1 对齐） |

混合型岗位（如部长=执行+决策+人事）取**权力最重的族**为主类型，其余为副型；
新主类型只能在「原子族组合不进现有六型」时增设。

## 四、规模变形与外部锚

### 4.1 规模不变量（12 条底线，任何规模不可省）

具名责任人 ｜ 执行≠验收 ｜ 发起≠批准（阈值以上）｜ 事实与记录分离 ｜ 意图可见 ｜
越权可归因 ｜ 叫停权 ｜ 纠错通道且不因纠错变差 ｜ 同源回避 ｜ 规则变更另有授权 ｜
退出/替换机制 ｜ 外部锚（内部无法分离时）。

### 4.2 规模变形表

| 权责项 | 微（≤5 岗） | 小（≤30 岗） | 中（≤300 岗） | 变形机制 |
|---|---|---|---|---|
| 记录/付款 | 法定仍分设 | 会计/出纳分设 | 财务部+预算岗 | 外化+补偿控制（流水直送老板、月度独立对账） |
| 复核 | 异源互看 | 专职复核岗 | 治理岗族 | 拆「技术复核」与「流程复核」 |
| 批准 | 老板一人（低阈值） | 额度分级 | 双签+合议 | 阈值表+双签+事后审计三重叠加 |
| 法务/审计 | 全外包 | 外部顾问+内部接口 | 法务岗+独立审计 | 执行外化，验收/审计/终止/数据取回权留内 |
| 决策 | 直觉 | 例会 | 委员会 | 人裁→规则裁→委员会裁，每级留兜底终裁 |
| 冲突解决 | 老板裁决 | 升级链 | 异议受理+仲裁 | 升级链必须有终点 |
| 监督 | **可无（合法）** | 一名监事 | 审计委员会 | 从人事监督转向证据监督 |

**「监事可无」与审计链的调和（M9）**：微型组织可不设审计岗，但必须满足其一：
①外部锚（见 4.3）承担审计职能；②举证责任倒置——关键结论自带可复算证据包，
否则视为未完成（一人公司 §23(3) 的启发）。**事前监督可省，可审计性不可省。**

### 4.3 外部锚的定义（v1.1 新增，不再是名词）

- **类型**：外部审计 / 独立顾问 / 客户或监管方 / 行业认证机构。
- **资格**：独立于被审线（无汇报关系、无利益关联、无同一上下文）；
  利益冲突申报；保密义务；报告路径直送制作人。
- **责任边界**：外部锚提供意见与证据，**不替组织承担最终责任**；
  验收/追责/终止三权必须留在内部。
- **选用/更换/付费由制作人决定**，不得由被审方自定（否则=「找个朋友签字」）。

- **I 族**：I1→参谋岗/情报岗/任何岗 ｜ I2→关卡岗/巡检岗 ｜ I3→独立辩护职能
  [按需指定，可外部锚] ｜ I4→各委员会 ｜ I5→披露职能（幕僚长/财务） ｜
  I6→制度保障（规则守护岗监督） ｜ I7→高危动作的两岗（如制作人+安全岗） ｜
  I8→对治理体全员[保留程序] ｜ I9→规范委员会（职级评审）

## 七、岗位生命周期（与人事族的接口）

```
设岗（H3，说明理由与成本）
 → 提名（E1，依据+备选）
 → 任命（E2，程序+理由）
 → 在岗（E3 考核：证据+校准+公示+可申诉；指标来自台账，禁止自评）
 → 变动（晋升 E5 ｜ 降档 ｜ 处分 E6 —— 决策树见下）
 → 退役（E7：离岗回收清单逐项结清——凭证/派单边/订阅/在途单/外部连接/记忆处置）
```

**人事变动决策树（M19）**：绩效持续优+标准达标→晋升（E5，职级委员会）；单次失误
或能力缺口→提醒/降档（S1-S3，上级+人事程序）；违纪/越权→调查（D6）→处分（E6）→
严重者解聘（E7）；治理体成员→除名（H5）或不信任票（I8）。

**记忆生命周期（v1.1 新增，I15）**——三类记忆三种处置：

| 记忆类 | 归属 | 转岗 | 离岗/退役 | 接替 |
|---|---|---|---|---|
| 个人记忆 | 任职者 | 随人走 | 归档（保留期后可删） | 不继承 |
| 岗位记忆 | 岗位 | 留在原岗 | 留岗 | 继任者经审批可读 |
| 组织记忆 | 公司级 | 公开/受控 | 不受影响 | 按密级读 |

读写删除权限：写=提案制（daemon 落账）；删=管理员可删不可改；继承=规范委员会审批。

**绩效归因最小方法（v1.1 新增，I16）**：同工号换模型/换执行体时——同任务配对、
模型版本分层、前后对照、人工校准；「个人绩效」与「执行体影响」分开报告；
高风险岗位跨模型抽样复核，防止「模型红利」被误读为「人的能力」。升降带的证据
必须来自归因后的绩效，否则升降不可信。

## 八、AI 语境的组合修正（v1.1 表述修正）

1. **「换个人」≠「换视角」**：独立性按 57-§五 剖面判定；同模型复核高度相关、
   **不构成独立**（软化表述，不写死数值）。
2. **核查表会退化成装饰**：关卡原子必须四件套齐（持有者+动作+否决后果+证据）。
3. **权限渐变是主风险**：限额到期、例外计数、定期权限复核、按原子组合审计。
4. **责任稀释比错误本身更危险**：建议可流动，责任锚不动；每张单据必须能回答
   「这条建议最终由哪个岗位承接」。
5. **并行独立再比对，不做串行评论**（五花判事的正确形态）。
6. **复核不加刑**（57-I6）。
7. **收入信号不进生产上下文**（编营分离的 AI 版）。
