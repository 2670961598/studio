## 一、这一轮做了什么（时间线）

全部发生在 2026-10-23 一天内，起点是「与 todos.dev 对比」的需求：

1. **对比与前沿调研**：todos.dev 调研（闭源 SaaS 多 agent 工作台）+ Studio Next 自审
   → 结论：两者不同层，对方是「工位产品」，我们是「制度框架」；我们的欠账在工位/
   记忆/安全，对方的空白在组织/台账/治理。（仓内已有 docs/53/54 同题文档）
2. **战略定向**（制作人）：开源基础服务；公司=可移植纯配置 git 目录；executor 以
   DSH 为主（其插件系统能重构 agent loop、拆开岗位能力，其他 CLI 做不到）；规范交给
   社区维护；初期制作人亲自跟。
3. **规范层草案**：产出 docs/55（岗位规范）+ docs/56（框架层规范）——提案流第 4 步
   方案定稿件，**尚未过审**。
4. **需求深挖**（制作人令）：「从权责入手，所有岗位=权责组合；借鉴大公司/小公司/
   古代官制；AI 无恶意，制衡=程序与测试的 battle」。四路调研：现代公司治理、
   中国古代官制、军队/司法/医院/开源等其他形态、组织理论与经济学。
5. **需求四件套**：docs/57（权责说明）→ 58（岗位组合）→ 59（框架制衡）→ 60（agent
   员工模型）。
6. **外部审查**：docs/61（另一个 AI 的管理逻辑审查）——7 处硬冲突、18 处重要问题、
   19 处次要问题；复核结论：审查合格，采纳率约 95%。
7. **v1.1 修订**：57/58/59/60 全部按 61 修订完成，55 同步一处修正（P-8）。

**当时状态（2026-10-23）**：57-60 v1.1 待制作人终审；55/56 待四件套定稿后回流修订；
61 审查已处置完毕。**当时的回流计划已废止，现行接手顺序见本文 §六。**

## 二、整合后的高层模型（一幅图）

### 2.1 总骨架

```
权责原子（57）→ 岗位组合（58）→ 框架制衡（59）→ 员工模型（60）
   谁可以做什么      原子怎么拼成岗      岗与岗怎么制约      agent 怎么上岗干活
```

四件套之下是规范层（55/56，待回流），之下才是实现层（未开始）。

### 2.2 本体四分（60-§一，全体系的地基）

「agent」不是一个东西，是四层：

| 层 | 是什么 | 挂什么 | 持久性 |
|---|---|---|---|
| 岗位 Position | 组织里持久的责任包 | 权责原子、预算帽 | 长期 |
| 任职者 Holder | 工号=员工身份与生涯 | 档案、记忆、绩效、任职史 | 长期（跨会话跨执行体） |
| 执行体 Executor | 可复用执行能力（宿主+模型+工具面） | 能力面、模型指纹 | 跨会话复用 |
| 会话 Session | 一次具体出工 | 任务书、凭证、在途证据 | 单任务 |

四层各答一问：记忆属于任职者；凭证发给会话；绩效算任职者（模型版本是解释变量）；
越权追「会话→任职者→岗位→授权链→制作人」。**仪器不是员工**（无工具只读零生命
周期的判定器不占工号）。责任分三层：运营责任（任职者）/管理责任（上级）/最终责任
（制作人，不可转移）。

### 2.3 权责原子体系（57）

- **三条公理**：①权责可结算（每个权配问责四件套：forum/证据等级/制裁档位/时限——
  forum 五类、证据四级、制裁六档、时限六档）；②权可授、最终责任不可授；
  ③原子性四判据（不可再分/可独立授予/可独立追责/不产生未定义情形）。
- **类型学**：权四型（作为/要求/变更/豁免——霍菲尔德）+ **义务第五元**（对象/触发/
  截止/验收/违约后果）。
- **九族 75 原子**：A 决策（10）/B 资源（13）/C 执行（7，含 v1.1 新增 C7 流程推进）/
  D 验证监督（10）/E 人事（8）/F 信息（8）/G 风险合规（4）/H 元规则（6）/I 协作
  协议（9）。
- **禁配表 25 条**（24 硬+1 软：A5 议程⊥A6 主持为软，配补偿控制）。
- **组合规则 9 条**：一事一裁 / 禁配 / 证据闭环 / 限额参数化 / 可撤回 / **异质验证**
  （同源复核不构成分离）/ 组合算子二选一（切分或合议）/ 过度分离红线 /
  **权力集中度上限**（防藩镇：同岗不得同时持提案+批准+派工+提名+考核决定）。
- **独立性剖面**（全库唯一定义）：模型/上下文/数据源/工具链/时点/指标口径/汇报线
  七维，分强弱；D1 复核至少「模型+上下文」双不同。
- **制衡对象五分**：恶（降级为审计）/错位（新增族，保留）/能（加厚）/相（最高优先）/
  漂（加厚）。威胁模型含人类操作者与供应链。
- 复合模式（三单匹配、三道防线）是原子的固定搭配，不是原子。

### 2.4 岗位组合（58）

- **岗位 = 原子的合法组合 + 参数**（职级/预算/幅度/节奏）；mandate 与 interfaces 是
  **派生面**（原子组合的人读摘要与关系投影），不独立授权。
- **类型=主族制**：六主型（execute/coordinate/govern/platform/intel/watch）+副型；
  watch 禁业务写动作、允许治理动作（告警/叫停/关卡主持）。
- **24 范式**：治理层（制作人/宰相/幕僚长/审计负责人）、部门层（部长·防藩镇版/
  执行/复核/验收/巡检/参谋/情报/关卡）、资源合规线（财务负责人/会计/出纳/对账/
  人事/法务合规/风控/安全）、元治理线（规范委员会/规则守护岗）、系统岗（流程守护岗/
  台账岗——框架自任职，「框架」不再是匿名行动者）。
- **规模观**：原子表不随规模变，只变持有者；12 条规模不变量（最小不可省=具名责任人
  +执行验收不同源）；监事可无但**可审计性不可省**（外部锚或举证倒置）；
  **外部锚已定义**（类型/资格/责任边界/选用权归制作人）。
- **生命周期**：设岗→提名→任命→在岗→变动（晋升/降档/处分决策树）→退役
  （离岗回收清单含**记忆处置**）。记忆分三类（个人/岗位/组织），绩效归因最小方法
  （同任务配对/模型版本分层/前后对照/人工校准）。

### 2.5 框架制衡（59）

- **六链分离**：提案 / 协调 / 决定（审议+终裁，A3 与 A10 在此）/ 执行 / 验收 / 审计；
  族×链矩阵已建；H 族（元规则）在链之上。
- **分离三档**（不是一刀切）：硬分离（高相关×不可逆×检出弱）/软分离（合并但验收
  归他岗）/补偿控制（合并+公开比对/抽样/例外计数）。
- **20 个失败模式→防线**：15 个历史病理（外戚/宦官/藩镇/冗官/票拟批红/台谏合流/
  考课失真/巡按膨胀/留中不发/窃符/内朝/党争/相权反复/信息垄断/程序空转）+
  5 个新增（信息入口垄断/记忆污染/上下文劫持/奖励黑客/供应链投毒）。
- **制作人保留权力 5 条**（含元保留）+**制作人约束 4 条**（自利型禁配同样适用/
  干预日志/自兼时用外部锚/可被移除）。
- **制衡有效性指标**：按风险×事项分层，每指标配反指标，有效果指标（否决被推翻率/
  复核改变结论率）；三条红线（同源复核=0/越权拦截=100%/离岗结清=100%）。

### 2.6 agent 员工模型（60）

- **上岗需求=九主维度+三派生要求**（检查清单，不宣称最小闭集）：身份/任务/授权/
  资源/信息/工具与技能/沟通/证据/反馈 + 记忆（信息×时间）/工位（资源+隔离）/
  边界（授权否定面）。
- **能力分带 G0-G6**：仪器（非员工）/见习执行/正式执行/资深复核/部长/宰相（G5）/
  幕僚长（G6）；类型×带矩阵已建。**带间差异=原子+配置差异，不是聪明程度差异**——
  等级管权责，模型管算力。
- **控制三交集**：实际控制=权责（该有）∩能力（能做）∩凭证（本次拿到）；三者写入者
  各异（公司作者/依赖清单/网关）；禁配在凭证签发时判定。
- **G6 幕僚长**=对接制作人的唯一日常**经营**接口；**直通例外**（审计/异议/辩护/
  不信任票/紧急叫停）不得经手。
- **git 底座（需求级）**：组织事实源+产物版本底座+「没有提交/台账事件的变更视为
  未发生」。

## 五、关键背景（接手者速读）

### 5.1 项目是什么

Studio Next：AI 公司框架（monorepo，本仓）。把「一家公司」建模为代码外部的 git 目录；
框架 daemon 负责唤起 executor（以 DSH 为主）→ 组装上下文（L0-L5）→ 收口写入
（wkey 网关）→ 收割证据与账目（SQLite 台账，append-only 可重建）→ 面板/API 呈现。
三条事实源：协作平台（Taiga/Matrix，YouTrack 已实际弃用）/ 公司 git 目录（daemon
唯一写入者）/ SQLite 台账。六名词（Company/Org/Work/Executor/Ledger/Contract）
三动词（派/批/变）+ 概念准入闸。纪律文档=docs/20（提案流六步、顺序铁律、证据断言、
分层宪法门禁）。

### 5.2 本轮设计的理论锚点（一句话各）

- Fama-Jensen：决策四步（提议/批准/执行/监督），控制与管理分离——57 的 A 族骨架；
- Jensen-Meckling：权与知识共置；组织内决策权不可让渡——授权=可撤回委托；
- Bovens：问责=actor↔forum 关系——问责四件套的来源；
- 霍菲尔德：权分四型——57-§一；
- Grossman-Hart：剩余控制权——A10 的来源；
- 三省六部：提案/审议/执行三分——六链的古典对应；封驳=A4 否决的原型；
- 虎符/用印：双人控制与凭证绑动作——I7/B13；
- 考课失真：无校准的评分必然全员中上——E3 四件套；
- 票拟批红：批准者无责则制衡不存在——59-#5；
- WHO 核查表：关卡主持四件套（持有者+动作+否决后果+证据）——I2；
- 军队参谋制：建议可流动、责任锚不动——I1；
- EP-QUORUM：批准延迟落账反橡皮图章——59 指标；
- DORA：重型审批委员会不降低变更失败率——过度分离红线（启发式引用）；
- PACE/Self-Healing Harness：验收器优先于驱动器；55% 提案「修好 A 弄坏 B」——
  56-EVO 组的实证底座；
- 评测集=供应链、Library Drift、HEARTBEAT 记忆污染——56 的 EVO-2/EVO-6 与 59-#17。

### 5.3 竞争与生态坐标（一句话）

todos.dev = 成熟单主人工位产品（不同层，不是纯竞品，是潜在 executor 供给面——它已
支持 dsh）；Gas Town/OpenClaw = 个人/小队编排器（无职级无编制）；Workday ASOR =
企业合规面（管账不管派工）；Org as Code/OPI 与 ODL = 2026 年新生的「公司即代码」
同类尝试（单人项目、无采纳证据，但说明**规范先发的窗口在关闭**）。
「职级+派单律+批示流+可重建台账」四件套在公开产品中无人做——这是差异化，也是
无参照系的风险。
