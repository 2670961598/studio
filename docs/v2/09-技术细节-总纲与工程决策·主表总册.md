## 〇、读法与主表纪律

1. **三张主表一处定义**：ID 族总表（§一）、枚举唯一主表（§二，条目前缀 `ENU-`）、术语表（§三，条目前缀 `TERM-`）——他卷只许引 ID（`ENU-NN`/`TERM-NN`/族 ID），不得重述值集或另立同义字面量。枚举字面量分**机器值**（英文 snake_case，落盘/交换用）与**显示名**（中文，人读用）；两列一一对应，本表即唯一来源。
2. **占位兑现**：各卷「取值/值集/枚举/状态族……（唯一）主表/登记 v2/09」类占位（全库 grep 计 154 处，分布于 14 个已成卷；00/01 无）逐一对号入座到 §二某 ENU 条或 §一某族；兑现核对见 §七。
3. **新增与修订**：新增族/枚举值/术语/决策一律先登记本卷（走 v2/00 §五 提示流；码值只增不改义，同 v2/10 §5.5 词表纪律）；修订冻结门 F2/F6 验收口径的对象正是本表。
4. **审计引证族不是规范 ID**：H0a/V8/L3J/P0-1 之类为 C 类证据件（00 §三）引证约定，值域定义在 83-审计-GLM/ 与 audit-DSF/ 自身，不适用裸字母禁令、不入 §一登记（见 §1.4）。
