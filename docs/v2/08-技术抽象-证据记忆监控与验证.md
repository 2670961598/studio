## 〇、读法与边界

### 0.1 职责边界

| 关系 | 本卷义务 | 本卷不做 |
|---|---|---|
| 对 v2/01 | 只引用 I 族/R 族与 §5.2 纪律 | 不重定义事实、证据、验收、独立性的概念本体 |
| 对 v2/02 | 提供个人记忆域对象与访问留痕义务 | 不重列个人记忆四子类、任职与绩效归因 |
| 对 v2/03 | 提供独立角色资格判定与供给机制 | 不设组织位置、不定任免（表 C/表 D 唯一主表在 03） |
| 对 v2/04 | 提供证据对象本体、收割者资格、观察面与观察对象 | 不定完成判据分级、验收程序、状态机、观察义务的义务侧；不另立事实源域表（v2/05）、记录字段形状（v2/11）与验证矩阵（v2/17） |

### 0.2 否定式（四条，贯通全卷）

1. **记录不是事实，证据不是真相**：记录存在不证明内容为真，没有记录不等于未发生（I-2）；内容逼真、格式齐全、签名有效都不单独排除伪造与俘获。
2. **派生物不得反向僭越**：监控、摘要、记忆、评分都是历史的派生物，不得反向改写历史或自封第二事实源。
3. **自供不成独立**：交付方自己采集的要素、自己选的样本、自己执行的检查只是材料与线索；凡要求「独立」的位置按 v2/01 §5.2 功能标准判定，不由名称、账号、模型或数量决定。
4. **判断留痕且不互推**：每个判断留判断者、依据、范围、时间与异议位置；执行成功、记录齐全、面板全绿、多 agent 投票都不能冒称独立验收，接受不推出结清（v2/04 §六）。

### 0.3 前缀族与标注约定

- 唯一主表 ID 族：`EVD-`（证据对象）、`MEM-`（记忆对象）、`MON-`（监控对象与观测面）、`OBS-`（持续观察对象）；枚举值主表在本卷、统一登记 v2/09，他卷只引 ID；记录形状（REC-EVD/MEM/OBS 族）归 v2/11，负向用例与断言归 v2/17。
- 〔设计〕＝可按公司事前规则替换；〔逻辑结论〕＝由 v2/01 推出不得删除；**目标（未证）**＝机制未建成，禁止「已保证/机制保证」语气。84b 抉择 6 三项未决（EX-3..6 精确边界、抽样比例、独立收割最小主体）本卷只冻结结构与缺省方向。

## 一、证据对象（EVD- 族）

### 1.1 证据包（EVD-PKG）

证据是关系，不是文件堆。**EVD-PKG** 的目标是让未参与者重建：权源→判断条件→行动→结果→未决；引用须能定位原始材料及其形成时间、来源与知悉范围。材料多不等于充分；证据充分性由合法验收位置或事后审计位置按事前口径判定，**不得由交付方单独宣布**（v2/04 §六）。

### 1.2 八要素（EVD-ELM-01..08，唯一主表）

| ID | 要素 | 回答什么 | 独立性来源（EX-2+ 必须非作者产出） | 缺失/不适用表示 |
|---|---|---|---|---|
| EVD-ELM-01 | 权源 | 谁在何授权与合同版本下行动 | 授权链记录（台账域，daemon 唯一写入者，v2/05） | 缺失→不得视行动为有权，转调查实际责任 |
| EVD-ELM-02 | 输入 | 用了哪些来源、假设与当时信息 | 交付方自述（线索级）；敏感面关键输入独立可采 | 缺失→区分判断错误与信息不足，标注不确定 |
| EVD-ELM-03 | 行动 | 关键动作、实际主体、时点、回执 | **收割批次与宿主回执（EVD-HVT）独立采集**；自述仅线索 | 缺失→不得凭最终产物倒推合法过程 |
| EVD-ELM-04 | 验收对象 | 判的是什么（分六类结果面：产物/状态/学习交付/事实链/无残留/承接确认，v2/04 §二/§七） | 对象版本引用可独立复算；EX-2+ 由收割者采集 | 缺失→无验收对象，验收不成立；维持/探索类按各自口径，不套产物模板 |
| EVD-ELM-05 | 自检 | 交付者检查了什么、发现什么 | **恒为交付方自述——这是属性不是缺陷**：自检不构成独立验收（W-03） | 缺失→记为未自检 |
| EVD-ELM-06 | 外部反馈 | 相对方/受益者/受影响者的接受、异议与影响 | 独立通道（相对方直连、I-15 异议通道），不经交付方转述 | 缺失→不得宣称外部价值或无损害 |
| EVD-ELM-07 | 代价 | 预算、时间、返工、空转、外部成本与残留 | 台账事件（唯一写入者） | 缺失→不得只按成功产物结算（I-3） |
| EVD-ELM-08 | 未决 | 已知缺陷、承诺、条件、争议与承接 | 结清核验位置独立采集（v2/04 §六，核验者≠责任者） | 缺失→不能宣称结清 |

「不适用」是合法取值但**不得空着**：须记不适用＋理由＋判者（84b 抉择 6），否则分级退化为填表（W-13）。

### 1.3 来源锚（EVD-ANC）

每项要素逐个给**来源锚**：谁采集、能否独立复采、缺失时写什么。证据来源分级＝`独立采集`｜`自述`〔枚举主表本卷，登记 v2/09〕：

- **独立采集**：由非作者位置或独立机械通道（收割批次、宿主回执、闸门退出码、台账事件、相对方直连）取得，可独立复采。
- **自述**：由交付方形成或填写。**自述证据不得单独支撑 EX-2+ 验收**；验收须能逐项区分两类来源（对账差异非空即判负，验证行 → v2/17）。
- 要素状态三态（值集唯一主表 v2/09 ENU-50）＝`present`｜`not_applicable`｜`missing`：`missing` 退回补件并传导下游判断（外部缺→不得判无损害；代价缺→结清「资源」项列保留；验收对象缺→仅探索/维持类按分型口径）；`not_applicable` 凭理由与判者放行并降级相应结论。补证与追认保留真实形成时间。

### 1.4 收割批次（EVD-HVT）与 EX 各级证据最小集（对象侧；84b 抉择 6）

| 级 | 证据最小集 | 采集者 |
|---|---|---|
| EX-2+ | **四要件**（终态事件＋非空输出＋REPORT 落盘＋闸门 exit=0）＋敏感面要素（EVD-ELM-01/03/04/06/07/08）独立采集＋EVD-ANC 两级来源逐项标注 | **独立收割者**（收割者≠交付者）；交付方申报只是输入 |
| EX-0/EX-1 | 终态（框架收割，**目标（未证）**）＋自报＋抽样复核（样本不得由被查方安排）＋不适用要素合法表示 | 终态=框架；自报=交付方；抽样=审计侧位置（表 C 上一层的周期职责） |

- **收割完整性规则**：收割批次是 EX-2+ 验收判断的**强制输入**；收割缺失或完整性存疑时不得判接受，除非记录补偿控制、独立复核位置与期限。
- **独立收割者资格**：收割者≠交付者是关系要件；最小主体形态＝84b 未决；单人/低层形态由承载审计职能的上一层位置采集并**明示标注**，不得自称独立于其自身交付物（同 §2.4）。
- **维持/无产物工作的证据形态**（K4 对象侧）：双指标材料＋独立抽样核验记录＋三段证据（避免类）引用构成法定闭合证据（判据四件 → v2/04 §七）；收割四要件不适用时按「不适用＋理由＋判者」表示，**不得以四要件替代维持验收记录**（W-07）。

### 1.5 五类判断不合并（对象表；程序 → v2/04 §六）

| 判断 | 证据对象 | 不能推出 |
|---|---|---|
| 执行结果 | EVD-HVT 终态与四要件 | 完成、验收、价值 |
| 自检 | EVD-ELM-05（自述） | 独立验收 |
| 独立验收/事后审计 | 验收结论（v2/11）＋EVD-AUD（§1.6） | 长期价值、相对方满意、已结清 |
| 价值/履约评价 | 价值复盘材料（§1.7） | 改写原验收或隐藏违规过程 |
| 结清 | 结清清单逐项证据（v2/04 §六，含派生面 EVD-RVK） | 由接受或价值为正推出 |

三组易混集合不可互推：受理五取值（v2/04 §二）、工作十态（v2/04 §五）、验收四取值（v2/04 §六）分属入口决定、过程状态、终局判断，绑定映射时不得直写。

### 1.6 事后独立审计对象（EVD-AUD）

EX-0/EX-1 闭合第三段（自检＋可复核证据＋**事后独立审计，不可省略**）的对象载体：

- **结论集**＝`无违规`｜`发现违规`｜`证据不足`〔枚举主表本卷，登记 v2/09〕——**禁用验收四值**，审计不是第二次验收。
- 审计者资格按 §二 功能标准判定，独立性依据由不直接受被审计方控制的位置出据，**自填即拒收**；附期限与逾期去向：逾期未审计＝异常（MON-12）并按 v2/04 §五升级，已生效低档结论不因逾期回溯失效，但须重验并公开标注「未经事后审计」。记录形状 → v2/11；追溯行 → v2/17。

### 1.7 价值面（对象侧；v2/04 §四/§六 引位）

- **价值＝结果对使命与受益者的实际意义，含负价值**：失败、返工、空转、外部损害按负价值入账，好结果不洗掉违规过程与隐性成本（I-3）；内部验收只是价值证据之一。价值结论由 v2/04 价值复盘作出，绩效归因归 v2/02 §九，本卷只承载价值/代价账的对象（→ v2/11）。
- **不可接受、不可补偿损害的认定**不由公司或受益委托方单独决定：依公共规则、事前合法约定的受影响者代理或独立裁决确认（I-15）；争议期间不得以内部收益或后续补偿抵销；损害正在发生时先停止影响、保全、披露并接受独立评价，再处理修复、救济与责任。难以量化的价值（信任、尊严、长期期权，R-13）用有理由、可异议、可复审的定性判断，不强造虚假精度。

### 1.8 撤回完成的证据对象（EVD-RVK；治 DSF P0-12/85c-Q9）

**撤回完成＝后代清单＋停用证据**（I-6），缺任一项不得称撤回完成：

1. **后代清单**：派生执行体（子 agent/子进程/会话快照）与被复制、被注入凭据的枚举，逐项带身份标识、持有凭据类别、终止或围栏证据；
2. **停用证据**：凭据停用的机制性证据（机制归 v2/15：撤回网关、围栏、secret 继承策略）；
3. **无后代的显式确认**：无后代时也必须声明「如何确认无后代」（探测方法与最后探测时点），不得留空视为零；配合工作侧结清「派生面」判据（v2/04 §六）、交接包第⑩项（v2/04 §十）；撤回后仍存活的执行体进入 OBS-02 持续观察。

## 二、独立性供给机制（治 DSF P0-5/GLM K6/85c-Q4）

### 2.1 功能标准（引 v2/01 §5.2，不重述）

独立性由**证据来源、判断过程、利益关系、错误相关性**判定；同源位置须声明能力来源并作错误相关评估（R-36）；选任、替换与独立性争议不由被验方/被审方/提案方单独决定，由不受其直接控制的上一级位置或宪制指定位置处理。

### 2.2 独立角色资格判定与供给表（本卷唯一主表）

| 独立角色 | 资格判定 | 常态供给（v2/03 表 D/C） | 低层/单人形态 | 不可得时处置 |
|---|---|---|---|---|
| 效果级首判/风险分类 | 分类者独立性按验收者同款功能标准 | 行 13：交付方 +1 | 缺位或存疑→**按高档**（EX-2+） | 不得自评低档（R-31） |
| 验收 | 验者≠交付者 | 行 5：交付方 +1；与本次评价同体按 03 §4.3 上提 | 上一层直至外部老板 | 存续必需→R-34 公司级处置 |
| 独立收割 | 收割者≠交付者＋可独立复采通道 | 框架收割机制（独立于交付方的机械通道，§八）＋表 C 上一层核验；最小主体＝84b 未决 | 由承载审计职能的上一层位置采集并**明示标注** | EX-2+ 不得按自报闭合（W-13） |
| 事后独立审计 | 同 2.1；结论集专用（EVD-AUD） | 表 C：部门=所属一级单元首长（单元缺位/不单设＝最高宰相；冲突上提最高宰相）；公司级=最高宰相自审（标「内部老板自审」）；独立审计=外部老板/外部锚 | 单人形态＝最高宰相自审**明示**、不得自称独立；唯一独立审计来自外部老板/外部锚 | 逾期→异常并标注「未经事后审计」 |
| 独立记录 | 记录者相对交付方与受益方满足禁配（I-17） | 行 15：台账唯一写入者＋最高宰相问责 | daemon 单写入者即最低供给 | 记录者=交付方的记录判负 |
| 记忆处置 | 处置者≠被处置者 | 行 10：个人记忆=任职链 +2；行 11：公司知识=最高宰相/部长 | 未设岗→保留承载 | 不得由「管机器的人」兼任 |
| 持续观察者 | 不由交付方单独担任 | 终止决定指定；未指定=保留承载（外部老板/最高宰相） | 同左 | 观察悬空＝W-14，不得宣称闭环 |

### 2.3 与分层审计矩阵的接线（84b 抉择 4）

- 部门层：上一层审下一层，审计者≠本次评价者（v2/03 §4.3）；审计与验收共用表 C 行位但结论对象不同（验收对事前口径，审计对合规与异常，EVD-AUD）。
- 公司层：当前态＝**最高宰相自审**（最高宰相即内部老板），明示登记「内部老板自审」、**不得自称独立**；**唯一独立审计来自外部人类老板/外部锚**。外部锚（董事会/定期外部审计/宪法程序至少一个非最高宰相主体）＝**目标（未证）**，建成前登记 v2/17 缺口表（85c-Q4）。一级单元首长（G8）＝最高宰相审计；若最高宰相同时是本次绩效评价的提议者，按「本次评价回避」上提外部老板/外部锚，或跨单元首长互审。
- 审计者产出发现与建议；处置决定权在被审计对象的任免者（v2/03 §4.4），审计者仅有限紧急冻结权。

### 2.4 独立性不可得时的处置（R-34 分流＋补充规则）

1. 非存续必需的 EX-2+ 事项：明示不能，终止或升级——**不得降档自报完成**。
2. 存续必需事项：触发公司级处置（变更宪制、引入外部验收关系或终止公司），按 R-34。
3. 单人/低层公司（CL2-CL3）：EX-0/EX-1 以「自报＋抽样复核＋EVD-AUD 事后审计」合法闭合，但不得对外表述为「已通过独立验收」（v2/01 §2.3 顶层诚实条款）；**无外部锚时不得对外承诺 EX-2+ 面的自治履约**。
4. 机械可复算事实（闸门退出码、内容哈希、宿主回执）可作独立性来源之一，**不等于判断独立**：符合性判断仍须由具备 §2.1 功能独立性的位置作出；探测、生效与吊销验证属可复算事实时，自报仅作线索（治 H2b-P1-2）。

## 三、记忆对象（MEM- 族）

### 3.1 三域归属（唯一主表）

| ID | 域 | 随谁 | 谁有权写 | 明确禁止 |
|---|---|---|---|---|
| MEM-01 | 个人记忆 | 任职者 | 任职者于自身工作事实、反馈与复盘中形成（子类枚举 → v2/02 §八） | 离岗自动交给继任者；公司宣称绝对所有 |
| MEM-02 | 工作记录（出工记忆） | 工作及其责任关系 | 工作责任关系内按 v2/04 §十一形成（每条标来源/置信/未决；传闻与未验证推断不得写入） | 离岗自动转个人记忆；以修正代替结清 |
| MEM-03 | 公司知识 | 公司（岗位知识=部门范围；组织知识=公司范围），不随某届治理者 | **经确认才入**：岗位方法由岗位自身沉淀、组织知识经最高宰相/部长分层确认（最高宰相确认属「内部老板确认」，须标注）；个人技能升级走 §六变更链，不自封标准 | 以多数摘要覆盖原始事实或上位规则 |

记忆是历史的派生物（v2/01 §一）：可作查找证据的线索，引用前核原始来源与时效；不得替代验收证据、不得直接用作绩效归因（v2/02 §九）。

### 3.2 处置七件事的授权（归属/形成/访问/继承/修正/清除/争议）

授权位置唯一主表在 v2/03 表 D 行 10/11；本卷补对象侧规则：个人记忆处置由任职链 +2 独立审查（回避、异议、保留期、不可恢复后果告知）；岗位/组织与出工记忆由最高宰相/部长按范围处置（最高宰相处置为公司内部老板处置，受外部审计抽样）。**操作系统账号、仓库管理权、文件读写都不是处置授权**——能读写只说明技术访问能力。修正保留原文、理由、来源、时间、影响范围与授权；**责任记录、承诺、证据、历史、权利相关信息与审计线索不得借记忆清除消灭**。

### 3.3 访问留痕与使用限制

每次访问留审计痕：谁（任职/位置/程序）、何时、为何目的、读了哪域哪些条、用到哪件工作或决定、授权依据与到期——只统计读取次数或命中率不算访问记录；知悉范围变化须重新审批。唤醒与心跳不自动获得写入长期记忆的权限（防循环自证与污染放大）；使用按任务需要与知悉范围最小化，不以「以后可能有用」全量注入。

### 3.4 记忆污染与传播防御（MEM-04；治 R-33）

污染（错误经验、同源盲点、被污染规则）发现后的对象化处置链：

1. **隔离来源**：暂停相关记忆条目与派生规则的使用，不得先删后查；
2. **追溯传播半径**：沿引用链（哪些决定、工作、下游记忆引用过）标定受影响范围；
3. **受影响决定批量标记与责任**：已据其作出的验收/决定按新证据标准批量重开（受理 → v2/01 §5.4，限定影响范围）；确认环节的责任位置对未识别污染承担相应责任；
4. **痊愈判据**：撤回率、多轮后验与退化比较（v2/01 §七），**不得仅删除最近一条错误经验宣布痊愈**；指标提升可能来自任务结构变化或判据被改（R-8）。

### 3.5 终止类事件的记忆分流

| 事件 | MEM-01 个人 | MEM-02 工作记录 | MEM-03 公司知识 |
|---|---|---|---|
| 任职结束 | 归档并按保留期处置；承诺与关系记忆随交接移交 | 随工作移交或按合同保留，不转个人 | 不变 |
| 岗位撤销 | 转岗则重评范围 | 未结工作与未决事项一并移交，须接收确认 | 岗位知识并入承接位置或按治理决定封存 |
| 公司清算 | 按保留期；责任/证据/救济材料不得清除 | 进清算包移交 | 按处置决定执行，未完成移交不得宣称结清（I-16） |

工作终止时三路分流（归档/清除/转出）未完成不得结清（v2/04 §六/§十一）；恢复出厂式删除、停索引、丢弃向量库都不构成合法结清。

### 4.1 投影六态（MON-ST；枚举主表本卷，登记 v2/09）

### 4.4 读面写面隔离与监控故障（一等观察）

面板与监控默认只读；外部请求、异议、审批或操作命令进入独立入口，按身份、授权、幂等与证据流程处理，不因来自管理页面而默示合法；多公司视图按公司与知悉范围隔离；读侧游标、幂等键与偏好是局部操作状态，不得混入权威历史或成为第二事实源/隐蔽写路径；据此限制新动作时，只能由信息门、预设叫停位置或事前授权的 fail-closed 策略执行并留授权依据与具名判断主体。**监控故障是一等观察，不是沉默**：采集中断、覆盖缺口、投影失败、来源不可达均入观察层记录（发生与发现时间、影响范围、受影响视图、最后可信游标、恢复与根因）；受影响视图期间必须显示未知/受损，不得留空、显示为零或沿用最后一张健康快照；监控故障不得篡改事实记录，也不得被当成「外部事件没有发生」。

## 五、持续观察义务（OBS- 族；治 H2b-P0/GLM K7）

### 5.1 迟到副作用观察对象（OBS-01）

义务侧四要件在 v2/04 §八；本卷定义其对象侧：

1. **观察者与资格**：由发起终止/撤回的位置在终止决定中具名指定；资格＝不由交付方单独承担（§2.2 表末行）；未指定＝保留承载（外部老板/最高宰相）。
2. **窗口与终局条件**：观察窗口、最后可信观察点事前声明；到期或窗口内连续无新副作用时**必须作出「观察结束」决定**（OBS-03）。
3. **观察记录**：观察对象、窗口、所见、终局依据、升级标记（记录形状 → v2/11）。
4. **升级与处置**：窗口内新副作用→能归原工作的按 v2/04 §六重开，不能归的按新事项受理；一律先止损、保全、说明（不可补偿损害不得用收益抵销）。**无终局的持续观察本身是异常**，进入 v2/04 §五强制出口。

### 5.2 孤儿执行体观察对象（OBS-02）

父任务终止/撤回后仍存活的派生执行体（子 agent、子进程、被撤回授权的会话）：**活性信号**（最后进展时点、资源脉冲；**目标（未证）**：活性采集通道属施工件）；**凭据状态**（持有什么、是否已被围栏/停用，对照 EVD-RVK 后代清单）；**独立发现通道**（围栏拒绝记录、平台活动流、写入审计的交叉对照——**不依赖执行体自报**，治 H2b-P1-6/P1-7）；**最后可信观察点**（不可达或不可观测的执行体按「未知」处理（MON-ST），不得记为「已停止」）。

### 5.3 观察结束是有据决定（OBS-03）与分工

观察结束不是遗忘：须引用窗口内所见与终局依据；结束后登记残留风险与再触发条件（同类副作用再现时按新事项受理并回查原观察记录）；重开路径与污染类批量重开（R-33）共用 v2/01 §5.4 受理。分工（防双主表）：义务侧（触发/四要件/工作面处置）＝v2/04 §八；对象本体、观察者资格与观察面行（MON-10/11）＝本卷；记录形状＝v2/11；凭据停用与围栏机制＝v2/15；验证行（观察悬空判负、活性断言）＝v2/17。

## 六、变更链段名（唯一主表；v2/04 §十一 引位，治 V6-P1-1）

```text
事实/异议 → 候选（方法/记忆/能力包/配置/规则/代码/全新框架）→ 实质分类（v2/01 §5.4）→ 验证授权 → 独立验证 → 激活批准 → 受控生效 → 后验观察
→ 保留 / 停止 / 恢复 / 修复 / 再次修正 → 链后义务
```

- **段名与次序唯一主表在本卷**；段名记录锚（激活批准/受控生效/后验观察三段的记录族）→ v2/11；方法沉淀的决定不得只落泛型决定记录而无激活/后验语义段。
- **三门不合并**：验证授权（允许对什么范围用什么判据验证）、独立验证（结果）、激活批准（是否允许生效）可由不同位置作出，但**都不能由被进化对象及其直接受益方单独作出**；不得以「验证已通过」替代激活批准，也不得倒推。
- **候选无特权**：「只是提示词/依赖升级/生成一个工具/生成一个框架」不自动降低分类；生成物接管公司运行须走权威迁移与退出验证（引位 v2/12/v2/16）。
- **链后义务**：凭据轮换、旧版本退役与清理须逐项留完成证据与残余清点（MON-13/14）；移除依赖不得只从清单删除。

## 七、事件溯源与可重建边界（84b 抉择 7）

1. **新数据走事件溯源**：成本、工时、证据、结清先写 append-only 事件（daemon 唯一写入者），汇总表是投影，**事件可重建投影**。
2. **记录视图降级**：records 是台账的记录投影，**不是第四事实源**（抉择 1；分域权威表唯一主表 → v2/05）。
3. **钱账限域**：历史 `cost_daily` 为遗留快照——只备份、不重放，明标「遗留不可重建」；「一切派生视图可重建」限域为「事件与记录可重建；资金/不可逆快照只能备份恢复」；钱账域在权威表**单列一行**，不塞进「台账=视图」总则（85c-Q6）。
4. **防篡改**：记录链防篡改（哈希链或等价物）建成状态＝**目标（未证）**；建成前 I-17 的规范要求照常生效，以「未经防篡改」登记 v2/17 缺口表。
5. 重建判负样例（改遗留快照应被拒、删库重建后金额一致性可判）→ v2/17；重建与对账工程面 → v2/16。
