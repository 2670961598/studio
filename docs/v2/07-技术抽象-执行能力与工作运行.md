## 〇、职责边界与总原则

| 关系 | 本卷义务 | 本卷不做 |
|---|---|---|
| 对 v2/02 | 供给能力件运行链（声明/探测/替换/吊销）、出工段执行配置 | 不定义任职资格链、身份、绩效（资格认定引 02 §五） |
| 对 v2/03 | 执行侧权效事实（运行时是否照锁定计划暴露） | 不定义授权权源、禁配、问责 |
| 对 v2/04 | 运行行为与十态迁移边的生产者映射、终态收割输入 | 不定义任务状态机、验收、结清（引 04） |
| 对 v2/06 | 执行器专属/通用资产的能力语义 | 不定义资产对象、传播、必备清单 |
| 对 v2/08/11 | 逐对象给证据义务与记录引位 | 不定义证据本体、记录字段 |
| 对 v2/12/14 | 定语义与闭合判据、端口维度要求 | 不落探针步骤、绑定档案、文件锚 |

**总原则（六分账，承接 v1 §〇）**：能做、被认定能做、这次配了能做、这次有权做、运行时真的这样做了、实际做成了——是六件不同的事，**相邻两项不得互相冒充**；其中「有权」与「真的这样做」必须分账举证（前者答有没有权这样用，后者答运行时暴露的是否真是锁定计划里的那套）。**能力、工具与任职者不能互相顶替**：任何绑定（模型/agent loop/CLI/插件/沙箱/远程服务）只是能力的组成与挂载方式，不是任职者、不是权源，不因被安装或写进提示词而取得资格或授权；绑定失效是能力问题，责任仍落任职者与治理位置（引 02/03）。

**不虚构兼容**：不要求任何宿主具备所有能力；不能暂停/恢复/快照/取消/替换都可以是真实限制；禁止的是隐藏限制，或用降低验收、扩大授权制造「兼容」（诚实路径见 §三末）。

### 能力状态链（从声明到生效不得合并；十三态值集唯一主表 v2/09 ENU-73，本表为分组语义视图）

| 状态号（ENU-73） | 状态 | 含义 | 不能推出 |
|---|---|---|---|
| 01 | 已声明 | 某来源声称有/公司提出需求 | 声明真实、兼容、可信 |
| 02·03 | 已解析·已供给 | 约束求得候选解；能取得发布物 | 已取得内容、可运行、获准使用 |
| 04 | 已安装/已落位 | 内容复制或指向受控位置并有登记 | 来源已核验、宿主已承认、可加载 |
| 05 | 来源与完整性已核验 | 发布者/摘要/许可/传递依赖独立核对一致 | 内容安全、宿主兼容 |
| 06·07 | 已加载·已探测 | 宿主承认并初始化；在指定环境观察到实际行为 | 全任务全时有效 |
| 08 | 已认定资格 | 认定位置承认具备资格（认定≠任免；职级高或声明在先不等于资格，v2/02 §五/E-11） | 已纳入计划、已授权 |
| 09·10 | 已纳入执行计划·已授权（待生效） | 本次出工锁定能力组合与边界；本次权源允许 | 已运行、验收通过 |
| 11 | 已按计划生效 | 运行时实际暴露＝锁定计划，且有可核验证据 | 授权仍有效、工作完成 |
| 12·13 | 授权撤回/到期·运行时偏离 | 权源已收回或到期；实际暴露与锁定计划不一致 | 运行时已停止、已发生副作用消失；偏离无害 |

**状态号编号唯一源＝v2/09 ENU-73（01..13 连续）**；本表按语义分组合并展示（治 09 §六-3：v2/12 §1.6 以「第 4/5/6/8/9/10/11/13 态」数字引用，编号以 ENU-73 为准）。环节不适用（如远程服务无安装、纯声明无加载）记「不适用＋理由」，不得虚构日志；任一必需环节无法证明→缩范围、补证、替换或拒绝。

**三失败面各有处置，不得用「反正批过了/装上了」掩盖**：①已授权未生效→查加载/配置/绑定，能补则补证生效，不能补则缩范围/换能力/暂停，已消耗如实入账；②已生效但授权撤回/到期→立即停新动作、撤运行时访问、围栏旧写入、清点在途影响，不得以「已跑起来」延续授权；③运行时偏离锁定计划（缺失/降权/额外能力/版本来源不符）→立即降级或暂停，额外能力按未授权处理并隔离，偏离出范围须重走开工五门（v2/04 §四），不得事后追认。**偏离发现的触发时点至少含：段开始、段边界、秘密注入时、变更后验**（持续观测面 → v2/08；治 H2b-P1-1）。

### CAP-02 探测

- 探测＝在指定环境与范围内观察实际行为；结论只覆盖被探测的范围/版本/时间，不得外推。
- **采集者独立性规则（治 H2b-P1-2）**：运行时暴露证据、可用性探测、吊销生效验证属**可复算事实**，须由宿主回执或独立探测通道取得；交付方/执行体自报仅作线索，不得冒充「已生效」证明。
- 探测报告与回执的记录承载 → v2/11（REC-CAP 族扩展，登记 v2/09——方向已定，字段未写）；**探针步骤与清单唯一主表 v2/12**，本卷不定义。

### CAP-03 替换

替换＝能力变更的生效事务：触发与保全→影响评估（任务/信息/权限/承诺/证据/资格/在途副作用）→交接与互斥（安全边界暂停或完成当前段，围栏旧写入）→资格处置（实质变更先重认，v2/02 §五；非实质只登记）→新段锁定新计划→后验比较（配置红利不得归因为任职者绩效，v2/02 §九）。**更换执行能力不换任职身份、不清历史、不重置禁配**（I-10 锚点）；新承接者/新执行配置重走五门（v2/04 §四）。生效级别（以何种热更级别落地）＝H 族（§六）。围栏（fencing）是技术手段，不等于激活批准，也不等于业务批准。

### CAP-04 吊销

- 触发：到期、条件未满足、实质变更未重认、事故、认定被推翻、授权撤回（权源 v2/03）。
- 吊销＝资格范围关闭＋**运行时停用验证**：须验证运行时确实拿不到（撤销句柄、停止注入、围栏旧凭据），不得只在清单删一行；迟到的旧凭据使用与残留副本属后验对账范围（观察面 v2/08）。
- **链后义务**（凭据轮换与吊销、旧版本退役与清理）：不扩充变更链主答（v2/08），但其权源、范围、证据与完成判据逐项保留——「移除依赖先停新分配并处理在途，再吊销运行时访问、停用、清理」；完成无据可查时不得宣称移除完成（治 H2b-P1-4；记录 → v2/11）。
- **后代枚举与停用义务** → §四（治 DSF P0-12）。

## 二、DSH 主绑定边界（84 裁决一）

**宪法口径**：DSH 是**默认且未来主力执行器**；绑定 DSH 是设计特色，不是债务。其他 CLI 可作备选，但**必定失去框架提供的部分功能——这是明示代价，不是缺陷**（84 D1）。**DSH 主绑定但不是公司本体**（84b §5.1）：正当性、公司账、验收、问责、跨框架规范留在框架侧；DSH 承载机制层（工具面/沙箱/审批/岗位运行时投影/事件）。公司可换执行体，但按明示代价换。

### 2.1 能力二分与备选 CLI 适配契约

| 类 | 能力项 | 备选 CLI |
|---|---|---|
| **通用（必达）** | 原生终态字段判定、流式事件收割、工作区路径挂载、会话续跑（或明报降级新派）、事件导出（JSONL 兜底）、能力声明不超证据（拟稿按不支持处理） | 适配契约必达，缺一不得接入 |
| **DSH 专属** | 岗位运行时策略投影下发（工具白名单/逐调用判定/审批/沙箱模式）、进程内子 agent 衰减、persona/preset 岗位族、会话检查点（副作用前持久化）、position 类事件面、DSH 插件资产（v2/06 执行器专属资产） | **明示不可用**，逐项落绑定损失清单 |

**备选 CLI 适配契约四条**：①通用能力必达；②专属能力逐项明示「不可用」并落**绑定损失清单**（记录 → v2/11；损失面显性，不得宣称等价承载）；③换宿主＝新出工段＋能力重认＋开工五门重判，在途工作钉旧计划；④**强策略岗位只能派给声明策略面可用的宿主，无解不派工（fail-closed），不得静默回落默认家**。特化公司可声明必备资产（接收方须具备相应执行器，引 v2/06）。

**执行器选择链**：单据指定＞岗位绑定＞默认（默认＝DSH）；**选择不是授权**（选择只回答「这单由哪家跑」，权与禁配另判 v2/03/04）；异源独立性（QA/复核用另一家、不同模型/上下文/会话/凭据）由单据指定支持（判据引 v2/02 §五/04 §六）。选择算法与端口 → v2/14（目标未证：现状唯一路径为默认＋模型档）。

### 2.2 效果级 × 执行位置（78a 按新模型重映射，84b §5.3）

效果级唯一主表 v2/04（EX-0..EX-6，EX-2+＝高侧）。执行位置缺省（精确映射＝〔设计〕）：

| 效果级 | 缺省执行位置 | 说明 |
|---|---|---|
| EX-0/EX-1 | 宿主内（沙箱/工具白名单约束） | 低侧尽量宿主内，减少外部审批 |
| EX-2+（共享写/对外/秘密/资金/生产/权威） | **外部闸门**：网关/凭据代理/出站控制/独立审批（机制 v2/15） | 硬边界在 agent 之外，不受提示词影响 |
| 权威变更（组织/授权/规则） | 治理面，不经执行体 | v2/03 |

**策略投影校验 fail-closed**（语义面，治 DSF V07-P0-1/P0-2）：派发须携带策略投影引用，校验失败（缺失/摘要不符/过期/引用不一致）即**不启动、不降级宽权限**；策略投影的传输通道与验签交付通道属施工件（**目标未证**，缺口登记 v2/17；端口字段 v2/14、通道形态 v2/12）。

### 2.3 旧格式迁移（「DSH 专属资产保留」口径，改写 v1 §3.2 两条铁律，治 V8-P1-1）

旧依赖格式经兼容绑定转换时：①**「DSH 专属」标记与未表达项必须保留**，不得丢弃、不得宣称另一框架读得懂名称/版本即等价承载；②旧包内插件目录**提取为独立能力包**（资产部一等资产、执行器专属标记，v2/06）并**单独授权**——这是专属资产的正式位置（84 D1/D1a），不再是「导入例外的收紧」。迁移处置与波次 → v2/16。

## 三、运行行为模型（EXEC- 族，唯一主表在本卷，登记 v2/09）

**总规则**：执行体/宿主事件**不是工作状态迁移的生产者**——迁移生产者三分（交付者发起型/决定型/规则型）唯一主表 v2/04 §五；执行体终态只是收割输入，`turn_end` 类事件直接覆盖工作状态＝违规；平台不支持某状态/字段必须报语义损失，不得把返工映射成完成。

### EXEC-01 派发

派发简报必含：工作与合同版本引用、执行计划锁定引用、工作区、**秘密类别＋逻辑引用**（值不进简报/日志/提示词）、策略投影引用与校验结论、宿主形态、预算与看护参数（端口维度 → v2/14）。派发前校验三fail-closed：策略投影校验失败不启动；执行体能力声明不足以覆盖岗位策略需求不派工；秘密供给未确认不注入。证据义务（派发回执）→ v2/08；记录 → v2/11。

### EXEC-02 执行

流式事件按段归属（出工段语义 v2/02 §六）。**副作用前留证主辅制**：主＝框架侧效果尝试（有外部回执的副作用，先记尝试后生效）；辅＝宿主检查点（仅补内部工具无外部回执场景），两者以幂等键对账（治 V07-P2-1）。工具调用经宿主策略流水线＝DSH 专属能力，备选家按 §二明示缺失。中途注入（插话）＝宿主能力维度，未声明即不支持（采纳/拒绝的决策登记 → v2/12）。长周期、中间无产物的工作必设中间复审点或进展信号（v2/04 §八；活性观察面 v2/08）。证据义务（事件流/工具回执/审批与拒绝事件）→ v2/08；记录 → v2/11。

### EXEC-03 中断

中断（叫停/杀）只能**整树**进行：枚举已知后代（§四）一并终止、围栏旧写入。**被杀执行体无终态事件→结果标「不明」**，不得与自报失败同形；对账完成前不得重试、接管或结清。**杀进程≠撤销外部后果，杀 worker≠工作结清**；工作面终止是另一个决定（EXEC-06）。常态更新不得杀活 worker；故障与紧急处置按预设叫停/止损权限执行并留证，不借「热更」扩大处置权。证据义务（围栏拒绝、终树清单、结果不明标记）→ v2/08；记录 → v2/11。

### EXEC-04 恢复（含会话续跑）

三层不得混同：①**工作面恢复＝新的决定**，由恢复位置按风险档作出（v2/04 §五；静默恢复＝W-06 违规）；②**执行面会话续跑＝同执行器同会话的技术续接**，前提＝同会话句柄＋cwd 逐字节一致；**续跑同一会话≠恢复同一出工段**（中断/恢复是段边界，续跑后开新段）；③新执行体接管（换家/换配置）须先对账再重试，不得盲目重放。不支持续跑的家**明报降级新派**，不得静默新开会话冒充续跑。会话归档收割入台账＝**目标未证**（现状：会话表无生产写者，V07-P2-2；记录 → v2/11）。证据义务（恢复决定引用、续跑会话与 cwd 证据、对账结论）→ v2/08；记录 → v2/11。

### EXEC-05 完成

**终态判据只认原生终态字段全值**（完成/错误/阻塞/中止/超限，枚举登记 v2/09；不得压缩为布尔；退出码仅作辅证，退出码 0 当且仅当「完成」类）。崩溃/超时/被杀→结果「不明」。**完成＝执行面闭合，按 EX- 分级判定**（v2/04 §一）：EX-2+＝四要件＋独立收割（收割者≠交付者）；EX-0/1＝终态＋自报＋抽样。执行体终态是「进行中→待验收」迁移的证据输入，不构成验收结论。证据义务（终态事件、用量、非空输出、REPORT、闸门结论）→ v2/08；记录 → v2/11。

### EXEC-06 终止

终止的执行面动作：停新动作→撤销运行时访问→围栏旧写入→**后代枚举与凭据停用（§四）**→迟到副作用持续观察（义务四要件引 v2/04 §八：具名观察主体、期限或终局条件、观察记录、升级处置；观察面 v2/08）。撤回完成判据见 §四；派生面未齐不得结清（v2/04 §六）。

**不支持时的诚实路径**（不虚构兼容的落点）：

| 不能 | 合法路径 |
|---|---|
| 暂停 | 在可中断边界停新动作，形成交接材料后结束段，不假装原地冻结 |
| 恢复 | 按当前证据重建新段，标明可能缺失与重复副作用，先对账再重试 |
| 快照 | 只保存外部可核验的输入/行动/结果/未决，不伪造宿主内部状态 |
| 取消 | 限制新动作、撤销可用凭据、隔离写入、持续观察迟到副作用 |
| 替换 | 暂停/改派/外部能力/终止，不为持续运行降低授权或验收 |

## 四、执行体派生树（治 DSF P0-12/O5-02、GLM K7 执行侧；85c-Q9 对象落地）

**对象定义**：执行体派生树＝以一次派发的**父执行体**为根、其运行期派生的全部执行体（子 agent、子 shell、外部后端子进程）及其**持有凭据清单**构成的树。本卷定义对象语义；记录形状 → v2/11；安全机制 → v2/15；权源 → v2/03；验证行 → v2/17。

**三规则**：

1. **派生即登记**：每次派生必记父引用、后端形态（进程内/外部 CLI）、preset 或能力子集、**凭据类别＋逻辑引用**（非值）、时点；无登记的派生＝违规，其行为仍归父责任链。子执行体的活性/进展并入父工作的观察面（v2/08）。
2. **子执行体不是任职者**：不产生身份、资格、任职史；其行为归父岗位责任链→任职者（v2/02）；不得用「工具自己做的」转移责任。**子执行体不得持 operating root key、不得自授**——root key 只由最高宰相（G9，内部老板）持有并用于签发内部硬动作；子执行体只持 scoped key（`REC-AUTH-04` 的 credential_class 区分 root/scoped；值集唯一主表 v2/09 **ENU-136 凭据类别**，字段形状 v2/11）。持 root key 的子执行体与「自授」同为负向用例（v2/15 §七 **SEC-ROOT-03** scoped key 不得升级为 root）。
3. **凭据继承默认不继承**：派生时凭据继承缺省值为「无」；子集继承须显式批准并记入派生登记；**衰减保证仅限进程内后端**——外部 CLI 后端保留自身权限系统，不假设继承收紧，须落绑定损失清单并记证据缺口（治 V07-P1-6 口径）。root key 不参与派生继承、不进派发简报/提示词/日志/快照（v2/15 三不入）。

**撤回时后代枚举与停用义务**（授权撤回/资格吊销/工作终止共用的执行面判据）：①后代清单（类型/标识/持有凭据类别＋逻辑引用）；②逐个停用或凭据失效证据；③**无后代时的显式确认方法**（如何确认无后代，不得空着）；④残留检查期的观察义务（v2/04 §八）。**撤回完成≠子执行体仍持可用凭据**——后代未全停或凭据未失效时，撤回不得记完成（撤回记录扩展字段语义本节，形状 v2/11；网关强制＝目标未证，建成前以审计断言代偿）。

## 五、工作区与会话续跑

**工作区＝受限履职环境**。分区语义：只读输入｜可变工作区（范围随授权最小化）｜产物/证据暂存（定稿经受控写入成不可变版本）｜交接区｜临时缓存（非证据、可清理）｜秘密代理面（短时句柄，值不进配置/快照/证据）。隔离六面（读/写/网络/执行/秘密）语义在本卷，**机制与形态（worktree/沙箱/seatbelt）唯一主表 v2/12、安全面 v2/15**。**cwd 不是隔离**：只影响相对路径解析，不构成读写/网络/秘密边界。现状约束（诚实登记）：当前隔离为**路径级**——同员工家内跨尝试可读、无 worktree 回滚；跨尝试隔离与可丢弃工作区＝**目标未证**（形态与损失清单 v2/12）。沙箱配置本身版本化，并验证逃逸/符号链接/绝对路径/外部句柄——归属验证分层（v2/17 故障注入层，治 H2b-P1-8 归属）。

**session_resume 口径**：会话续跑能力＝执行体能力声明的一个维度（声明不超证据，拟稿按不支持）。现状事实（参考装配）：DSH 适配器 `session_resume=true`（2026-10-23 真单证翻转，`--session-id` 透传续跑已真机实证）；daemon 合并跑已实现**跨进程续跑**——按断点解析原工位原会话唤起（`resumeWithSession`），cwd 逐字节一致为调度纪律。规范口径不变：续跑前提与段语义归 EXEC-04；会话证据归档收割＝目标未证（V07-P2-2）。
