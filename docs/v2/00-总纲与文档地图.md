## 一、V2 是什么、为什么重写

**是什么**：把「AI 自治公司」从根命题到逐文件技术细节的全部规范，按两族审计（GLM 26 份+DSF 63 份）与制作人两轮裁决（84 四条+84b 八项）重新写成一套**口径唯一、字面自洽、机器可验收**的现行规范。

**为什么重写而不修补**（84b 抉择 8）：v1 的权责模型（11 类可选治理位置/独立第三方审计/完成=终态/全部可重建）与制作人定调的新模型（两层老板：外部老板为根＋最高宰相为内部老板·N 个一级单元·分层审计·完成分级·钱账限域）不兼容，补丁式修订会留双基线。两族审计合并约 20 个 P0 根因，其中 6 项（GLM A 档）是「冻结即炸」的字面级问题，12 项是「权责/安全链不成立」的结构级问题——结构级问题只能靠重写消除。

**唯一权威结构（2026-10-28 修订令 §1.1/§1.2；全库按此写；旧模型句式见卷末修订记录第 3 条，仅作历史引文）**：

- **对外**：人类老板（所有者）是根，位于 agent 树之外。保留权力＝任命/撤回最高宰相、root 密钥轮换/撤回、外部审计/清算；宪法否决**默认没有**，只有显式配置 `external_veto` 才有。
- **对内**：**最高宰相（G9，唯一）就是内部老板**，持 operating root key、以老板身份签发内部硬动作；其权源来自外部老板的 `root_delegation`（范围/期限/可撤回/密钥指纹/外部签名或离线批准件），超范围＝外部可撤回的违约，不是内部程序非法。子 agent 不得自授、不得持 root key，只能持 scoped key（组织语义唯一源 v2/03 §3.1/§3.3；记录字段 v2/11；安全机制 v2/15 §七）。
- **最高层始终只有一个最高宰相（G9）**；其下设 **N 个一级单元（N≥1；N 为公司配置参数，默认 N=1）**。单设单元首长时，每单元一个首长＝G8「一级单元首长/部长」；**N=1 且不单设单元首长时，最高宰相直接管理（默认形态，退化为单层）**。「三省」只是 N=3 的**示例**，不是规范；不得写死 3。
- 一级单元首长是 G8、不是 G9：不持 root key、不是「小老板」，不能对外承诺、不能自定公司宪法、不能绕过最高宰相。**单元一域一权、域不重叠；跨单元事项与单元间冲突由最高宰相终裁，单元间不得各自对外承诺；单元缺位＝登记组织事件、最高宰相直管该单元、缺位期该单元不得新增 G8（紧急例外双角色记录＋外部审计抽样）。** 老板可**直接对话**一级单元首长（直通是沟通/监督通道），但授权链仍是「外部老板 → 最高宰相 → 一级单元首长 → 部门」——直通不产生第二个根。
- 术语：`宰相`一律写「最高宰相（G9，唯一，内部老板）」；新增「一级单元」「一级单元首长（G8）」两词（术语修订与新增已登记 v2/09 §三：**TERM-02 最高宰相**、**TERM-43 一级单元**、**TERM-44 一级单元首长**）。

**V2 不做什么**：不写实现代码；不改旧卷正文（旧卷只加「历史，非现行」头注）；不替代 AGENTS.md（其事实源/唯一写入者条文须按 V2 修订，**施工时点＝MIG-04 入口前**——`docs/86` B6 与 plan/03 §十三；DSF L0-A/L1-B 已证其自相矛盾）。

## 五、V2 写作纪律（每条对应 v1 的一个病根）

1. **唯一主表**：每个 ID 族、枚举、术语只在 09 卷定义一次；他卷只引用其 ID，禁止重述字面量。（治 GLM K9/K11、DSF P0-1）
2. **全前缀式 ID，禁裸字母**：公司层级 `CL2-CL9`、个人职级 `G1-G9`、部门等级 `D1-D9`、不变量 `I-`、反例 `R-/E-/W-`、记录 `REC-`、端口 `PORT-`、决策 `DEC-`、迁移 `MIG-`、验证 `V-`、缺口 `GAP-`。（治 K11、85c-Q10）
3. **记录型三件套**：每个有权责意义的对象=对象定义（05-08）+记录形状（11）+负向用例（17）三处齐，缺一不得标「已定」。（治 K1-K4、DSF P0-3/6/8/12）
4. **「目标（未证）」强制标注**：未建成机制的一律标注，禁止「已拍定/机制保证」语气。（治 DSF L0-A-P0-03、85c-Q5）
5. **字面自洽**：规范自给的示例值必须按自身规则合法；枚举值与类型声明一致。（治 K8）
6. **自引用自检**：卷内引用的节号/ID 必须存在；17 卷给出可执行的机械检查口径并对 V2 自身先跑一遍。（治 K10）
7. **规范/实现分离**：Studio Next 参考实现只在各卷末「参考装配」节，不混入规范正文。（治 H2a）
8. **安全面 fail-closed 默认**：任何「关掉即裸」「缺省放行」的配置键在 15 卷列为禁止形态。（治 DSF P0-9）
9. **审计处置表**：每卷末列出承接的 GLM K 簇/DSF P0 与处置（已解/方向已定/目标未证）。（84b §5.3）
10. **篇幅**：规范正文不含论证过程（论证归审计与决策记录）；目标 ≤ v1 对应卷 60%。
