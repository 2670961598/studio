把事做成。**三册不是三套理论，而是同一根命题的三种观察位置。

新增概念必须能映射回 63 的核心概念，并回答：为何存在、由谁承担、何时结束、失败去哪。
不能只换名字来逃避 63 的约束。

### 2.3 跨册引用规则

- **65 → 66**：只引用组织授权、资格认定与争议论坛，不决定其设置方式；
- **65 → 67**：只引用任务对能力、证据与交接的要求，不定义任务生命周期；
- **66 → 65**：只引用任职者身份、能力资格与生命周期，不决定个人记忆或个人绩效；
- **66 → 67**：只引用组织结果、资源消耗与承诺兑现情况，不定义工作执行过程；
- **67 → 65**：只引用任职者、能力资格与员工责任，不改变员工身份连续性；
- **67 → 66**：只引用授权、工作治理位置、验收位置、争议终裁与承诺规则，不另设组织权力。

引用形成的是输入输出关系，不是定义权转移，更不是责任转移。

## 六、每册扩写时必须回答的七个问题

每一章、每一制度、每一职责组合，均须能回答：

1. **为何存在**：它解决什么使命、责任或协调问题；
2. **谁负责**：责任位置及实例化主体是什么；
3. **权从何来**：授权、义务或禁止的依据是什么；
4. **如何完成**：正常输入、输出与完成判据是什么；
5. **如何证明**：证据、独立验收与异议位置是什么；
6. **失败去哪**：超时、冲突、无能、返工、停止与恢复如何处置；
7. **如何退出**：撤回、替换、终止、历史与承诺如何结清。

只答前四项而不答后三项，视为未展开完成。可选组织与协作形态只在条件成立时适用，
不得把部门、职级、派工、外部锚或合议写成所有公司的必然形态。
