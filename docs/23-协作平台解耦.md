# 23 · 协作平台解耦（FlowPlatform 端口）

> 2026-10-16 ｜ 制作人定调：YouTrack 也解耦，需要能切换协作平台的能力。
> 与 executor 适配器同一哲学：平台差异收敛进适配器，框架核心零 `if platform`。

## 一、FlowPlatform 端口（框架需要的七个能力）

```typescript
interface FlowPlatform {
  issues:    { list(q); get(id); create(...); transition(id, state); setField(...) }
  comments:  { add(issue, body); list(issue) }                    // 含署名注入
  fields:    { schema(); provision(map); }                        // 自定义字段与枚举
  kb:        { upsert(path, md); search(q); get(path) }           // 工作知识
  activity:  { since(cursor): ActivityPage }                      // 增量事件（轮询契约）
  links:     { link(a, b, type); children(id) }                   // 父子/依赖
  guards:    { install(company, rules); uninstall(company) }      // 平台侧第二道闸
}
```

- **YouTrack = 参考实现**（packages/yt 改造为该端口的 adapter；bundle/agiles/guard JS 等
  YouTrack 特性全部封装在适配器内，不外泄）
- **LocalFile = 第二实现**（packages/localplatform）：文件驱动的本地协作平台
  （单据=jsonl 文件、状态=目录流转、评论=md 追加）——同时满足三个目的：
  P8 的零依赖 demo 模式、契约测试的靶子、端口有效性的证明

## 二、映射层

- 公司在 org-config.yaml 声明：`platform: youtrack | localfile | ...` + 字段/状态流映射覆盖
  （延续"模板与建议不写死"总纲第 0 条）
- 等级/部门/泳道等业务字段名由公司模板定义，适配器只认端口语义
- 换平台 = 公司配置改一行 + 适配器实现存在；数据迁移走 export/import（独立工具，不在端口内）

## 三、纪律

- 框架核心只 import 端口类型，不 import 任何平台实现
- 新平台接入 = 实现端口 + 过契约包的平台测试集（cases.json 里平台无关的那部分）
- 状态权威仍归平台侧（18-§二），换平台不换状态机语义

### 三.2 平台无关契约面（plat 域；studio-dev-126 增批注记）

- 规范真源 = `packages/contract/CASES.md`（格式）+ `cases.json`（清单）；本节只钉
  解耦口径，冲突以 CASES.md 为准。
- **op 词表**（subject 路由约定）：`activity.since` / `comments.add` /
  `fields.provision` / `fields.provision.rerun` / `fields.provision.concurrent` /
  `issues.get` / `kb.get`——subject 由各适配器测试包内接线。
- **provision 收敛义务**（C-plat-009/010，studio-dev-126）：同 map 的 provision
  幂等且并发收敛——重跑/两写者竞跑（TOCTOU 判重窗口）均不得误报 CONFIG_INVALID。
  机制是适配器自由度（yt=实例内热换绑；localfile=整体替换落盘；taiga=GET-first
  判重 + 400 读回吸收，docs/32-§十），**收敛口径三适配器同一**。
- **分层证明**：契约 case=义务面（subject 诚实计算 `converged`，反证面揪谎报）；
  窗口吸收机制归各包单测（taiga：fields.test.ts——FakeTaiga 脚本化 400 形状
  对齐真机实测）。

## 四、验收口径

1. 同一张单的生命周期在 youtrack 与 localfile 两个适配器上各跑通一遍，证据格式一致
2. demo 模式（localfile）零外部依赖跑通 TTHW
3. 核心包对 youtrack 实现零直接 import（依赖方向测试）
