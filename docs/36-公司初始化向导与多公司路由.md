## 2. 向导流（拟）

```
studio-next company create（向导）           # 网页 / API 同一内核
① 选级 2-9 → 展示该级默认架构图（纵=等级 横=部门，可缩放）
② 人事面：逐层列出部门/岗位/人数（默认来自 docs/33 模板）
   简单模式=一键默认；开发者模式=逐项改（跨度/部门增删/岗位调整）
   员工命名：随机花名 + 工号规则（AGENT-N 可覆盖）
③ 公司配置面：IM（matrix）｜协作平台（Taiga）｜执行器（dsh 默认）
   ——仅列「capabilities 已声明适配」的选项，未适配不可选
④ 路由面：slug 决定（/就决定好了，冲突检查）→ 预览子路由树（/仪表盘 /单据 /报表 …）
⑤ 执行：init（按级模板）→ platform onboard（九步幂等）→ 建号 → jobs 装载
   → 插件 provisioning → 验收报告（全程 --dry-run 可预演）
```

## 3. API 面（拟，:8788 对外 API 扩展）

- `POST /companies`（body=向导五面的 JSON；同步返回路由树；幂等键=slug）
- `GET /companies` / `GET /companies/<slug>`（清单/详情）
- `DELETE /companies/<slug>`（退役=归档非删除，公司目录 git 仓保留）
- 鉴权走既有网关面（wkey/HMAC），本机 ZCode/codex 用 CLI 凭据直调
