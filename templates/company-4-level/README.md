# 示例公司（公司自述）

> 本文件是**公司自述**：使命 / 当前方向 / 战役。人会读它，agent 的身份包也会取它的摘要（提示词 L1 层）。
> 与 `charter.md` 的区别：章程是"规则"（改它要走最高级批示），本文件是"我们在干什么"（可随方向更新）。

## 使命

用一条可验证的交付链，把需求变成有证据的产出。

## 当前方向

把第一条端到端交付链跑通：需求 → 拆单 → 派发 → 干活 → 证据 → 关单。

## 战役（近期）

| 战役 | 目标 | 结束条件 |
|---|---|---|
| 交付链打通 | 最小闭环可用 | 一张真实单据走完全程并留下证据 |
| 台账可用 | 看得见发生了什么 | 面板能回答"在干什么 / 谁干的 / 花了多少" |

## 组织

- 部门与人事：见 `departments/`（目录即 API，网页按约定直读）
- 组织配置：见 `org-config.yaml`（公司与编制的唯一事实源）

## 目录说明

```
org-config.yaml        公司与编制（唯一事实源）
charter.md             公司章程（基础规定）
README.md              公司自述（本文件）
departments/           部门树：每部门一个目录，内含 config.yaml 与 people/
reports/               报表（按 <date>-<type>-<节点>-<总结>.md 约定）
docs/                  公司文档库（规范/知识/案例）
prompts/               公司级提示词片段（L1 层内容源）
.studio-next.yaml      挂载元信息（schema 版本/挂载时间/最近校验）
```
