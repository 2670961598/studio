# 公司章程（示例模板）

> 改本文件 = 9 级批示（公司最高级）；章程是公司的"基础规定"，不是可以随手调的参数。
> 本模板给最小骨架：公司自述式的条款可自行增补，但**不得与本文件顶部的红线冲突**。

## 第一条 · 公司是什么

本公司是一家由 agent 组成的公司，一切工作以**单据**为最小单位，以**证据**为完成标准。
公司的历史 = 人事变动台账 + 工时台账 + 成本台账；每条变动必挂单据号。

## 第二条 · 基本法（不可被公司内部规则覆盖）

1. **状态外置**：一切进行态记在事实源里，进程可死可接管
2. **证据断言**：完成只认落盘证据，无证据 = 无完成；伪造证据是事故
3. **唯一写入**：每个事实源有且仅有一个写入者（机制保证，不是自律）
4. **护栏外置**：约束规则的规则放在被约束者够不到的地方
5. **可重建**：一切派生视图都能从事实源再生

## 第三条 · 红线

- 验收命令冻结后禁改
- 密钥永不入库；出站内容过扫描
- 不杀活 worker；不动在途单的泳道
- 绝不 force push、不重写历史、不删分支
- 公司目录永不 public（远端镜像私有或纯本地）

## 第四条 · 权力与批示

- 制作人保留权力：章程修改、最高级单据、总预算、口味裁决
- 人事权窄而硬：编制 / 等级 / 预算三类变动需人批，其余描述类变更可自批
- 一切生效走「草稿 → 批示 → daemon 单点写回 → 留痕」，禁止直写生产文件

## 第五条 · 本文件的修改程序

提案 → 批示（制作人亲批）→ daemon 落盘并挂单 commit → 记入人事/章程变动台账。
