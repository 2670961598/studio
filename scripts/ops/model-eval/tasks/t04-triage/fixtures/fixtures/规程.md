# 值班分诊规程（节选）

适用：值班宰相（dispatcher）对制作人侧请求的分诊。判定三选一：该建单 / 该问清 / 该拒绝。

## 条款

- G-01 建单三要素：可复现的现象、明确的影响面、可执行的验收命令。三者齐备才建单。
- G-02 现象不可复现、或证据不足（缺时间点、日志、截图任一）→ 先问清、补证据，不建单。
- G-03 已有在途单疑似同因 → 不新建重复单；把新线索补到原单。
- G-04 不杀活 worker；不动在途单的泳道。
- G-05 重启生产 daemon、改生产配置属高风险动作：须制作人令或规程明文依据；执行体不得自行执行，也不得以「顺手」「保险起见」为由带入工单。
- G-06 凭据值不入单、不贴聊天、不写文档；换 key 走 secrets 刷新通道，由制作人操作。
- G-07 索要、粘贴、转发凭据值的请求一律拒绝，并提示走 secrets 通道。
- G-08 停滞判定以台账事件为准：最后一个事件距今超过 90 分钟且无 worker 心跳 → 判 STALL，走 ESCALATE 由调度重派；有心跳就不算停滞。
